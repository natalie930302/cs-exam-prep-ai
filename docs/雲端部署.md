# 雲端部署（Vercel + Turso）

雲端版跟本機版是同一套程式：同樣的頁面、動畫、筆記、字幕、搜尋、測驗和計算練習。差別只有兩點：

- 進度存在 Turso（雲端的 SQLite），不是 `data/prep.db`
- 要密碼才能進去，密碼是環境變數 `SITE_PASSWORD`

進度只留雲端一份。上線後電腦和手機都用雲端網址；開機自動開啟的也會改成雲端網址（見最後一步）。

## 第一次部署

以下指令都在專案資料夾執行。帳號和密碼都由你自己輸入。

1. **登入 Vercel**

   ```
   vercel login
   ```

2. **建立專案**：照提示選你的帳號，新建一個專案（名字自取，例如 `csie-prep`）。

   ```
   vercel link
   ```

3. **建立資料庫**：到 Vercel 網站打開這個專案，進入 **Storage** → **Create Database**（或 Marketplace）→ **Turso**。
   - 方案選免費的。
   - 地區選 **Tokyo（aws-ap-northeast-1）**，跟網站放在同一區，速度最快。
   - 建好後選 **Connect** 到這個專案。

   接上後，專案的 Environment Variables 會多出資料庫的網址和金鑰。名稱要是 `TURSO_DATABASE_URL` 和 `TURSO_AUTH_TOKEN`；如果名稱不一樣，把截圖給我。

4. **設定網站密碼**：在專案的 **Settings** → **Environment Variables** 新增一個變數，環境勾選 **Production**。
   - 名稱：`SITE_PASSWORD`
   - 值：你想用的密碼。

5. **把本機的進度搬上去**

   ```
   vercel env pull --environment=production .env.cloud
   node --env-file=.env.cloud tools/migrate-to-cloud.mjs
   ```

   會印出每張表搬了幾筆。重跑也沒關係，不會重複。`.env.cloud` 裡有金鑰，已設成不會進 git，也不會被上傳。

6. **部署**

   ```
   vercel deploy --prod
   ```

   完成後會印出網址（`https://….vercel.app`）。打開它、輸入密碼，就是你的網站。

7. **檢查雲端版**：把下面的網址換成你的。

   ```
   node --env-file=.env.cloud tools/check.mjs --labs=none
   ```

   執行前，先在 `.env.cloud` 最後加一行 `BASE=https://你的網址.vercel.app`。

8. **開機改開雲端版**：把網址存進 `tools/autostart/cloud-url.txt`，只要一行。之後開機會直接打開雲端版，不再啟動本機伺服器。

## 之後更新網站

改完程式、`npm run check` 通過後：

```
vercel deploy --prod
```

一定要從這台電腦用指令部署，不要在 Vercel 上接 GitHub 自動部署。字幕（`public/transcripts`）不在 GitHub 上，從 GitHub 部署的版本會沒有字幕，搜尋結果也會少很多。

## 換密碼

在 Vercel 改 `SITE_PASSWORD`，再執行一次 `vercel deploy --prod`。所有裝置都會被登出，要用新密碼重新登入。

## 費用與限制

Vercel Hobby 方案和 Turso 免費方案都不用錢。Hobby 限個人、非商業用途。

一段時間沒人用之後，第一次打開會慢大約 1 秒；第一次搜尋要先建索引，也會慢幾秒。
