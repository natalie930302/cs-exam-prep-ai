# 矩陣與線性方程組

線性代數最基本的問題只有一個：解線性方程組（system of linear equations）。這一章用三種角度看同一組方程式（row picture、column picture、矩陣形式 Ax = b），再用高斯消去法（Gaussian elimination）有系統地把它解出來，並且把消去的每一步寫成矩陣乘法。考試最常考的是手算消去、找 pivot、判斷消去會不會失敗（矩陣是否可逆），以及「左乘做列運算、右乘做行運算」。

## 學完這章要會
- 把一組方程式寫成 Ax = b：係數矩陣 A、未知數向量 x、右邊向量 b。
- 用 row picture（線／平面相交）和 column picture（行的線性組合）解讀同一個方程組。
- 用兩種方法算矩陣乘向量：行的線性組合、列和向量做內積。
- 手算消去：找 pivot、算 multiplier、做到上三角 U，再用增廣矩陣 [A | b] 加回代求解。
- 判斷消去是「暫時失敗」（換列就好）還是「完全失敗」（矩陣 singular）。
- 寫出消去矩陣 E₂₁、E₃₂、置換矩陣 P，知道它們放左邊還是右邊，會求 E 的反矩陣。
- 記住：矩陣乘法有結合律、沒有交換律。

## 為什麼要同時有「計算」與「幾何」兩種理解
很多人第一次學線性代數，會算卻不懂：
- 會算矩陣乘法：[1 2; 3 4] 乘 [5 6; 7 8] = [19 22; 43 50]。
- 會算行列式（determinant）：2×2 的 [a b; c d] 是 ad − bc，例如 [1 2; 3 4] 是 1·4 − 2·3 = −2。
- 會算外積（cross product）：兩個三維向量的外積是同時垂直它們的向量，例如 x 方向 × y 方向 = z 方向。
- 會算特徵值（eigenvalue）：有些向量被矩陣作用後只被拉長，拉長的倍數就是特徵值，例如某個矩陣把 (1, 1) 放大成 3 倍。

可是說不出：矩陣乘法為什麼這樣定義？外積跟行列式有什麼關係？特徵值到底代表什麼？

兩種理解分工不同：
- **幾何理解**：知道遇到問題該拿什麼工具、它為什麼有效、結果怎麼解讀。例如矩陣 [1 1; 0 1] 其實就是把整張方格紙推斜（shear）；它的第 2 行 (1, 1) 正是「往上的單位箭頭」被推到的位置。
- **數值理解**：真的把答案算出來。[1 1; 0 1] 乘 (1, 2) = (1·1 + 1·2, 0·1 + 1·2) = (3, 2)，就是點 (1, 2) 變形後的位置。

兩種都要有，不是二選一。只學數字、沒有幾何基礎，問題會潛伏到更深的課程才冒出來，那時別人好像一眼就知道答案的樣子，其實是靠幾何直覺，而不是腦中把數字全算一遍。

> **比喻** 假設你學 sin 時只拿到一個無窮多項式 sin x = x − x³/3! + x⁵/5! − …（n! 是 1 × 2 × … × n），作業就是代數字、在合理的地方截斷。例如 x = 1 算到第 4 項，已經和 sin 1 ≈ 0.8415 差不到千分之一。計算機確實是用多項式近似之類的方法、只靠加減乘除去算 sin 的。但你從不知道 sin 1 其實是「半徑 1 的圓上，角度 1 弧度那點的高度」。到了物理課，別人一看就知道正負號，你卻每題算很久。線性代數也一樣：背後只有少數幾個關鍵的視覺直覺，而且計算和圖像的連結很直接，懂了之後細節都會合理很多。

> **觀念** 現在大量的數值計算交給電腦，人要負責的是概念那一半。讀的時候覺得需要就停下來想，真正的學習發生在你自己思考的時候。

## 線性方程組的三種看法
「線性」的意思：每個方程式只含一次項（像 2x、−y），而且好幾個方程式要同時成立。先看最正常的情況：n 個方程式、n 個未知數。

同一組方程式有三種看法：
1. **Row picture**：一次看一個方程式（矩陣的一列 row）。兩個未知數時每式是一條直線，解是交點。
2. **Column picture**：一次看一整行（column），把方程組看成「行向量的線性組合」。這是最重要、也可能是你第一次看到的觀點。
3. **矩陣形式**：把係數排成矩陣 A，整組寫成 Ax = b。

### 寫成 Ax = b
例子（2 個方程式、2 個未知數）：

```
 2x −  y = 0
 −x + 2y = 3
```

- 係數矩陣（coefficient matrix）A：把 x、y 前面的數字照位置排成一張長方形數字表。第 1 列放第一式的係數 2、−1；第 2 列放第二式的係數 −1、2。所以 A = [2 −1; −1 2]。
- 未知數排成直的向量 x = (x, y)（向量常寫成粗體，和數字 x 區分）。
- 右邊排成向量 b = (0, 3)。

整組就是 Ax = b：A 的每一列乘上 (x, y)，剛好得到 2x − y 和 −x + 2y。

本書寫法：[a b; c d] 表示第 1 列是 a b、第 2 列是 c d 的矩陣；(x, y) 表示行向量。

## Row picture：直線（平面）的交點

### 2×2：兩條線交於一點
一次拿一個方程式，在 xy 平面上把滿足它的點全部畫出來。

第一式 2x − y = 0：
- 先看 x 軸（y = 0）：2x = 0，x = 0，所以原點 (0, 0) 在線上。
- 令 x = 1：2 − y = 0，y = 2，所以 (1, 2) 在線上。
- 線上任何點都是解，例如 (1/2, 1)：2 × 1/2 − 1 = 0，成立。

所有解排成一條直線，所以叫「線性」方程式（linear 裡面藏著 line）。

第二式 −x + 2y = 3：
- 過不過原點？x、y 代 0，左邊是 0 ≠ 3，所以不過原點。
- 令 y = 0：−x = 3，x = −3，點 (−3, 0)。
- 令 x = −1：1 + 2y = 3，y = 1，點 (−1, 1)。
- 兩點決定一條直線。

兩條線的交點同時滿足兩式，就是解：**x = 1、y = 2**。
檢查：2·1 − 2 = 0 ✓；−1 + 2·2 = 3 ✓。

> **重點** 判斷一條線（或一個平面）過不過原點，只要看右邊：右邊是 0 的方程式一定通過原點，右邊不是 0 就不通過。

### 3×3：三個平面交於一點
三個方程式、三個未知數：

```
 2x −  y      =  0
 −x + 2y −  z = −1
     −3y + 4z =  4
```

第一式沒有 z，等於 z 的係數是 0；第三式沒有 x。矩陣形式：

```
     [ 2 −1  0 ]        [ 0 ]
 A = [−1  2 −1 ]    b = [−1 ]
     [ 0 −3  4 ]        [ 4 ]
```

在三維空間裡，一個一次方程式的所有解排成一個**平面**（像一張無限大的薄紙）。以第二式 −x + 2y − z = −1 為例：
- 原點代入得 0 ≠ −1，不在平面上。
- (1, 0, 0)：−1 = −1 ✓
- (0, 0, 1)：−1 = −1 ✓（在 z 軸上）
- (0, −1/2, 0)：2y = −1，y = −1/2 ✓

這三點決定這個平面。第一式 2x − y = 0 沒有 z，z 可以是任何值，它也是一個平面。

- 兩個不平行的平面交成一條直線（像打開的書，兩頁交在書脊），線上的點滿足前兩式。
- 第三個平面把這條線切在一點，那一點就是解。

但三個平面疊在一起已經很難看清楚，四維以上更不可能畫，所以要改用 column picture。

## Column picture：用行向量湊出 b

### 2×2
同一組 2x − y = 0、−x + 2y = 3，這次一行一行看：
- x 在兩式的係數 2、−1 正好是第 1 行 col₁ = (2, −1)。
- y 的係數 −1、2 是第 2 行 col₂ = (−1, 2)。

整組變成：

```
 x·(2, −1) + y·(−1, 2) = (0, 3)
```

問題變成：**幾份 col₁、幾份 col₂ 才湊得出 b？**

每個向量乘一個數字、再全部加起來，叫**線性組合**（linear combination），這是整門課最基本的運算。

畫成平面上的箭頭（從原點出發，第一分量管左右、第二分量管上下）：
- col₁ = (2, −1)：往右 2、往下 1。
- col₂ = (−1, 2)：往左 1、往上 2。

取 x = 1、y = 2，向量相加的畫法是「下一個箭頭的尾巴接在前一個的尖端」：

```
 起點 (0, 0)
 + 1·col₁   → (2, −1)
 + 1·col₂   → (1,  1)
 + 1·col₂   → (0,  3)  = b ✓
```

數字檢查：第一分量 2 + (−2) = 0，第二分量 −1 + 4 = 3。

如果 x、y 可以是任何數，所有組合會到哪裡？col₁、col₂ 不在同一條線上，所以它們的組合**填滿整個平面**，任何 b 都湊得出來。

> **重點** 線性代數一再出現的兩個問題：
> 1. 哪個組合會得到 b？（解方程組）
> 2. 所有組合能得到哪些 b？（哪些 b 有解）

### 3×3：b 剛好是第 3 行
同一個 3×3 例子寫成行的組合：

```
 x·(2, −1, 0) + y·(−1, 2, −3) + z·(0, −1, 4) = (0, −1, 4)
```

col₁ = (2, −1, 0)，col₂ = (−1, 2, −3)，col₃ = (0, −1, 4)，b = (0, −1, 4)。

這題的 b 剛好等於 col₃，兩個箭頭完全疊在一起，所以答案一眼看出來：0 份 col₁、0 份 col₂、1 份 col₃，即 **(x, y, z) = (0, 0, 1)**。這個點就是 row picture 中三個平面交會的點：在 row picture 看不出來，換成 column picture 就一目了然。

當然不是每題都能一眼看出來，一般情況要用消去法（elimination）。

### 同一個 A，換一個 b
保持 A 不變，把 b 換成前兩行的和：(2, −1, 0) + (−1, 2, −3) = (1, 1, −3)。
b 是 1 份 col₁ 加 1 份 col₂，所以解是 **(1, 1, 0)**。
- Row picture：右邊換了，三個平面都跟著移動，變成三個新平面，交在新的點 (1, 1, 0)。
- Column picture：三個行向量完全沒變，只是換一種組合。

### 每個 b 都有解嗎？可逆與奇異
代數問法：對每個 b，Ax = b 都有解嗎？
組合問法：A 的各行的所有線性組合，能不能填滿整個空間？

這兩個是同一個問題，因為 Ax 本來就是「A 的各行乘上 x 的分量再相加」。

- 上面的 3×3 A 可以填滿三維空間：它是 **non-singular**（非奇異），也就是**可逆**（invertible）。
- 如果三個行向量剛好落在同一個平面上，例如 col₃ = col₁ + col₂，第 3 行沒帶來新方向，所有組合都被壓在那個平面裡。只有平面上的 b 有解；平面外的 b 怎樣都到不了，而大部分的 b 都在平面外。這種矩陣叫 **singular**（奇異），不可逆。

推廣到九維：9 個方程式、9 個未知數就有 9 個行向量，每個有 9 個分量。隨便挑一個隨機的 9×9 矩陣，幾乎一定是可逆的；但如果第 9 行剛好等於第 8 行，它沒貢獻新東西，9 行的組合只能填出九維空間裡的一個「8 維平面」，就會有到不了的 b。想像不出九維沒關係，代數的問法完全一樣。

### 解的三種情況
把上面的圖像整理成考試常問的三種情況（以 row picture 看就是「線／平面怎麼相交」）：

| 情況 | Row picture（2×2） | Column picture | 消去時看到的 |
|---|---|---|---|
| 唯一解（unique） | 兩線交於一點 | 行向量填滿空間，b 有唯一組合 | n 個 pivot 都湊得出來 |
| 無解（no solution） | 兩線平行不相交 | b 落在行的組合之外 | 某列左邊全 0、右邊不是 0（0 = 非零） |
| 無限多解（infinitely many） | 兩線重合 | b 在行的組合裡，但組合方式不只一種 | 某列左右都變成 0（0 = 0），有自由的未知數 |

後兩種只發生在 singular 矩陣：行向量擠在較低維的平面裡，b 在平面外就無解，在平面上就有無限多種組合。

## 矩陣乘向量：用行，也用列
A = [2 5; 1 3]，x = (1, 2)，求 Ax。

**方法一：一次一行（行的線性組合）**

```
 1·(2, 1) + 2·(5, 3) = (2 + 10, 1 + 6) = (12, 7)
```

**方法二：一次一列（內積 dot product）**
- 第 1 列 (2, 5) 和 x 對應相乘再相加：2·1 + 5·2 = 12
- 第 2 列 (1, 3) 和 x：1·1 + 3·2 = 7

兩種答案一樣，Ax = (12, 7)。反過來說，若 b = (12, 7)，方程組的解就是 x = (1, 2)。

> **重點** Ax 是 A 的行的線性組合，x 的分量告訴你每一行用幾份。

## 高斯消去法（Gaussian elimination）
消去法是每套軟體解方程組的方法：矩陣夠好時又快又能得到答案。消去的過程本身也會告訴你矩陣是好（可逆）是壞（奇異）。解方程組不需要用行列式。

例子：

```
  x + 2y + z =  2
 3x + 8y + z = 12
      4y + z =  2
```

資訊全在係數裡，所以只寫 A = [1 2 1; 3 8 1; 0 4 1]，右邊 b = (2, 12, 2)。

### 第一步：pivot 與 multiplier
- 第一式不動，我們要用它去消別人。
- 目標：把第二式的 x 消掉，也就是讓 (2,1) 位置（第 2 列第 1 行）變成 0。
- 左上角的 1 是**第一個 pivot**（樞紐元素），它所在的列叫 pivot row。
- 要減掉第一式的幾倍？第二式有 3x、第一式有 1x，所以是 3 倍。這個倍數叫 **multiplier**：ℓ₂₁ = 要消掉的數 ÷ pivot = 3 ÷ 1 = 3。
- 慣例：multiplier 是「乘了之後再**減**掉」的倍數。

R₂ − 3R₁：3 − 3·1 = 0，8 − 3·2 = 2，1 − 3·1 = −2。第 3 列不動。

```
 [1 2  1]      [1 2  1]
 [3 8  1]  →   [0 2 −2]      R₂ − 3R₁
 [0 4  1]      [0 4  1]
```

這叫「2-1 步」（清掉 (2,1) 位置）。

### 第二步：(3,1) 與 (3,2)
- (3,1) 本來就是 0，multiplier 是 0，不用做（但程式還是得檢查一下才知道）。
- 現在 x 已經從下面兩式消失，剩下 y、z 的兩個方程式。新的左上角 2 是**第二個 pivot**。整個過程就是同樣的事一再重複，像遞迴一樣。
- 要清 (3,2) 位置的 4：multiplier ℓ₃₂ = 4 ÷ 2 = 2。

R₃ − 2R₂：4 − 2·2 = 0，1 − 2·(−2) = 5。

```
 [1 2  1]      [1 2  1]
 [0 2 −2]  →   [0 2 −2]  = U    R₃ − 2R₂
 [0 4  1]      [0 0  5]
```

三個 pivot：**1、2、5**。

> **陷阱** 第 2 列算完是 (0, 2, −2)，不是 (0, 2, −1)：1 − 3·1 = −2。這一格算錯，第三個 pivot 就會錯；正確是 1 − 2·(−2) = 5。

### 從 A 到 U：上三角矩陣
消去完的矩陣叫 **U**（upper triangular，上三角）：對角線下方全是 0。消去的目的就是從 A 走到 U，這是科學計算裡最常見的計算。

規則：pivot 不能是 0（要拿它來除）。這個矩陣一路都沒碰到 0，是好矩陣。

> **重點** 行列式等於 pivot 相乘（沒有換列時）：det A = 1 × 2 × 5 = 10。

### 消去什麼時候會失敗
失敗的意思是：湊不出 n 個 pivot。

- **左上角一開始就是 0**：第一式沒有 x。不用放棄，跟下面的列交換就好。
- 嚴格說 pivot 不會是 0：是「pivot 的位置是 0」，要換一個非零的列上來當 pivot。
- **暫時失敗**：把 A 的 8 改成 6，則 6 − 3·2 = 0，第二個 pivot 的位置變成 0。但它下面還有非零的 4，把第 2、3 列交換就能繼續。

```
 [1 2  1]      [1 2  1]      [1 2  1]
 [3 6  1]  →   [0 0 −2]  →   [0 4  1]    R₂ ↔ R₃
 [0 4  1]      [0 4  1]      [0 0 −2]
```

- **完全失敗**：把右下角的 1 改成 −4。照同樣步驟，最後一格是 −4 − 2·(−2) = 0，第三個 pivot 位置是 0，下面已經沒有列可以換，所以沒有第三個 pivot：這個矩陣**不可逆（singular）**。

```
 [1 2  1]      [1 2  1]      [1 2  1]
 [3 8  1]  →   [0 2 −2]  →   [0 2 −2]
 [0 4 −4]      [0 4 −4]      [0 0  0]
```

> **重點** pivot 位置是 0、下面還有非 0 → 換列（暫時失敗）；pivot 位置是 0、下面全是 0 → 完全失敗，矩陣 singular。

### 增廣矩陣與回代（back substitution）
右邊 b 也要跟著做同樣的列運算（方程式兩邊要做同樣的事）。把 b 當成多出來的一行接在 A 旁邊，叫**增廣矩陣**（augmented matrix），寫成 [A | b]（augment = 接上去）。

```
 [1 2  1 |  2]      [1 2  1 |  2]      [1 2  1 |   2]
 [3 8  1 | 12]  →   [0 2 −2 |  6]  →   [0 2 −2 |   6]
 [0 4  1 |  2]      [0 4  1 |  2]      [0 0  5 | −10]
                    R₂ − 3R₁:            R₃ − 2R₂:
                    12 − 3·2 = 6         2 − 2·6 = −10
```

A 變成 U，b 變成 c = (2, 6, −10)。新方程組 Ux = c：

```
 x + 2y +  z =   2
     2y − 2z =   6
          5z = −10
```

U 是三角形，所以從最後一式往上一個一個解，這叫**回代**：
1. 5z = −10 → z = −2
2. 2y − 2·(−2) = 6 → 2y + 4 = 6 → y = 1
3. x + 2·1 + (−2) = 2 → x = 2

解是 **(x, y, z) = (2, 1, −2)**。檢查：A 乘 (2, 1, −2) = (2 + 2 − 2, 6 + 8 − 2, 0 + 4 − 2) = (2, 12, 2) ✓。

## 把消去寫成矩陣：左乘組合列，右乘組合行
前面一直在變換矩陣，現在把「操作本身」也寫成矩陣。

- **矩陣 × 行向量 = 行的線性組合。** 以 A = [1 2 1; 3 8 1; 0 4 1] 乘 (3, 4, 5)：

```
 3·(1, 3, 0) + 4·(2, 8, 4) + 5·(1, 1, 1)
 = (3 + 8 + 5, 9 + 32 + 5, 0 + 16 + 5) = (16, 46, 21)
```

- **列向量 × 矩陣 = 列的線性組合。** 把 1×3 的列 [1 2 7] 放在 A 左邊乘，結果是一個列：

```
 1·[1 2 1] + 2·[3 8 1] + 7·[0 4 1]
 = [1 + 6 + 0, 2 + 16 + 28, 1 + 2 + 7] = [7 46 10]
```

> **重點** 從左邊乘，是在做「列」的線性組合；消去用的全是列運算，所以這個觀點更重要。

### 消去矩陣 E₂₁
要找一個矩陣 E，放在 A 左邊，能做到「第 2 列減 3 倍第 1 列，其他列不變」。

- 第 1 列不變 → E 的第 1 列是 [1 0 0]（取 1 份第 1 列，其他 0 份）。
- 第 3 列不變 → E 的第 3 列是 [0 0 1]。
- 如果中間也放 [0 1 0]，就是**單位矩陣**（identity matrix）I：乘什麼都不變，就像數字 1。
- 但新第 2 列 = −3 份第 1 列 + 1 份第 2 列，所以中間是 [−3 1 0]。

```
       [ 1 0 0 ]
 E₂₁ = [−3 1 0 ]        E₂₁A = [1 2 1; 0 2 −2; 0 4 1]
       [ 0 0 1 ]
```

抽查一格：E₂₁A 的 (2,3) 位置 = E₂₁ 的第 2 列和 A 的第 3 行做內積 = −3·1 + 1·1 + 0·1 = −2 ✓。

E 是 elementary（基本）或 elimination（消去）矩陣，下標 21 表示它負責把 (2,1) 位置變成 0。

到這裡已經有三種看矩陣乘法的方式：一次一行、一次一列、一次一個元素（列和行做內積）。

### E₃₂ 完成消去
第 3 列減 2 倍第 2 列，負責 (3,2) 位置：

```
       [1  0 0]
 E₃₂ = [0  1 0]
       [0 −2 1]
```

前兩列不改；第 3 列 = 0 份第 1 列、−2 份第 2 列、1 份第 3 列。規律：**multiplier 的負值**坐在要清的那個位置（減 2 倍就放 −2）。

整個消去寫成：E₃₂(E₂₁A) = U。

### 結合律：一個矩陣做完全部
有沒有一個矩陣能一次把 A 變成 U？有：把括號移一下。

```
 E₃₂(E₂₁A) = (E₃₂E₂₁)A = U
```

**結合律**（associative law）：矩陣的順序不能動，但先算哪個乘法可以換。線性代數裡很多步驟和證明都只是在移括號，這條規則一定要記住。

```
                      [ 1  0 0]
 E = E₃₂E₂₁ =         [−3  1 0]
                      [ 6 −2 1]
```

（E 的第 3 列 = 0·[1 0 0] − 2·[−3 1 0] + 1·[0 0 1] = [6 −2 1]。）EA = U。

### 置換矩陣（permutation matrix）
另一種 elementary matrix：交換兩列。pivot 位置是 0 時就需要它。

以 M = [a b; c d] 為例，想變成 [c d; a b]：新第 1 列要 1 份第 2 列，新第 2 列要 1 份第 1 列，所以

```
 P = [0 1]      PM = [c d]
     [1 0]           [a b]
```

快速找法：**對單位矩陣 I 做同樣的換列，得到的就是 P。**

如果想交換「行」，變成 [b a; d c]？放在左邊做不到，因為左乘永遠在組合列。要放在右邊：MP 一次看一行，新第 1 行取 M 的第 2 行、新第 2 行取 M 的第 1 行：

```
 MP = [a b][0 1] = [b a]
      [c d][1 0]   [d c]
```

> **重點** 列運算：矩陣乘在**左邊**；行運算：矩陣乘在**右邊**。

> **陷阱** 矩陣乘法沒有交換律（commutative law）：PM 跟 MP 不一樣，一般 AB ≠ BA。但結合律成立。一句話：**順序不能換，括號可以移。**

### 反矩陣：減掉的加回去
比起把 E₃₂E₂₁ 乘出來，更好的問法是：怎麼從 U 回到 A？把步驟倒回去的矩陣叫**反矩陣**（inverse），記作 E⁻¹（讀作 E inverse）。

E₂₁ = [1 0 0; −3 1 0; 0 0 1] 做的是「第 2 列減 3 倍第 1 列」，例如把 (2, 12, 2) 變成 (2, 6, 2)。

要還原：剛才減掉 3 倍第 1 列，現在就把 3 倍第 1 列**加回**第 2 列。

```
         [1 0 0]
 E₂₁⁻¹ = [3 1 0]        只是 −3 變成 +3
         [0 0 1]
```

它把 (2, 6, 2) 變回 (2, 12, 2)。檢查：E₂₁⁻¹E₂₁ = I。之後就是用這些反矩陣把消去倒過來，得到 A = LU。

> **例題** 寫出做「R₃ − 2R₂」的矩陣和它的反矩陣。
> 解：E₃₂ = [1 0 0; 0 1 0; 0 −2 1]；反向操作是「R₃ + 2R₂」，E₃₂⁻¹ = [1 0 0; 0 1 0; 0 2 1]。

## 重點整理
- 線性方程組 = Ax = b；A 是係數矩陣，x 是未知數向量，b 是右邊向量。
- Row picture：每個方程式是一條線（2D）或一個平面（3D），解是交點。
- Column picture：Ax = x₁·col₁ + x₂·col₂ + …，問「幾份每一行湊得出 b」。
- 右邊是 0 的方程式一定過原點。
- Ax = b 對每個 b 都有解 ⇔ A 的行的組合填滿空間 ⇔ A non-singular（可逆）。
- 行向量擠在同一個平面（例如 col₃ = col₁ + col₂）→ singular，平面外的 b 無解。
- 解的三種情況：唯一解（n 個 pivot）、無解（0 = 非零）、無限多解（0 = 0，有自由未知數）。
- Ax 兩種算法：行的線性組合；每列和 x 做內積。
- multiplier ℓᵢⱼ = 要消掉的數 ÷ pivot，做 Rᵢ − ℓᵢⱼRⱼ。
- 例題 A = [1 2 1; 3 8 1; 0 4 1] 的 pivots 是 1、2、5；det = 10；Ax = (2, 12, 2) 的解是 (2, 1, −2)。
- pivot 位置是 0：下面有非 0 就換列（暫時失敗），沒有就 singular（完全失敗）。
- 增廣矩陣 [A | b]：b 跟著做同樣的列運算，得到 Ux = c，再由下往上回代。
- E₂₁ = I 的 (2,1) 位置放 −ℓ₂₁；E = E₃₂E₂₁，EA = U。
- 左乘 = 列運算，右乘 = 行運算；置換矩陣 P = 把 I 的列交換。
- 結合律成立、交換律不成立：一般 AB ≠ BA。
- 消去矩陣的反矩陣：把 −ℓ 改成 +ℓ（減掉的加回去）。
