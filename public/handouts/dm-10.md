# 代數結構

代數結構（algebraic structure）就是「一個集合 + 一個或多個運算 + 這些運算滿足的性質」。這一章依性質由少到多認識 group（群）、ring（環）、field（體）與 vector space（向量空間），重點是記清楚每種結構要哪幾條公理，並會用例子判斷「是不是」。最後補上布林代數的化簡規則。這章考得少，時間不夠可以放到最後讀，但群的四條性質一定要會。

## 學完這章要會
- 代數結構是什麼、為什麼要分類。
- group 的條件：封閉性、結合律、單位元、反元素；abelian group 多交換律。
- 判斷常見例子：(ℤ, +)、(ℤₙ, + mod n)、(ℝ*, ×)、可逆函數與合成、2 × 2 可逆矩陣與乘法。
- ring 的條件（加法 abelian group、乘法結合、乘法單位元、左右分配律）與「ring 要不要有 1」兩種定義。
- field：乘法可交換、非零元素都有乘法反元素；ℤₙ 是 field ⇔ n 是質數；ℚ[√2] 的運算與反元素。
- vector space 的條件與例子。
- 布林代數的基本定律與化簡。

## 什麼是代數結構

一堆物件組成的集合——可以是數字，也可以是函數、矩陣，什麼都可以——再加上一個或多個能對它們做的運算（加、乘、合成……）。依「有幾個運算」和「運算滿足哪些性質」來分類。

**為什麼要分類**：
1. 在看起來毫不相干的系統（數字、矩陣、函數）之間找到共通點。
2. 發現性質跟熟悉系統很像的新系統。
3. 最重要：一個定理只要證一次，就對所有具有相同性質的系統都成立——證了一個關於所有 group 的定理，它對每一個 group 都成立，連還沒被發現的也一樣。

由少到多：group → ring → field → vector space。

## Group（群）

集合 G 加上一個運算 ⊕（寫成圈圈加號，提醒它可以是加法、乘法或任何運算），滿足：

| 條件 | 內容 |
|---|---|
| 封閉性 closure | a, b ∈ G ⇒ a ⊕ b ∈ G |
| 結合律 associativity | (a ⊕ b) ⊕ c = a ⊕ (b ⊕ c) |
| 單位元 identity | 存在 e，對所有 g：e ⊕ g = g ⊕ e = g |
| 反元素 inverse | 每個 g 都有 g⁻¹：g ⊕ g⁻¹ = g⁻¹ ⊕ g = e |

（封閉性有時被包含在「⊕ 是 G 上的運算」這句話裡，不另外列。）單位元實際上可能叫 0，也可能叫 1。

> **陷阱** 單位元和反元素都要「兩個順序」都成立；group 不要求交換律。

> **例題** (ℤ, +) 是 group：
> 1. 封閉：整數加整數還是整數。
> 2. 結合律：(2 + 3) + 4 = 2 + (3 + 4) = 9，整數加法本來就有。
> 3. 單位元是 0：a + 0 = 0 + a = a。
> 4. a 的反元素是 −a：a + (−a) = (−a) + a = 0。
>
> 四條都成立 ⇒ group。之後的例子要驗的就是這幾條。

**更多 group**：
- (ℤₙ, + mod n)：例 n = 5，0 到 4 互加完（mod 5）還在 0 到 4，0 是單位元，非零的 a 的反元素是 5 − a。
- (ℚ, +)、(ℝ, +)。
- (ℝ*, ×)：非零實數用乘法，單位元是 1。要拿掉 0，因為 0 乘任何數都是 0，回不到 1，沒有乘法反元素。(ℚ*, ×) 也是。
- 所有**可逆函數**，運算是合成：f ∘ (g ∘ h) = (f ∘ g) ∘ h；單位元是恆等函數 I(x) = x；因為可逆，每個都有反函數。
- 2 × 2 **可逆矩陣**，運算是矩陣乘法：單位元是單位矩陣 I；要求可逆是為了每個都有反元素；AB 不一定等於 BA，但 (AB)C = A(BC)，所以還是 group。

**abelian group**（commutative group，阿貝爾群）：再滿足 a ⊕ b = b ⊕ a。上面 ℤ、ℤₙ、ℚ、ℝ* 是 abelian；可逆函數和可逆矩陣不是，但照樣是 group。

## Ring（環）

兩個運算 ⊕（加法）和 ★（乘法），符號像加乘，但不一定是平常的加乘。條件：
1. (R, ⊕) 是 **abelian group**：有加法單位元 0、加法反元素，加法結合、可交換。
2. ★ 有**結合律**。
3. 有**乘法單位元** 1（不一定是實數的 1）。
4. **分配律**，左右都要：a ★ (b ⊕ c) = (a ★ b) ⊕ (a ★ c)，(b ⊕ c) ★ a = (b ★ a) ⊕ (c ★ a)。左右都要寫，是因為 ★ 不一定能交換。

> **陷阱** 「ring 要不要有 1」有兩種定義。一種要求有 1；沒有乘法單位元、其他都有的結構另外叫 rng（把 ring 的 i 拿掉，也有人叫 rong）。另一種（不少離散數學課本）的 ring 不要求 1，有 1 的叫 ring with unity。考試先確認題目用的是哪一種。

**ring 的例子**（要逐條驗證工作量很大，這裡不一一證）：
- (ℤ, +, ×)。
- ℤₙ（加、乘都 mod n）。
- 所有 2 × 2 矩陣（不必可逆，因為 ring 不需要乘法反元素；加法反元素是每一格加負號，相加得零矩陣）。
- ℝ[x]：所有實係數多項式，例如 (x + 1)(x − 1) = x² − 1，乘完還是多項式。

## Field（體）

field 是一個乘法**可交換**的 ring（commutative ring），而且 **0 以外**的每個元素 f 都有乘法反元素 g：f × g = g × f = 1。一句話：乘法可交換、非零都可逆的 ring。

> **陷阱** 只要求「非零」元素有乘法反元素；0 乘什麼都是 0，永遠到不了 1。

> **例題** ℤₙ 什麼時候是 field？
> - ℤ₅：1 × 1 = 1、2 × 3 = 6 ≡ 1、4 × 4 = 16 ≡ 1 (mod 5)，非零的都有反元素（3 的反元素是 2）⇒ field。
> - ℤ₆：2 乘任何數再 mod 6 只會得 0、2、4，永遠得不到 1；3 和 4 也沒有反元素 ⇒ 不是 field。
>
> ℤₙ 是 field ⇔ n 是質數（記 ℤₚ）。

其他常見 field：ℚ、ℝ、ℂ（a + bi，i² = −1）。

### ℚ[√2]

ℚ[√2] = { a√2 + b : a, b ∈ ℚ }，用一般的加法、乘法。

> **例題** 加法：(3√2 + 4) + (4√2 + 6) = 7√2 + 10，合併同類項，還是 a√2 + b 的樣子。

> **例題** 乘法：(2√2 − 4)(−5√2 + 3)，用 FOIL（First、Outer、Inner、Last）展開：
> - First：2√2 · (−5√2) = −10 · 2 = −20
> - Outer：2√2 · 3 = 6√2
> - Inner：(−4) · (−5√2) = 20√2
> - Last：(−4) · 3 = −12
>
> 合併：(6√2 + 20√2) + (−20 − 12) = **26√2 − 32**。

> **例題** 3√2 + 4 的乘法反元素：直覺是 1/(3√2 + 4)，但這不像 a√2 + b。上下同乘 3√2 − 4（分母有理化）：
> 分母 (3√2)² − 4² = 18 − 16 = 2 ⇒ 反元素 = (3√2 − 4)/2 = **(3/2)√2 − 2**。
> 驗算：(3√2 + 4)((3/2)√2 − 2) = 9 − 6√2 + 6√2 − 8 = 1 ✓。a = 3/2 是有理數，沒問題。
> 一般 a√2 + b ≠ 0 時，分母變成 2a² − b²；因為 √2 是無理數，a、b 不全為 0 時它不會是 0。所以每個非零元素都有反元素（這是證明的想法）。

## Vector space（向量空間）

結構最複雜，因為有兩個集合：向量集合 V 和純量（scalar）集合 F，F 必須是 field。
1. (V, +) 是 commutative group：零向量是單位元，有加法反元素，結合、可交換。
2. F 是 field。
3. **純量乘法**：任何 s ∈ F、v ∈ V，s·v ∈ V，而且
   - 1·v = v
   - (ab)v = a(bv)
   - a(u + v) = au + av
   - (a + b)v = av + bv

例：ℝⁿ（n 個實數排成一列或一行）；所有 ℝ → ℝ 的函數（能相加、能乘純量）；ℂ 當成 ℝ 上的向量空間；ℚ[√2] 當成 ℚ 上的向量空間（後兩者元素其實能相乘，但當向量空間時不管那個乘法）。再往下是 basis、dimension，屬於線性代數。

> **比喻** 抽象代數不是在「解 2x + 5 = 0」，而是在多項式、矩陣、數字這些不同系統中找出共通的結構。group 一個運算；ring 多第二個運算；field 再要求乘法交換、非零可逆；vector space 再多一組純量。

## 布林代數的化簡規則（補充）

**Boolean algebra**：集合 B 上有兩個二元運算 +（OR）、·（AND），一個一元運算 '（補數，NOT），以及兩個特別元素 0、1。最常見的是 B = {0, 1}：1 + 1 = 1、1·0 = 0、0' = 1。

| 定律 | 加法形式 | 乘法形式 |
|---|---|---|
| 單位律 identity | x + 0 = x | x · 1 = x |
| 補數律 complement | x + x' = 1 | x · x' = 0 |
| 交換律 commutative | x + y = y + x | x · y = y · x |
| 結合律 associative | (x + y) + z = x + (y + z) | (xy)z = x(yz) |
| 分配律 distributive | x + yz = (x + y)(x + z) | x(y + z) = xy + xz |
| 冪等律 idempotent | x + x = x | x · x = x |
| 支配律 domination | x + 1 = 1 | x · 0 = 0 |
| 吸收律 absorption | x + xy = x | x(x + y) = x |
| De Morgan | (x + y)' = x'y' | (xy)' = x' + y' |

另外 (x')' = x（雙重補數）。

- **對偶原理**（duality）：把一條恆等式的 + 和 · 互換、0 和 1 互換，得到的仍是恆等式（上表左右兩欄就是彼此的對偶）。
- 注意 x + yz = (x + y)(x + z) 在一般數的算術裡不成立，布林代數裡成立。

> **例題**（示意）化簡 xy + xy'：
> xy + xy' = x(y + y')（分配律）= x · 1（補數律）= **x**。

> **例題**（示意）化簡 x + x'y：
> x + x'y = (x + x')(x + y)（加法對乘法的分配律）= 1 · (x + y) = **x + y**。

> **例題**（示意）化簡 (x + y)(x + y')：
> = x + yy'（分配律 x + yz = (x + y)(x + z) 倒過來用）= x + 0 = **x**。

> **陷阱** 布林代數沒有「減法」和「除法」：x + y = x + z 推不出 y = z（例：x = 1 時兩邊都是 1）。

## 重點整理
- 代數結構 = 集合 + 運算 + 性質；證一次定理，同類系統都適用。
- group：封閉、結合、單位元、反元素（兩個順序都要）；不要求交換；交換的叫 abelian。
- (ℤ, +)、(ℤₙ, +)、(ℚ, +)、(ℝ, +)、(ℝ*, ×)、可逆函數 ∘、2 × 2 可逆矩陣 × 都是 group；後兩者不是 abelian。
- ring：加法 abelian group + 乘法結合 + 乘法單位元 + 左右分配律；有的定義不要求 1（ring with unity）。
- field：乘法可交換、非零元素都有乘法反元素；ℤₙ 是 field ⇔ n 質數；ℚ、ℝ、ℂ、ℚ[√2] 是 field。
- 1/(3√2 + 4) = (3/2)√2 − 2。
- vector space：(V, +) 交換群、F 是 field、純量乘法四條規則。
- 布林代數：補數律、冪等律、吸收律、De Morgan、x + yz = (x + y)(x + z)；對偶原理。
