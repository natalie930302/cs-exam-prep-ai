# 對稱矩陣與二次型

對稱矩陣（A = Aᵀ）是最重要的一類矩陣：特徵值全是實數、特徵向量可以選成互相垂直，所以一定能用正交矩陣對角化 A = QΛQᵀ（譜定理）。這一章先證明這兩個事實，接著把它推廣到複數（Hermitian、unitary 矩陣、Fourier 矩陣與 FFT），最後是對稱矩陣裡「最棒」的一群：正定矩陣，以及它和二次型 xᵀAx、函數最小值、橢圓／橢球的關係。考試重點：對稱矩陣的正交對角化流程（求 Q 使 QᵀAQ = Λ，出現機率極高）、正定的各種判斷法（特徵值全正、所有左上子行列式全正、pivots 全正、xᵀAx > 0）。

## 學完這章要會
- 說出並證明：實對稱矩陣的特徵值是實數、不同特徵值的特徵向量互相垂直。
- 做完整的正交對角化：求特徵值 → 求特徵向量 → 重根時在特徵空間裡做 Gram-Schmidt → 單位化 → Q、Λ。
- 寫出 A = QΛQᵀ = λ₁q₁q₁ᵀ + … + λₙqₙqₙᵀ（投影的組合）。
- 用 pivots 的正負號數出正、負特徵值的個數。
- 複數向量的長度 zᴴz、內積 yᴴx；Hermitian（Aᴴ = A）、unitary（QᴴQ = I）。
- Fourier 矩陣 (F)ⱼₖ = wʲᵏ、F₄ 的樣子、FFT 為何只要 ½ n log₂ n 次乘法。
- 正定的四種等價測試，特別是「所有左上子行列式 > 0」；分辨正定、半正定、不定。
- 把 xᵀAx 寫成二次型 ax² + 2bxy + cy²，用配方（= 消去法）判斷碗或馬鞍。
- Hessian 正定 ⇔ 最小值；xᵀAx = 1 是橢圓／橢球，主軸沿特徵向量、半軸長 1/√λ。

## 對稱矩陣的兩大事實
對稱（symmetric）矩陣：沿左上到右下的對角線對折，兩邊數字一樣，A = Aᵀ。學到一種特殊的矩陣，先問兩件事：特徵值有什麼特別？特徵向量有什麼特別？（例如 Markov 矩陣一定有 λ = 1。）

> **重點** 實對稱矩陣：(1) 特徵值**全是實數**；(2) 特徵向量**可以選成互相垂直**（orthogonal），而且永遠有完整的 n 個。

對照：旋轉 90° 的 [0 −1; 1 0] 不對稱，特徵值是 ±i，跑出實數線；對稱矩陣不會這樣。

### 「可以選成」垂直
- 單位矩陣 I：特徵值全是 1，**每個**向量都是特徵向量（Ix = x），它們當然不全垂直。所以準確的說法是「可以選成」垂直：從中挑三支互相垂直的（例如三個座標軸）。
- 特徵值都不同：每個 λ 只有一條直線的特徵向量（特徵空間一維），這些線自動互相垂直。
- 有重根，例如特徵值 4、2、2：λ = 2 的特徵向量鋪滿一整個平面，平面上任何向量乘 A 都變 2 倍。在平面裡**挑兩支互相垂直的**，再加上 λ = 4 那條線，就湊出 3 支互相垂直的單位特徵向量。

> **陷阱** 「特徵向量垂直」嚴格說是「不同特徵值的特徵向量自動垂直；同一個重根特徵值的特徵向量要自己挑成垂直」。重根時特徵空間裡也有不垂直的特徵向量。

## 譜定理：A = QΛQᵀ
一般可對角化的矩陣 A = SΛS⁻¹（S 的行是特徵向量）。對稱矩陣的特徵向量互相垂直，再各自除以長度變成單位向量，就是 orthonormal，S 改叫 **Q**。Q 的行標準正交，QᵀQ = I，所以 Q⁻¹ = Qᵀ：

```
 A = QΛQ⁻¹ = QΛQᵀ        （正交矩陣 × 對角矩陣 × 正交矩陣的轉置）
```

反過來，(QΛQᵀ)ᵀ = (Qᵀ)ᵀΛᵀQᵀ = QΛQᵀ，所以能寫成這種形式的矩陣一定對稱。

> **重點** **譜定理**（spectral theorem）：實矩陣 A 能被正交矩陣對角化 ⇔ A 是對稱矩陣。spectrum（譜）就是特徵值的集合，像光拆成純色的光譜，矩陣也拆成純粹的特徵值和特徵向量。力學裡叫**主軸定理**（principal axis theorem）。

> **例題** A = [2 1; 1 2]。特徵值 3、1（trace 4、det 3）；特徵向量 (1, 1)、(1, −1)，(1, 1)·(1, −1) = 0。除以 √2：q₁ = (1, 1)/√2、q₂ = (1, −1)/√2。Q = (1/√2)[1 1; 1 −1]，Λ = [3 0; 0 1]，QΛQᵀ 乘回去就是 [2 1; 1 2]。

> **比喻** 主軸定理的動畫：單位圓先轉 45°（乘 Qᵀ，轉到特徵向量座標），沿座標軸拉長 3 倍、1 倍（乘 Λ），再轉回來（乘 Q），結果和直接乘 A 一樣。沿著對的軸看，各方向互不牽連。

### 正交對角化的標準流程（必考）
題型：「求正交矩陣 P（或 Q）使 PᵀAP = D 為對角矩陣」。
1. 解 det(A − λI) = 0，得到特徵值（對稱矩陣一定全是實數）。
2. 對每個 λ 解 (A − λI)x = 0，得到特徵空間的基底。
3. 不同 λ 的特徵向量自動垂直，不用處理；**同一個重根 λ** 的多個特徵向量若不垂直，在那個特徵空間裡做 Gram-Schmidt。
4. 每個向量除以長度。
5. 把單位特徵向量依序排成 P 的行，D 的對角線依**同樣順序**放對應的特徵值。檢查 PᵀP = I。

> **例題** A = [2 1 1; 1 2 1; 1 1 2]，求正交矩陣 P 使 PᵀAP = D。
> 1. 令 μ = 2 − λ：det(A − λI) = μ³ − 3μ + 2 = (μ − 1)²(μ + 2)。μ = 1 ⇒ λ = 1（二重根）；μ = −2 ⇒ λ = 4。檢查：1 + 1 + 4 = 6 = trace，1·1·4 = 4 = det。
> 2. λ = 4：A − 4I = [−2 1 1; 1 −2 1; 1 1 −2]，解得 x₁ = (1, 1, 1)。
> 3. λ = 1：A − I = [1 1 1; 1 1 1; 1 1 1]，只剩一個方程 x + y + z = 0，特徵空間是平面，基底例如 v₂ = (1, −1, 0)、v₃ = (1, 0, −1)。
> 4. v₂、v₃ 不垂直（v₂·v₃ = 1），做 Gram-Schmidt：v₃′ = v₃ − (v₃·v₂ / v₂·v₂)v₂ = (1, 0, −1) − ½(1, −1, 0) = (1/2, 1/2, −1)，乘 2 得 (1, 1, −2)。檢查 (1, 1, −2)·(1, −1, 0) = 0，且 A(1, 1, −2) = (1, 1, −2)。
> 5. 單位化：q₁ = (1, 1, 1)/√3、q₂ = (1, −1, 0)/√2、q₃ = (1, 1, −2)/√6。
> 6. P = [q₁ q₂ q₃]，D = diag(4, 1, 1)，PᵀAP = D。

```
 P = [1/√3   1/√2   1/√6
      1/√3  −1/√2   1/√6
      1/√3    0    −2/√6]
```

> **陷阱** D 對角線的順序要和 P 的行一一對應；特徵向量忘了單位化，P 就不是正交矩陣（PᵀP ≠ I），也不能用 Pᵀ 代替 P⁻¹。

### 每個對稱矩陣都是投影的組合
把 A = QΛQᵀ 用「行 × 列」展開：ΛQᵀ 把 Qᵀ 的每一列乘上對應的 λ，再用每個行 qᵢ 乘對應的列 λᵢqᵢᵀ，加起來：

```
 A = λ₁q₁q₁ᵀ + λ₂q₂q₂ᵀ + … + λₙqₙqₙᵀ      （譜分解 spectral decomposition）
```

q 是單位向量，**qqᵀ 就是投影到 q 那條線的投影矩陣**（投影公式 aaᵀ/aᵀa，長度 1 所以不用除）：對稱，而且 (qqᵀ)(qqᵀ) = q(qᵀq)qᵀ = qqᵀ。

> **例題** A = [2 1; 1 2]：q₁q₁ᵀ = [½ ½; ½ ½]，q₂q₂ᵀ = [½ −½; −½ ½]，3·q₁q₁ᵀ + 1·q₂q₂ᵀ = [2 1; 1 2]。拿 x = (1, 0)：投影到 q₁ 得 (½, ½)，投影到 q₂ 得 (½, −½)，各乘 3、1 相加：(3/2 + 1/2, 3/2 − 1/2) = (2, 1) = Ax。

> **觀念** 每個對稱矩陣 = 互相垂直的投影矩陣的組合，係數是特徵值。

## 證明：對稱矩陣的特徵值是實數
先假設 λ、x 可能是複數，目標是證明 λ 在實數軸上。取共軛（conjugate）就是把每個 i 換成 −i：a + ib → a − ib。

1. 從 Ax = λx 出發。
2. 整條取共軛：Āx̄ = λ̄x̄。A 是實數矩陣，Ā = A，所以 Ax̄ = λ̄x̄。（順便得到：實矩陣的複數特徵值一定 λ、λ̄ 成對出現，例如旋轉矩陣的 ±i。）
3. 轉置：x̄ᵀAᵀ = λ̄x̄ᵀ。用**對稱** Aᵀ = A：x̄ᵀA = λ̄x̄ᵀ。（整個證明只有這裡用到對稱。）
4. 第 1 式左乘 x̄ᵀ：x̄ᵀAx = λ x̄ᵀx。第 3 式右乘 x：x̄ᵀAx = λ̄ x̄ᵀx。
5. 左邊相同，所以 λ x̄ᵀx = λ̄ x̄ᵀx。x̄ᵀx > 0（見下），約掉得 **λ = λ̄**：等於自己共軛的數虛部為 0，是實數。

> **陷阱** 第 4 步一定要「一條左乘 x̄ᵀ、另一條右乘 x」，兩條都用同一種乘法會得到相同的式子，證不出東西。

### 垂直的特徵向量（不同特徵值）
若 Ax = λ₁x、Ay = λ₂y、λ₁ ≠ λ₂：λ₁yᵀx = yᵀAx = (Aᵀy)ᵀx = (Ay)ᵀx = λ₂yᵀx，所以 (λ₁ − λ₂)yᵀx = 0，yᵀx = 0。這也用到 Aᵀ = A。

### x̄ᵀx：複數向量的長度平方
x̄ᵀx = x̄₁x₁ + … + x̄ₙxₙ。每一項是 (a − ib)(a + ib) = a² + b² + iab − iab = a² + b² ≥ 0，虛部消失（i·(−i) = 1）。所以 x̄ᵀx > 0（零向量除外），可以約掉。

> **例題** x = (3 + 4i, 1 − 2i)。x̄ᵀ = (3 − 4i, 1 + 2i)。x̄ᵀx = (3 − 4i)(3 + 4i) + (1 + 2i)(1 − 2i) = 25 + 5 = 30 > 0。

> **陷阱** 複數向量不能用 xᵀx 當長度：上例 xᵀx = (3 + 4i)² + (1 − 2i)² = (−7 + 24i) + (−3 − 4i) = −10 + 20i，連實數都不是。實數時才是 xᵀx = x₁² + … （例 (3, 4)：9 + 16 = 25 = 5²）。

### 「好矩陣」：實數要對稱，複數要 Āᵀ = A
「好矩陣」= 特徵值是實數、特徵向量互相垂直。實數矩陣裡就是對稱矩陣。如果 A 本身是複數，取共軛時 A 也變 Ā，證明要成立就需要 **Āᵀ = A**（轉置再取共軛等於自己）。例：[2 3+i; 3−i 5]。實際應用 99% 是實數矩陣，這時對稱就是關鍵。

> **陷阱** 複數矩陣只滿足 Aᵀ = A 不夠，要 Āᵀ = A 才保證特徵值是實數。

## 複數向量與複數矩陣

### 為什麼要學複數
就算矩陣全是實數，特徵值也可能是複數（旋轉 [0 −1; 1 0]：λ² + 1 = 0、λ = ±i）。向量、矩陣變成複數時，長度、內積都要重新定義。

### 長度與內積：zᴴz、yᴴx
z = (z₁, …, zₙ) ∈ Cⁿ（n 維複數空間）。

- 直接用 zᵀz 會出事：z = (1, i) 時 zᵀz = 1·1 + i·i = 1 − 1 = 0，但 z 不是零向量。
- 正確：**‖z‖² = z̄ᵀz = |z₁|² + |z₂|² + … + |zₙ|²**，每項 ≥ 0。z = (1, i)：共軛 (1, −i)，1 + (−i)(i) = 1 + 1 = 2，長度 √2。
- 「轉置 + 取共軛」記成 H：**zᴴ = z̄ᵀ**（念作 z Hermitian，紀念 Hermite）。
- 內積改成 **yᴴx**，通常是複數。例：y = (1, 1)、x = (1, i)，yᴴx = 1 + i。y = x = z 時就是長度平方 zᴴz。

> **陷阱** yᴴx 和 xᴴy 互為共軛，不一定相等（順序有差）。

### Hermitian 矩陣與 unitary 矩陣
複數版的對稱：**Aᴴ = A**（Āᵀ = A），叫 **Hermitian 矩陣**。對角線轉置後在原位、取共軛後也不能變，所以必須是實數；右上放 3 + i，翻到左下就要是 3 − i：

```
 A = [ 2    3+i
      3−i    5 ]
```

> **例題** 這個 A 的特徵值：trace = 7，det = 10 − (3 + i)(3 − i) = 10 − 10 = 0，所以 λ = 7、0，都是實數。λ = 7：A(3 + i, 5) = (2(3 + i) + 5(3 + i), (3 − i)(3 + i) + 25) = (7(3 + i), 35) = 7·(3 + i, 5)。λ = 0：A(3 + i, −2) = (2(3 + i) − 2(3 + i), 10 − 10) = 0。垂直要用共軛內積：(3 + i, −2)ᴴ(3 + i, 5) = (3 − i)(3 + i) + (−2)(5) = 10 − 10 = 0。長度：|3 + i|² + 25 = 35、|3 + i|² + 4 = 14，除以 √35、√14 後排成 Q，QᴴQ = I。

複數空間的「字典」：

| 實數 | 複數 |
|---|---|
| Rⁿ | Cⁿ |
| xᵀy | xᴴy |
| xᵀx = ‖x‖² | xᴴx = ‖x‖² |
| 對稱 Aᵀ = A | Hermitian Aᴴ = A |
| 正交矩陣 QᵀQ = I | unitary 矩陣 QᴴQ = I |

標準正交基底的條件改成 qᵢᴴqⱼ = 0（i ≠ j）、qᵢᴴqᵢ = 1。**Unitary 矩陣**是複數版的正交矩陣：方陣、行互相垂直且長度 1（內積記得取共軛），Q⁻¹ = Qᴴ。

> **觀念** 正規矩陣（normal matrix）：AAᴴ = AᴴA（實數時 AAᵀ = AᵀA）。複數版的譜定理是「A 能被 unitary 矩陣對角化 ⇔ A 是正規矩陣」。對稱、Hermitian、反對稱、正交、unitary 矩陣都是正規的；但**正規不一定對稱**，例如旋轉 [0 −1; 1 0]：AAᵀ = AᵀA = I，是正規的，特徵值卻是 ±i。只有在實數範圍內用正交矩陣對角化（特徵值全實數）才需要對稱。

## Fourier 矩陣與 FFT

### Fourier 矩陣
最有名的複數矩陣，行互相正交，Fourier 轉換就是乘上它。編號從 0 開始（電機系的習慣）：行、列編號都是 0, 1, …, n − 1。

- 第 0 行全是 1；第 1 行是 1, w, w², …, wⁿ⁻¹；第 2 行是 1, w², w⁴, …。
- 一句話：**(F)ⱼₖ = wʲᵏ**（第 j 列第 k 行，j、k 從 0 數）。例如第 2 列第 3 行是 w⁶。
- 沿列看和沿行看一樣，F 是對稱的（Fᵀ = F）；但數字是複數，它**不是** Hermitian。
- w 滿足 **wⁿ = 1**：w = e^{i2π/n} = cos(2π/n) + i sin(2π/n)，長度 1、角度 2π/n。

> **陷阱** 從 0 開始編號，元素是 wʲᵏ，不是 w^{(j−1)(k−1)}。

### 單位根
w 在單位圓上。取次方用 e^{iθ} 形式最清楚：取 10 次方，角度直接乘 10，得 e^{i·20π/n}。

- n = 6：w = e^{2πi/6}，角度 60°。w² 在 120°（長度 1 的平方還是 1，留在單位圓上，角度加倍），w³ 在 180°，w⁴ 在 240°，w⁵ 在 300°，w⁶ 轉一整圈回到 1。這六個點是 1 的六個「六次方根」，連成正六邊形；w 叫 primitive root。
- n = 4：w = e^{2πi/4} = e^{iπ/2} = i。次方依序 i、i² = −1、i³ = −i、i⁴ = 1（上、左、下、右）。

### F₄
指數 = 列號 × 行號，右下角是 i⁹ = i：

```
      [1   1    1    1        [1  1   1   1
 F₄ =  1   i    i²   i³    =   1  i  −1  −i
       1   i²   i⁴   i⁶        1 −1   1  −1
       1   i³   i⁶   i⁹]       1 −i  −1   i]
```

四點 Fourier 轉換：x 乘上 F₄；逆轉換乘 F₄⁻¹。

> **例題** 檢查 F₄ 的行互相正交。
> 1. 第 0 行 · 第 1 行：1 + i − 1 − i = 0。第 0 行 · 第 2 行：1 − 1 + 1 − 1 = 0。
> 2. 第 1 行 (1, i, −1, −i) 和第 3 行 (1, −i, −1, i)：若直接相乘，1 + i(−i) + 1 + (−i)(i) = 1 + 1 + 1 + 1 = 4，看似不正交！
> 3. 正確做法要先取共軛：第 1 行共軛是 (1, −i, −1, i)，乘第 3 行：1·1 + (−i)(−i) + (−1)(−1) + i·i = 1 − 1 + 1 − 1 = 0，正交。
> 4. 每行是四個模長 1 的數，長度平方 4、長度 2。除以 2 後行是 orthonormal：(½F₄)ᴴ(½F₄) = I，所以 ½F₄ 是 unitary，反矩陣就是共軛轉置：F₄⁻¹ = ¼ F̄₄ᵀ。

> **陷阱** 檢查複數向量垂直時忘了取共軛，會把正交的兩行誤判成不正交。

### FFT：把 F₆₄ 拆成兩個 F₃₂
一般 n×n 的滿矩陣乘向量要 n² 次乘法。FFT（fast Fourier transform，快速 Fourier 轉換）利用 Fourier 矩陣的特殊結構，把它拆成好幾個「有很多 0」的因子。

關鍵：大小 n 和一半大小的 Fourier 矩陣有關係。w₆₄ 轉 1/64 圈，平方後角度加倍，正好是 w₃₂：**(w₆₄)² = w₃₂**。於是

```
 F₆₄ = [ I   D ] [ F₃₂   0  ] P
       [ I  −D ] [  0   F₃₂ ]
```

- P：排列矩陣，把 x 的偶數號分量 x₀, x₂, x₄, … 排前面，奇數號 x₁, x₃, … 排後面。只是重新排隊，不用乘法。
- 中間：兩份 F₃₂ 放在對角，另外兩塊是 0，乘法少一半。
- 左邊：D = diag(1, w, w², …, w³¹)（w = w₆₄），偶、奇兩部分各做完 F₃₂ 後用它拼回去；乘對角矩陣只要 32 次乘法，I 不用乘。
- 工作量：64² = 4096 → 2·32² + 32 = 2080，差不多砍半。

小例子 n = 4：F₄ = [I D; I −D][F₂ 0; 0 F₂]P，F₂ = [1 1; 1 −1]，D = diag(1, i)，P 把 (x₀, x₁, x₂, x₃) 排成 (x₀, x₂, x₁, x₃)；乘出來確實是 F₄。

### 遞迴：½ n log₂ n
同一招遞迴（recursion）下去：每個 F₃₂ 拆成兩個 F₁₆ 加一個大小 32 的修正和排列。兩次排列合起來把分量分成「偶偶」（0, 4, 8, 12, …）、「偶奇」（2, 6, 10, 14, …）、「奇偶」、「奇奇」四組。每個 32² = 1024 換成 2·16² + 16 = 528。

一直拆到 2 點、1 點的轉換：右邊堆的都是排列（幾乎不花時間），左邊堆的是 [I D; I −D] 修正因子，每個 n/2 次乘法。64 → 32 → 16 → 8 → 4 → 2 → 1 共 log₂ 64 = 6 層，總共 6 × 32 = 192 次，取代 4096。

> **重點** FFT 的乘法次數是 **½ n log₂ n**。n = 1024 = 2¹⁰：直接乘 n² = 1,048,576 次；FFT 只要 ½ × 1024 × 10 = 5120 次，約快 200 倍。

## Pivots 的正負號 = 特徵值的正負號
知道特徵值是實數後，下一個問題：正還是負？這決定 du/dt = Au 穩不穩定。50×50 的對稱矩陣，解 det(A − λI) = 0 這個 50 次多項式在數值上非常不穩定；但消去法求 50 個 pivots 又快又穩。

> **重點** 對稱矩陣：**正 pivots 的個數 = 正特徵值的個數**（負的也一樣）。pivots 不等於特徵值，但正負號的個數相同。

> **例題** A = [1 2; 2 1]：pivots 1、1 − 4 = −3（一正一負）；特徵值 3、−1（一正一負），個數一樣。兩者乘積都是 det = −3。

**移位技巧**：A − cI 的特徵值是 λ − c。數 A − cI 的負 pivots，就知道 A 有幾個特徵值比 c 小。例：上面的 A，A − 2I = [−1 2; 2 −1]，pivots −1、−1 + 4 = 3，一個負 pivot ⇒ A 恰有一個特徵值小於 2（就是 −1）。

另一個事實：pivots 的乘積 = 特徵值的乘積 = det（沒有列交換時）。但乘積只是一個數，正負號的事實告訴我們每一個的符號。

> **陷阱** 這個「正負號個數相同」只對對稱矩陣成立。

## 正定矩陣

### 定義與入門例子
說到正定（positive definite），一定先假設矩陣對稱（特徵值是實數）。對稱矩陣是「好」的，正定矩陣是其中「最棒」的：**所有特徵值 > 0**，等價地 **所有 pivots > 0**。

> **例題** A = [5 2; 2 3]。
> 1. 第一個 pivot 是 5。
> 2. pivots 的乘積 = det = 5×3 − 2×2 = 11，所以第二個 pivot = 11/5。兩個都正 ⇒ 正定。
> 3. 對照特徵值：λ² − 8λ + 11 = 0（8 = trace、11 = det），λ = 4 ± √5 ≈ 6.24、1.76，都正，一致；但算起來不如 pivots 漂亮。

### 行列式測試要看每一個左上子行列式
正定 ⇒ 特徵值全正 ⇒ det = 乘積 > 0。**但反過來不成立。**

> **陷阱** B = [−1 0; 0 −3]：det = 3 > 0，可是 pivots、特徵值都是 −1、−3，全負（負定）。負負得正騙了行列式。

正確的測試：從左上角長出來的 1×1、2×2、…、n×n 子矩陣，n 個**左上子行列式**（leading principal minors）**全部 > 0**。
- [5 2; 2 3]：5 > 0、11 > 0，通過。
- [−1 0; 0 −3]：第一個就是 −1 < 0，不通過。

### 2×2 正定的四種測試
A = [a b; b c]（對稱）正定 ⇔ 下面任一條：
1. 特徵值 λ₁ > 0、λ₂ > 0。
2. 左上子行列式：a > 0 且 ac − b² > 0。
3. pivots：a > 0 且 (ac − b²)/a > 0（pivots 乘積 = det）。
4. **xᵀAx > 0 對所有 x ≠ 0**。

大部分書以 ④ 為正定的定義，①②③ 是檢查的方法。n×n 時同樣成立：特徵值全正、n 個左上子行列式全正、n 個 pivots 全正、xᵀAx > 0。

> **重點** 對稱矩陣的 pivots（第一週）、行列式（學期中）、特徵值（最近）在正定這裡會合，三種測試給同樣答案。前 k 個 pivots 的乘積 = 第 k 個左上子行列式。

### 例題：[2 6; 6 c]，c 要多大才正定
> **例題** 求 c 使 [2 6; 6 c] 正定。
> 1. 第一個 pivot 2 > 0，這關一定過。
> 2. det = 2c − 36 > 0 ⇒ **c > 18**。例 c = 19：det = 38 − 36 = 2 > 0，正定。
> 3. c = 18 是邊界：det = 0，矩陣奇異，有一個特徵值 0；另一個看 trace：2 + 18 = 20。特徵值 0、20 都 ≥ 0，叫**半正定**（positive semi-definite）。
> 4. c = 18 的 pivots：第一個 2，第二個 18 − 3×6 = 0，沒有第二個 pivot。因為第二列 (6, 18) 是第一列 (2, 6) 的 3 倍，rank 1。

> **陷阱** 半正定（所有 λ ≥ 0、有 λ = 0）不算正定；pivot 測試會「少一個 pivot」。類似地，負定（negative definite）是所有 λ < 0；有正有負叫不定（indefinite）。

## 二次型 xᵀAx

### 展開成 ax² + 2bxy + cy²
> **例題** A = [2 6; 6 18]，x = (x₁, x₂)。
> 1. Ax = (2x₁ + 6x₂, 6x₁ + 18x₂)。
> 2. xᵀ(Ax) = x₁(2x₁ + 6x₂) + x₂(6x₁ + 18x₂) = 2x₁² + 6x₁x₂ + 6x₁x₂ + 18x₂² = **2x₁² + 12x₁x₂ + 18x₂²**。左上的 2 給 x₁²，兩個非對角的 6 各貢獻一次交叉項。

一般 [a b; b c] 給出 **ax² + 2bxy + cy²**（交叉項係數是 2b），叫**二次型**（quadratic form）：Ax 是一次的，多乘一個 xᵀ 就全是二次項，沒有一次項和常數。

c = 18 差一點沒過正定：x = (3, −1) 時 2·9 + 12·(−3) + 18·1 = 18 − 36 + 18 = 0，不是 > 0。

### c = 7：馬鞍面
> **例題** A = [2 6; 6 7]。
> 1. det = 14 − 36 = −22 < 0，pivots 2、−11（乘積 −22），一個負 pivot ⇒ 一正一負特徵值，不是正定。
> 2. f = 2x² + 12xy + 7y²。試 (1, −1)：平方項都正但交叉項變負，2 − 12 + 7 = −3 < 0。
> 3. 畫 z = f(x, y)：一定過原點；沿 x 軸 f = 2x² 往上；沿 y 軸 f = 7y² 往上；沿 x = y 是 2 + 12 + 7 = 21 > 0 往上；但沿 x = −y 往下掉。

有些方向往上、有些往下，這叫**馬鞍面**（saddle），原點是**鞍點**（saddle point）：某些方向是最大、某些方向是最小，不是真正的最小值。最該看的是特徵向量方向：沿正特徵值方向往上彎，沿負特徵值方向往下彎。

> **陷阱** 沿 x 軸、y 軸都往上，不代表是最小值；必須所有方向都往上。

### c = 20：碗形與最小值
> **例題** A = [2 6; 6 20]。
> 1. pivots 2、20 − 3×6 = 2，都正。
> 2. 不求特徵值也知道正負：λ₁λ₂ = det = 40 − 36 = 4 > 0，同號；λ₁ + λ₂ = trace = 22 > 0，所以都正。
> 3. f = 2x² + 12xy + 20y²：純平方 2x²、20y² 夠大，壓得過可正可負的 12xy。

圖形是**碗**（bowl），從原點往任何方向都往上，放在碗壁上的球會滾到原點：原點是最小值。原點的切平面是水平的（一階偏導數都帶著 x 或 y，所以是 0），但**一階導數 = 0 只代表平**，可能是最大也可能是最小；決定的是二階導數。單變數要 f″ > 0（曲線往上彎）；多變數時「f″ > 0」翻譯成「二階導數矩陣正定」。

> **觀念** 一個數是正的，翻譯成矩陣就是正定。

### 配方：平方和
麻煩全來自 xy 項，把它塞進一個平方裡（配方 completing the square）：

```
 2x² + 12xy + 20y²
 = 2(x + 3y)² + 2y²          （2(x + 3y)² = 2x² + 12xy + 18y²，還差 2y²）
```

兩個平方、係數都正，不可能為負；只有 x + 3y = 0 且 y = 0（原點）時為 0。18 又出現了：正是剛才的邊界。

- c = 7：2(x + 3y)² + (7 − 18)y² = 2(x + 3y)² − 11y²，有負號 ⇒ 馬鞍。
- c = 18：2(x + 3y)²，沿 x = −3y 這條線 f = 0，是一條平平的谷底（槽）。
- c = 20：碗。

用水平面在高度 1 切碗：切口 f = 1 是**橢圓**；切馬鞍面得到**雙曲線**（f = 正數一對、f = 負數另一對）。例如 x² − y² = 1 這種雙曲線來自有正有負特徵值的矩陣。

### 配方 = 消去法
配方結果 2(x + 3y)² + 2y² 裡的三個數字：

```
 A = [2 6; 6 20]
 第一個 pivot 2；乘數 ℓ₂₁ = 6/2 = 3；第二個 pivot 20 − 3×6 = 2
 U = [2 6; 0 2]，L = [1 0; 3 1]，A = LU
```

> **重點** 配方就是消去法：**pivots 在括號外、乘數在括號裡**。消去法對 n×n 都能做，所以配方也能推廣到 n 個變數。一條線串起來：pivots 全正 → 平方和係數全正 → f 處處 > 0 → 圖形往上 → 原點是最小值。

### 二階導數矩陣（Hessian）要正定
兩個變數的二階導數組成 2×2 矩陣：

```
 H = [ fxx  fxy
       fyx  fyy ]
```

- 先對 x 再對 y 微分，和先 y 再 x 一樣：fxy = fyx，所以 H 對稱。
- 最小值：一階導數都要是 0；fxx > 0、fyy > 0（沿 x、y 都往上彎）還不夠，它們要大到壓過交叉的 fxy：**H 正定**。
- 微積分的兩變數條件 **fxx·fyy > fxy²** 就是 2×2 的行列式測試。例：f = 2x² + 12xy + 20y² 的 H = [4 12; 12 40]（剛好是 2A），4×40 = 160 > 144 = 12²。
- n 個變數：可以做消去法、看特徵值，或寫成 n 個平方的和。

## 3×3 例子與橢球

> **例題** A = [2 −1 0; −1 2 −1; 0 −1 2]。
> 1. 左上子行列式：2；2×2 − (−1)(−1) = 3；整個 det = 4。這類矩陣的行列式是 2、3、4、5…（考試時最快的方法）。
> 2. pivots：2、3/2、4/3，全正（前 k 個 pivots 乘積 = 第 k 個左上行列式：2、2 × 3/2 = 3、3 × 4/3 = 4）。
> 3. 所以三個特徵值全正，不必解三次方程。實際上是 2 − √2、2、2 + √2。檢查：和 = 6 = trace；積 = (2 − √2)(2 + √2)·2 = (4 − 2)·2 = 4 = det。
> 4. 二次型：xᵀAx = 2x₁² + 2x₂² + 2x₃² − 2x₁x₂ − 2x₂x₃（(1, 2)、(2, 1) 的兩個 −1 合成 −2x₁x₂；(1, 3) 是 0，沒有 x₁x₃）。
> 5. 配方：xᵀAx = 2(x₁ − ½x₂)² + (3/2)(x₂ − ⅔x₃)² + (4/3)x₃²。括號外正是三個 pivots，括號裡是乘數 −½、−⅔。

它的圖形是 4 維空間裡往上的碗（三個變數加上高度），畫不出來。在高度 1 切開：**xᵀAx = 1 是一顆橢球**（ellipsoid），像一顆歪歪的橄欖球，有一個中心和三個主方向。
- 球：所有方向一樣，對應 I，三個特徵值相等。
- 美式足球：一個方向長、另兩個一樣，有兩個特徵值相等（例 diag(1, 4, 4)）。
- 本例三個特徵值都不同：長軸、中軸、短軸。

> **重點** 主軸定理：A = QΛQᵀ，**主軸方向 = 特徵向量（Q）**，**半軸長 = 1/√λ（Λ）**。驗證：沿單位特徵向量 q 走到 x = q/√λ，xᵀAx = (1/λ)qᵀAq = (1/λ)·λ = 1。λ 越大，那個方向越短。

> **陷阱** 半軸長是 1/√λ，不是 1/λ。

### 換變數：二次型的主軸化
令 x = Qy（y 是特徵向量座標），xᵀAx = yᵀQᵀAQy = yᵀΛy = λ₁y₁² + λ₂y₂² + … + λₙyₙ²，交叉項全部消失。

> **例題** 2x² + 2xy + 2y² = 1 是什麼圖形？A = [2 1; 1 2]，λ = 3、1，q₁ = (1, 1)/√2、q₂ = (1, −1)/√2。新座標下 3y₁² + y₂² = 1：橢圓，沿 (1, 1) 方向半軸 1/√3、沿 (1, −1) 方向半軸 1。

## 補充：正定矩陣的其他性質
- A 正定 ⇒ A⁻¹ 正定（特徵值 1/λ > 0）。
- A、B 正定 ⇒ A + B 正定：xᵀ(A + B)x = xᵀAx + xᵀBx > 0。
- 任何 m×n 的 A，AᵀA 對稱且 xᵀAᵀAx = ‖Ax‖² ≥ 0；A 的 columns 獨立（rank n）時 AᵀA 正定。最小平方的 AᵀA（例如 [3 6; 6 14]）就是正定的。

## 重點整理
- 實對稱 A = Aᵀ：特徵值全實數；不同 λ 的特徵向量垂直；重根時可選成垂直；永遠有 n 個。
- 譜定理：A = QΛQᵀ，Q⁻¹ = Qᵀ；實矩陣可正交對角化 ⇔ 對稱。
- 正交對角化：求 λ → 求特徵向量 → 重根做 Gram-Schmidt → 單位化 → P、D 順序對應。
- 譜分解 A = Σ λᵢqᵢqᵢᵀ，qqᵀ 是投影矩陣。
- 證明實特徵值：一條左乘 x̄ᵀ、一條右乘 x，得 λ = λ̄；x̄ᵀx = Σ|xᵢ|² > 0。
- 複數：‖z‖² = zᴴz、內積 yᴴx；Hermitian Aᴴ = A（實特徵值、垂直特徵向量）；unitary QᴴQ = I。
- 正規矩陣 AAᴴ = AᴴA；對稱 ⇒ 正規，反之不然（旋轉矩陣）。
- Fourier：(F)ⱼₖ = wʲᵏ、w = e^{2πi/n}、wⁿ = 1；F₄ 用 w = i；½F₄ unitary；FFT ½ n log₂ n。
- 對稱矩陣：正 pivots 個數 = 正特徵值個數；A − cI 的負 pivots 數 = 小於 c 的特徵值數。
- 正定 ⇔ 所有 λ > 0 ⇔ 所有左上子行列式 > 0 ⇔ 所有 pivots > 0 ⇔ xᵀAx > 0（x ≠ 0）。
- 只看 det > 0 不夠（[−1 0; 0 −3]）；[2 6; 6 c] 正定 ⇔ c > 18，c = 18 半正定。
- 二次型 [a b; b c] ↔ ax² + 2bxy + cy²；配方 = 消去法，pivots 在外、乘數在內。
- 碗（正定，最小值）、馬鞍（不定，鞍點）、槽（半正定）；切口：橢圓 vs. 雙曲線。
- 最小值：一階導數 0 且 Hessian 正定；2×2 即 fxx > 0、fxx·fyy > fxy²。
- xᵀAx = 1：橢球，主軸沿特徵向量，半軸長 1/√λ；x = Qy ⇒ Σλᵢyᵢ²。
