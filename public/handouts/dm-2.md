# 證明方法

這一章把邏輯變成能用的證明工具：先補上述詞（predicate）與量詞，學會什麼樣的推論才合法，再練直接證法、逆否證法、矛盾證法、列舉法；接著拿數論練手（整除、同餘、Euclid 演算法、模反元素、中國餘數定理、費馬小定理，一路走到 RSA），最後是數學歸納法、強歸納法、良序原理、遞迴定義與遞迴演算法，以及函數的基本定義。考試最常考：量詞的否定與順序、推論規則與謬誤、各種證明法的格式、強歸納法的起始條件、CRT 的計算。

## 述詞與量詞

### 述詞：把主詞挖成變數
命題邏輯只處理「1 + 1 = 2」這種可判斷真假的句子。**述詞邏輯**（predicate logic）再進一步。

看「Alice is a girl」：Alice 是主詞（在講誰），is a girl 在描述她，這段就是**述詞**（predicate）。John is a girl、Amy is a girl 這些句子只差主詞，乾脆把主詞挖成空格：**P(x)：x is a girl**。這就像函式 f(x)。

- x 還沒決定時，P(x) 說的是「某個不知道的人是女生」，沒辦法判斷真假，所以 **P(x) 本身不是命題**。
- 把 x 換成 Andy，得到 P(Andy)：Andy is a girl，這才是命題（Andy 是男生，為假）。
- P 的函式值是一個命題，所以 P 叫 **propositional function**（命題函式）。

變數不限於主詞，也可以有好幾個：
- Q(x, y, z)：x + y = z。代 x = 1、y = 2、z = 3 得 1 + 2 = 3，是真命題。
- P(x)：x > 3。P(2)：2 > 3 為假；P(4)：4 > 3 為真。同一個 P 代不同值，真假不同。
- 有 n 個變數的叫 **n-ary predicate**，(x₁, …, xₙ) 叫 **n-tuple**。

> **陷阱** P(x) 不是命題：要代入 x 的值，或加上量詞，才能判斷真假。

### 全稱量詞 ∀ 與論域
「班上同學是不是每個人都高於 120 公分？」設 P(x)：x 的身高大於 120，把班上同學看成一個集合，寫成 **∀x P(x)**（∀ 是倒過來的 A，All）。正式名稱 universal quantification，讀作 for all x。

- 要它為真：每個人都量過，全部超過 120。
- 只要有一個人沒超過（例如 115 公分），整句就假。
- 「所有人」其實有個範圍：只看班上。這個範圍叫 **domain**（論域，universe of discourse）。範圍擴大到隔壁班，隔壁有人 112 公分，同一句話就變成假的。所以量詞一定要先講清楚 domain。

**∀ 就是一長串 AND**：P(x)：英文字 x 以 b 開頭，domain U = {lily, apple, banana, cherry}。

∀x ∈ U, P(x) ≡ P(lily) ∧ P(apple) ∧ P(banana) ∧ P(cherry)

只有 banana 是 b 開頭，AND 有一個假就假，答案 F。∀ 就像 ∑：∑ 是每項加起來，∀ 是每項 AND 起來。

再一題：P(x)：x + 1 > x，domain 是所有實數。任何實數加 1 都比原來大，∀x P(x) 為真。

### 存在量詞 ∃
「班上**有沒有**人超過 120？」只要找到一個就真。「班上有沒有百萬富翁？」一個、兩個、全部都是都算對，只有一個都沒有才錯。寫法 **∃x P(x)**（∃ 是左右翻轉的 E，Exist），意思是至少有一個 x 滿足 P(x)，叫 existential quantifier。

**∃ 就是一長串 OR**：∃x ∈ U, P(x) ≡ P(lily) ∨ P(apple) ∨ P(banana) ∨ P(cherry)。banana 是 b 開頭，所以為真。

| | 要說它真 | 要說它假 |
|---|---|---|
| ∀x P(x) | 每個 x 都要檢查 | 找到一個反例就夠 |
| ∃x P(x) | 找到一個就夠 | 要說明所有 x 都不成立 |

### 量詞的否定
把 domain 列成 x₁, …, xₙ：

```
∃x P(x)  = P(x₁) ∨ P(x₂) ∨ … ∨ P(xₙ)
¬∃x P(x) = ¬(P(x₁) ∨ … ∨ P(xₙ))
         = ¬P(x₁) ∧ … ∧ ¬P(xₙ)      De Morgan
         = ∀x ¬P(x)
```

同理 **¬∀x P(x) ≡ ∃x ¬P(x)**。白話：要說「不是所有人都超過 120」，只要找一個沒超過的人。

> **陷阱** 否定量詞時，∀ 和 ∃ 要互換、¬ 要搬到裡面，不能只在前面加個 ¬ 就算了。

> **例題** P(x)：x² > 10。分界在 √10 ≈ 3.16。三個 domain：U₁ = {1, 2, 3}、U₂ = {2, 3, 4}、U₃ = {4, 5, 6}。
> - ∀x ∈ U₁, P(x)：1、4、9 全都不大於 10，假。
> - ∀x ∈ U₂, P(x)：只有 4² = 16 > 10，2²、3² 不行，「所有」要全對，假。
> - ∀x ∈ U₃, P(x)：16、25、36 都大於 10，真。
> - ∃x ∈ U₂, P(x)：舉出 4 就夠，真。
> - ¬∃x ∈ U₂, P(x)：先蓋住 ¬，裡面為真，加上否定就是假。

> **例題** 寫出否定：
> - ∃x (x² > x) 的否定：¬∃x (x² > x) ≡ ∀x ¬(x² > x) ≡ **∀x (x² ≤ x)**。
> - ∃x (x² = 2) 的否定：∀x (x² ≠ 2)。原句真假看 domain：自然數裡沒有平方是 2 的數，原句假；實數裡 √2 和 −√2 都滿足，原句真。

> **陷阱** 「x² > x 不成立」是 x² ≤ x，等號一定要留，不是 x² < x。

### 唯一存在 ∃!
∃! 表示「剛好只有一個」（驚嘆號像 1）。用身高講：量過每個人，剛好只有一個人超過 120 才為真；有兩個人超過就假。

> **例題** ∃!x (x² = 2)：
> - domain 是自然數：一個都沒有，假。
> - 實數：√2、−√2 兩個，不唯一，假。
> - 正實數：只有 √2，真。
> 所以 ∃! 比 ∃ 嚴格：有兩個解時 ∃ 真、∃! 假。

### 把 domain 寫進式子
- ∀x ∈ U, P(x) 也可寫成 **∀x (x ∈ U → P(x))**。
- ∃x ∈ U, P(x) 也可寫成 **∃x (x ∈ U ∧ P(x))**。

一個配箭頭、一個配 AND，翻譯句子時很重要。

兩個都是 ∀（∀x ∀y P(x, y)）可以交換順序；兩個都是 ∃ 也可以。**∀ 和 ∃ 混在一起就不能交換**。

### 量詞的優先權與作用範圍
∀、∃ 的優先權非常高，像負號，比 ¬、∧、∨ 都高。
- ¬∀x P(x) 就是 ¬(∀x P(x))，括號可省。
- ∀x P(x) ∨ Q(x) 是 (∀x P(x)) ∨ Q(x)：∀ 只管到 P(x)。

為什麼不能用分配律把它「合」成 ∀x (P(x) ∨ Q(x))？展開 ∀x P(x) ∨ Q(x) = (P(x₁) ∧ … ∧ P(xₙ)) ∨ Q(x)，分配後是 (P(x₁) ∨ Q(x)) ∧ … ∧ (P(xₙ) ∨ Q(x))。x₁…xₙ 是確定的人，但 Q(x) 裡的 x 仍是不知道是誰的 x，不能寫回 ∀x (P(x) ∨ Q(x))。

> **比喻** 量詞像程式的迴圈：迴圈裡的 i 只在迴圈裡有效，迴圈外又用一個 i，那是另一個變數。∑ 的 i 也一樣。

### 自由變數與綁定
- 還沒指定、可以隨便換的變數叫 **free variable**（自由變數）。式子裡有自由變數就不能判斷真假。
- ∀x P(x) 說「把所有 x 拿來檢查」，這個把變數綁住的動作叫 **binding**，被綁住的叫 bound variable。
- ∀x P(x, y)：x 被綁住，y 仍是 free，不能判斷。
- ∀x ∃y P(x, y)：兩個都綁住了，是可以判斷真假的命題。

### 巢狀量詞：x 喜歡 y
L(x, y)：x 喜歡 y，x、y 都是教室裡的人。

| 式子 | 意思 |
|---|---|
| ∀x ∀y L(x, y) | 每個人都喜歡每個人（包括自己），像雙層迴圈全部配對都要成立 |
| ∃x ∃y L(x, y) | 有某個人喜歡某個人 |
| ∀x ∃y L(x, y) | 每個人都至少喜歡一個人，喜歡的對象可以不同 |
| ∃y ∀x L(x, y) | 有一個人被所有人喜歡（萬人迷，同一個 y） |
| ∀y ∃x L(x, y) | 每個人都至少被一個人喜歡 |
| ∃x ∀y L(x, y) | 有一個人喜歡所有人 |

讀法：從最靠近 L 的量詞往外讀。∀y ∃x L(x, y)：先讀「有人喜歡 y」，再說「對每個 y 都成立」。

> **比喻** 把 x 畫在左邊（A、B、C），y 畫在右邊（1 到 5），箭頭代表「喜歡」：
> - ∀x ∃y：左邊每個人都至少射出一條箭頭。
> - ∃y ∀x：右邊有一個人（例如 3 號）被左邊所有箭頭射中。
> - ∀y ∃x：右邊每個人都至少被射中一次。
> - ∃x ∀y：左邊有一個人（例如 B）射向右邊全部。

> **陷阱** ∀x ∃y L(x, y) 和 ∃y ∀x L(x, y) 完全不同：前者每人喜歡的人可以不同，後者是同一個人被大家喜歡。量詞混用時順序不能亂換。

### 等價推導與否定多層量詞
> **例題** 證明 ¬∀x (P(x) → Q(x)) ≡ ∃x (P(x) ∧ ¬Q(x))。∀x 管的是整個括號。
> ```
> ¬∀x (P(x) → Q(x))
> ≡ ∃x ¬(P(x) → Q(x))        量詞的 De Morgan
> ≡ ∃x ¬(¬P(x) ∨ Q(x))       p → q ≡ ¬p ∨ q
> ≡ ∃x (¬¬P(x) ∧ ¬Q(x))      De Morgan（括號別漏）
> ≡ ∃x (P(x) ∧ ¬Q(x))        Double negation
> ```

> **例題** 求 ∀x ∃y ∀z T(x, y, z) 的否定，¬ 要搬到最裡面。
> ```
> ¬∀x ∃y ∀z T(x,y,z)
> ≡ ∃x ¬∃y ∀z T(x,y,z)
> ≡ ∃x ∀y ¬∀z T(x,y,z)
> ≡ ∃x ∀y ∃z ¬T(x,y,z)
> ```
> ¬ 每穿過一個量詞，∀、∃ 就互換一次。

### 把句子翻成述詞邏輯
> **例題** 「班上所有學生都修過微積分。」設 C(x)：x 修過微積分。
> - domain 就是班上學生：∀x C(x)。
> - domain 是所有人，另設 S(x)：x 是班上學生：**∀x (S(x) → C(x))**。
> 寫成 ∀x (S(x) ∧ C(x)) 是錯的，意思變成「每個人都是班上學生而且修過微積分」。

> **例題** P(x)：x 是獅子，Q(x)：x 勇敢，R(x)：x 喝咖啡。
> 1. 所有獅子都勇敢：∀x (P(x) → Q(x))
> 2. 有些獅子不喝咖啡：∃x (P(x) ∧ ¬R(x))
> 3. 有些勇敢的動物不喝咖啡：∃x (Q(x) ∧ ¬R(x))

> **重點** 口訣：「所有」配箭頭，「有些」配 AND。

## 推論規則

### 怎樣的推論才合法
先看一段論述：「如果候選人 A 今天宣布參選，B 明年就不會當選。A 今天宣布參選了。所以 B 明年不會當選。」想攻擊它，有兩條路：說第一句 if-then 本身就錯，或說第二句其實沒發生。前提一錯，推論就垮。

所以討論「有效推論」時，**先假設前提都為真**，再問：為什麼前提對，結論就一定對？

一個推論分成前提 p₁, p₂, …, pₙ 和結論 q，寫法像直式：

```
p₁
p₂
…
pₙ
────
∴ q
```

「前提都成立」藏著「而且」，所以推論就是 (p₁ ∧ p₂ ∧ … ∧ pₙ) → q。

> **重點** 推論**有效**（valid），就是 (p₁ ∧ … ∧ pₙ) → q 是 tautology（恆真式）。

### 三段論與它的證明
**三段論**（hypothetical syllogism）：p → q，q → r，∴ p → r。

例：如果早上出太陽，我就騎腳踏車上學；如果騎車上學，就一定騎車回家。所以：如果今天出太陽，我今天一定騎車回家。

要證 ((p → q) ∧ (q → r)) → (p → r) 是 tautology。方法一：三個變數畫 8 列真值表，最後一欄全 T。方法二：等式化簡（一次不要做太多事）：

```
前提 (¬p ∨ q) ∧ (¬q ∨ r)
  = (¬p∧¬q) ∨ (¬p∧r) ∨ (q∧¬q) ∨ (q∧r)     分配律展開
  = (¬p∧¬q) ∨ (¬p∧r) ∨ (q∧r)              q∧¬q ≡ F，消掉
整句 ¬[前提] ∨ (¬p ∨ r)
  ¬[前提] = (p∨q) ∧ (p∨¬r) ∧ (¬q∨¬r)      De Morgan
  把 (¬p ∨ r) 用 ∨ 對 ∧ 的分配律分進每個括號：
  (p∨q∨¬p∨r) ∧ (p∨¬r∨¬p∨r) ∧ (¬q∨¬r∨¬p∨r)
  = T ∧ T ∧ T = T
```

第一個括號有 p、¬p，第二個有 p、¬p，第三個有 r、¬r，都是 T。只要公式沒套錯，最後一定能化到 T，路線好壞只影響長短。

證過一次，這個形式就是合法推論，以後可以直接套用，只要寫清楚每一步用哪一條。

### Modus ponens（肯定前件）
```
p
p → q
────
∴ q
```

證明 (p ∧ (p → q)) → q 是 tautology：

```
p ∧ (¬p ∨ q) ≡ (p∧¬p) ∨ (p∧q) ≡ p ∧ q
整句 ≡ ¬(p ∧ q) ∨ q ≡ ¬p ∨ ¬q ∨ q ≡ ¬p ∨ T ≡ T
```

### 推論規則一覽

| 名稱 | 前提 | 結論 | 直覺 |
|---|---|---|---|
| Modus ponens 肯定前件 | p，p → q | q | 前件成立，後件成立 |
| Modus tollens 否定後件 | ¬q，p → q | ¬p | p → q ≡ ¬q → ¬p |
| Hypothetical syllogism 三段論 | p → q，q → r | p → r | 中間跳過 |
| Disjunctive syllogism 選言三段論 | p ∨ q，¬p | q | 至少一個對，p 錯就是 q 對 |
| Addition 附加 | p | p ∨ q | p 對了，「p 或 q」當然對 |
| Simplification 簡化 | p ∧ q | p | 兩個都對，取一個 |
| Conjunction 合取 | p，q | p ∧ q | 兩個都對，合起來 |
| Resolution 消解 | p ∨ q，¬p ∨ r | q ∨ r | 見下 |

> **陷阱** modus tollens 是「否定後件」得到否定前件。不要和「否定前件」搞混，後者是謬誤。

### Resolution
要證 ((p ∨ q) ∧ (¬p ∨ r)) → (q ∨ r) 是 tautology。

硬證：箭頭換掉，前提展開得 (p∧r) ∨ (¬p∧q) ∨ (q∧r)（p∧¬p 是 F 不寫）；否定後得 (¬p∨¬r) ∧ (p∨¬q) ∧ (¬q∨¬r)；把 q ∨ r 分進每個括號，第一個有 r、¬r，第二、三個有 q、¬q，全是 T。

聰明證：這次反過來把 OR 換成箭頭。p ∨ q ≡ ¬q → p，¬p ∨ r ≡ p → r。套三段論得 ¬q → r，換回 OR 就是 q ∨ r。

直覺：兩個前提一個有 p、一個有 ¬p，兩者必一真一假。p 假時 p ∨ q 要成立，q 對；¬p 假時 ¬p ∨ r 要成立，r 對。所以 q、r 至少一個對。Resolution 在 AI 的自動推論很常用。

### 用規則判斷推論
> **例題** 「如果今天下雨，今天就不烤肉；如果今天不烤肉，明天就烤肉。所以今天下雨，明天就烤肉。」
> p：今天下雨，q：今天不烤肉，r：明天烤肉。前提 p → q、q → r，結論 p → r，正是三段論，推論有效。

> **例題** 前提：「你寄 email 給我，我就會寫完程式」「你沒寄 email，我就早點睡」「我早睡，醒來就精神很好」。結論：「如果我沒寫完程式，醒來會精神很好」。
> 步驟一：分出前提和結論。步驟二：基本命題設變數。
> p：你寄 email；q：我寫完程式；r：我早睡；s：我醒來精神很好。
> ```
> (1) p → q          前提
> (2) ¬p → r         前提
> (3) r → s          前提
> (4) ¬q → ¬p        (1) 的逆否
> (5) ¬q → r         (4)(2) 三段論
> (6) ¬q → s         (5)(3) 三段論，即結論
> ```
> 每一步都要寫出依據（等價或哪條規則）。

### 兩個常見謬誤
- **肯定後件的謬誤**（fallacy of affirming the conclusion）：「如果 A 宣布參選，我口袋就有一百塊。」我掏出一百塊，不能說 A 一定參選了。((p → q) ∧ q) → p 不是 tautology。
- **否定前件的謬誤**（fallacy of denying the hypothesis）：A 沒參選，我口袋就沒有一百塊嗎？不一定，可能本來就有。((p → q) ∧ ¬p) → ¬q 不是 tautology。

> **陷阱** 「結論對」不能推回「前提對」；「前件錯」不能推出「後件錯」。

### 有量詞時的推論
| 規則 | 用法 | 例子 |
|---|---|---|
| Universal instantiation | ∀x P(x) ∴ P(c) | 全班都穿外套，小明是班上的，所以小明穿外套 |
| Universal generalization | 對任意 c 證出 P(c) ∴ ∀x P(x) | 設 c 是任一同學（不指名），證出 c 有穿，就證了全班 |
| Existential instantiation | ∃x P(x) ∴ 對某個 c，P(c) | 至少一人穿外套，就設 c 是那個人往下推 |
| Existential generalization | P(c) ∴ ∃x P(x) | 小明有穿，所以班上存在有人穿 |

> **陷阱** Universal generalization 的 c 必須是「任意」的，一旦指定是誰就不算。

## 證明方法

### 名詞
- **proposition**：這裡指比較不重要的小定理，例如 1 + 1 = 2。
- **theorem**（定理）：能根據假設與已知說服人它為真的敘述。
- **proof**（證明）：說服人的那段推論過程。
- **axiom**（公理）：公認為真、無法用別的東西證明的基本假設，例如幾何的「平行線永不相交」。
- **lemma**（引理）：大定理的工具，把共同的小部分挑出來先證。
- **corollary**（系理）：定理證完馬上得到的小結果。證了 x + x = 2x，令 x = 1 得 1 + 1 = 2。
- **conjecture**（猜想）：大家相信、但還沒人證出對錯。例如費馬最後定理 1637 年提出，1994 年才被證明。

### 證 p → q 的幾種方法
p → q 唯一會錯的是 p 真、q 假，證明就是排除這種情況。

| 方法 | 做法 |
|---|---|
| 直接證法 direct proof | 假設 p 真，一路推出 q 真 |
| 逆否證法 proof by contraposition | 假設 ¬q，推出 ¬p |
| 矛盾證法 proof by contradiction | 假設 ¬q（或 p ∧ ¬q），推出矛盾 |
| 空證明 vacuous proof | p 永遠為假，所以 p → q 恆真 |
| 平凡證明 trivial proof | q 永遠為真，所以 p → q 恆真 |
| 列舉證法 proof by cases | 把 p 拆成幾個情況，逐一證 |

定義（證明裡隱含的前提，用到就拿出來）：
- n 是**偶數**：存在整數 k，n = 2k。
- n 是**奇數**：存在整數 k，n = 2k + 1。
- 整數不是偶數就是奇數，不會同時成立。

### 直接證法
> **例題** 證明：若 n 是奇數，則 n² 是奇數。
> 寫成 ∀n (P(n) → Q(n))。要證所有整數，所以只說「給一個奇數 n」，不指定是 3 還是 5。
> 由定義，存在整數 k 使 n = 2k + 1。
> n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1。
> 2k² + 2k 是整數，所以 n² 是奇數。∎

> **陷阱** 要證「對所有 n」，n 必須是任意的；只代 3、5 檢查不算證明。

> **例題** 證明：兩個有理數相加還是有理數。
> 有理數：能寫成 p/q，p、q 是整數，q ≠ 0（必要時可再假設 p、q 互質，因為分數可以約分）。
> 設 x = p/q、y = r/s（q、s ≠ 0）。x + y = (ps + rq)/(qs)。分子分母都是整數，且 qs ≠ 0，所以 x + y 是有理數。∎

> **陷阱** 兩個不同的數要用不同字母。都寫成 p/q，等於假設 x = y。

完全數（perfect number）是所有真因數加起來等於自己的數，例如 6 = 1 + 2 + 3，可以拿來練習直接證法。

### 逆否證法
直接從前面推不好算時，改證等價的 ¬q → ¬p。

> **例題** 若 3n + 2 是奇數，則 n 是奇數。
> 直接證：3n + 2 = 2k + 1 ⇒ n = (2k − 1)/3，很難說是不是整數。
> 改證：若 n 不是奇數（即偶數），則 3n + 2 不是奇數。設 n = 2k，3n + 2 = 6k + 2 = 2(3k + 1)，是偶數。∎

> **例題** 若 n² 是奇數，則 n 是奇數。
> 直接證要開根號，難處理。改證：n 是偶數 ⇒ n² 是偶數。n = 2k，n² = 4k² = 2(2k²)。∎
> 等價說法：**n² 是偶數 ⇒ n 是偶數**，下面證 √2 時會用到。

### 空證明與平凡證明
> **例題** P(n)：若 n > 1，則 n² > n。證 P(0)。
> 代入：若 0 > 1，則 0 > 0。若一直想證後面的 0 > 0，永遠證不出來（它本來就是錯的）。關鍵是前提 0 > 1 永遠不成立，所以 P(0) 為真。這是 **vacuous proof**。

> **例題** P(n)：若 a、b 是正整數且 a ≥ b，則 aⁿ ≥ bⁿ。證 P(0)。
> 結論 a⁰ ≥ b⁰ 即 1 ≥ 1，永遠成立（有等號），前面不必管。這是 **trivial proof**。

### 矛盾證法
從 ¬q 出發，推出永遠為假的 F。推論沒錯，所以「¬q → F」為真；箭頭為真、後面為假，前面就只能是假，所以 ¬q 為假，q 成立。做法：先假設結論錯，推到一半撞到矛盾，就說假設錯了。

逆否法其實也是矛盾法的一種：推到 ¬p，而本來就有 p，p ∧ ¬p 永遠為假。

> **例題** 證明 √2 是無理數。
> 1. 假設 √2 是有理數，√2 = p/q，q ≠ 0，**且 p、q 互質**（已約到最簡）。
> 2. √2·q = p，平方得 p² = 2q²，所以 p² 是偶數，因此 p 是偶數。
> 3. 設 p = 2k：4k² = 2q²，即 q² = 2k²，所以 q 也是偶數。
> 4. p、q 都有因數 2，與互質矛盾。所以 √2 是無理數。∎

> **陷阱** 「p、q 互質」這個假設一定要先寫，矛盾就是跟它衝突。

> **例題** 合成數 n 一定有一個質因數 ≤ √n。
> n 是合成數，n = ab，a、b 都不是 1 也不是 n。要證 a、b 至少一個 ≤ √n。
> 反證：假設**兩個都** > √n，則 ab > √n·√n = n，與 ab = n 矛盾。所以至少一個 ≤ √n，它的質因數也 ≤ √n。例：91 = 7 × 13，7 ≤ √91 ≈ 9.54。

> **例題** 質數有無窮多個。
> 反證：假設只有有限個 p₁, …, pₙ。令 N = p₁p₂…pₙ + 1。N 除以清單上任何質數都餘 1，但 N ≥ 2 總有質因數，這個質因數不在清單上，矛盾。

> **例題** 實數集合 ℝ 不可數（Cantor 對角線法）。
> 可數：能和 1、2、3、… 一一配對，像幫每個元素發號碼牌。可數集合的子集合也可數，所以只要找到一個不可數的子集合即可。
> 假設 (0, 1) 的實數可數，排成清單：
> ```
> r₁ = 0.d₁₁ d₁₂ d₁₃ …
> r₂ = 0.d₂₁ d₂₂ d₂₃ …
> r₃ = 0.d₃₁ d₃₂ d₃₃ …
> …
> ```
> 造 r = 0.e₁e₂e₃…：dᵢᵢ ≠ 4 時 eᵢ = 4，dᵢᵢ = 4 時 eᵢ = 5。例如 r₁ 第一位是 2，r 第一位放 4；r₂ 第二位是 4，r 第二位放 5。r 和每個 rᵢ 在第 i 位不同，不在清單上，矛盾。
> 只用 4、5 是為了避開 0.4999… = 0.5 這種一個數有兩種寫法的問題。

### 錯誤證明
> **例題** 「證明」1 = 2：
> 1. 令 a = b。
> 2. 兩邊乘 a：a² = ab。
> 3. 兩邊減 b²：a² − b² = ab − b²。
> 4. 因式分解：(a − b)(a + b) = b(a − b)。
> 5. 消去 a − b：a + b = b。**錯在這裡**：a = b，a − b = 0，不能除。
> 6. 2b = b，2 = 1。
> 消去律是「ab = ac **且 a ≠ 0**，才得 b = c」。證明只要一處錯，整個作廢。

> **例題** 「若 n 不是正數，則 n² 不是正數」的證明：「若 n 是正數，則 n² 是正數；現在 n 不是正數，所以 n² 不是正數。」這是 p → q、¬p ∴ ¬q，否定前件的謬誤。結論本身也是錯的：(−1)² = 1。

### 列舉證法
要證 (p₁ ∨ p₂ ∨ … ∨ pₙ) → q，它等價於 (p₁ → q) ∧ (p₂ → q) ∧ … ∧ (pₙ → q)。中間是 AND，**每個 case 都要證，一個都不能漏**。最常見是把整數分成奇數、偶數兩個 case。

> **例題** 證明 x² + 3y² = 8 沒有整數解。依 y 分 case：
> - y = 0：x² = 8，x = ±2√2，不是整數。
> - y = ±1：x² = 5，不是整數。
> - |y| ≥ 2：3y² ≥ 12，x² ≤ −4，不可能。
> 只寫 y = 0、1、≥ 2 是錯的，漏掉負數。y² 正負一樣，可說「不失一般性（without loss of generality）」同理。

## 數論基礎

### 整除
整數集合記作 ℤ。a ≠ 0 時，**a | b**（a 整除 b）表示存在整數 c 使 **b = a·c**。這時 a 是 b 的因數，b 是 a 的倍數。

- 3 | −12：−12 = 3 × (−4)。
- 3 ∤ 7：有餘數。
- b 是偶數 ⇔ 2 | b。0 = 2 × 0，所以 0 是偶數；−4 = 2 × (−2) 也是偶數。
- 0 = a × 0，所以 0 是任何非 0 整數的倍數。

> **陷阱** a | b 是一句有真假的敘述，不是一個數，不要和分數 a/b 混。

**整除的性質**（a ≠ 0）：
1. a | b 且 a | c ⇒ a | (b + c)。證：b = ak₁、c = ak₂，b + c = a(k₁ + k₂)。
2. a | b ⇒ a | bc（c 為任意整數）。證：bc = a(k₁c)。
3. a | b 且 b | c ⇒ a | c（遞移性）。證：c = bk₃ = a(k₁k₃)。
4. a | b 且 a | c ⇒ 對任何整數 m、n，a | (mb + nc)（線性組合 linear combination）。

> **重點** 證整除的套路：把「a | b」翻成「b = a·整數」，算完看結果是不是「a × 某個整數」。中文條件先用符號寫下來，推的時候換回等式。

### 除法演算法
**Division algorithm**（其實是定理）：a 為整數、d ≠ 0，存在**唯一**一組整數 q（商）、r（餘數）使

a = dq + r，0 ≤ r < |d|

限制餘數的範圍，答案才唯一。d > 0 時 q = ⌊a/d⌋，r = a − dq。

| 題目 | 寫成等式 | 商 | 餘數 |
|---|---|---|---|
| 101 ÷ 11 | 101 = 11·9 + 2 | 9 | 2 |
| 11 ÷ 3 | 11 = 3·3 + 2 | 3 | 2 |
| −11 ÷ 3 | −11 = 3·(−4) + 1 | −4 | 1 |
| 11 ÷ (−3) | 11 = (−3)·(−3) + 2 | −3 | 2 |
| −11 ÷ (−3) | −11 = (−3)·4 + 1 | 4 | 1 |

> **陷阱** −11 ÷ 3 不是商 −3 餘 −2，餘數不能是負的。除數是負的時候，餘數也要在 0 到 |d| − 1 之間，11 ÷ (−3) 餘 2，不是 −1。最好寫成等式，不要寫「3 餘 2」。

### mod 運算
a mod d（d > 1）就是除法演算法的餘數：**a mod d = a − d·⌊a/d⌋**。101 mod 11 = 2，−11 mod 3 = 1。

> **陷阱** C 語言的 −11 % 3 是 −2，但數學上 −11 mod 3 = 1。

### 同餘
「同餘」只在意除以同一個數的餘數。10、13、16、1 除以 3 都餘 1，寫成 10 ≡ 13 (mod 3)。不用等號，因為它們不是真的相等。

定義（m 為正整數）：

**a ≡ b (mod m) ⇔ m | (a − b) ⇔ 存在整數 k，a = b + km**

餘數相同的兩數相減，餘數抵消，所以差是 m 的倍數。例：3 − 1 = 2，2 | 2，所以 3 ≡ 1 (mod 2)。由 a = dq + r 得 a − r = dq，每個數都和自己的餘數同餘。判斷同餘不必算餘數，看差是不是 m 的倍數就好。

**同餘的運算**：若 a ≡ b、c ≡ d (mod m)，則
1. **a + c ≡ b + d (mod m)**。證：a = b + k₁m，c = d + k₂m，相加 a + c = b + d + (k₁ + k₂)m，k₁ + k₂ 是整數。例：7 ≡ 2、11 ≡ 1 (mod 5)，18 ≡ 3 (mod 5)。
2. **ac ≡ bd (mod m)**。證：ac = (b + k₁m)(d + k₂m) = bd + m(bk₂ + dk₁ + mk₁k₂)。

推論：(a + b) mod m = ((a mod m) + (b mod m)) mod m，乘法也一樣。寫程式靠這招，數字就不會爆掉。

> **陷阱** 同餘可以相加、相乘，但**不一定能相除**，要等到互質的條件（見消去律）。

> **重點** 證明套路：已知寫上面（a = b + k₁m、c = d + k₂m），目標寫下面（a + c = b + d + ?·m），中間把 ? 湊出來，最後一句「k₁ + k₂ 是整數」不能漏。

**為什麼資工要學同餘**：一個 byte 有 8 bit，能表示 0 到 255（2⁸ = 256 種）。要存 1000 放不下，就除以 256：256 × 3 = 768，1000 − 768 = 232，所以 1000 mod 256 = 232 放第一個 byte，商 3 放另一個 byte，用時湊回 256 × 3 + 232 = 1000。加密運算也只在意餘數，RSA 處處都是同餘。

### 質數、gcd、lcm
- **質數**（prime）：≥ 2，且正因數只有 1 和自己。
- **合成數**（composite）：≥ 2 且不是質數。

> **陷阱** 1 和負數都不是質數也不是合成數，兩個定義都要求 ≥ 2。

- 1 到 100 有 25 個質數，最好背起來。51 看起來像質數，其實 51 = 3 × 17。
- 標準分解式：100 = 2 × 2 × 5 × 5 = 2²·5²；一般整數可寫成 p₁^n₁ · p₂^n₂ ⋯ p_k^n_k。
- **gcd(a, b)** = max{m : m | a ∧ m | b}。12、18 的公因數 1、2、3、6，gcd = 6。
- **lcm(a, b)** = min{m ∈ ℤ⁺ : a | m ∧ b | m}。倍數可以是負的（−36、−72…沒有最小），所以要限制正整數。lcm(12, 18) = 36。
- a、b **互質**：gcd(a, b) = 1，例如 8 和 15。

### b 進位
十進位：個位 10⁰、十位 10¹、百位 10²，滿 10 進一位。以 b 為基底（base），任何正整數都能寫成

n = a_k·b^k + … + a₁·b + a₀

條件：最高位 a_k ≠ 0；每位 0 ≤ aᵢ ≤ b − 1（滿 b 就要進位）。在這兩個條件下寫法**唯一**。

**157 的各種進位**：
- 十進位：1·10² + 5·10 + 7（decimal expansion）。
- 十六進位：157 = 9·16 + 13。13 寫成一格會跟「1、3」混，所以 10～15 用 A～F，**157 = (9D)₁₆**。
- 八進位：157 = 2·64 + 3·8 + 5 = (235)₈。
- 二進位：157 = 128 + 16 + 8 + 4 + 1 = (10011101)₂。

**b 進位換十進位**：乘開加起來。(134)₅ = 1·25 + 3·5 + 4 = 44。(16)₂₀ = 1·20 + 6 = 26。

**十進位換 b 進位：連除法**

```
139 換四進位            139 換五進位
4 | 139  餘 3          5 | 139  餘 4
4 |  34  餘 2          5 |  27  餘 2
4 |   8  餘 0          5 |   5  餘 0
      2                     1
由下往上讀：(2023)₄      由下往上讀：(1024)₅
```

驗算：2·64 + 0·16 + 2·4 + 3 = 139；125 + 0 + 10 + 4 = 139。

> **陷阱** 餘數由下往上讀（最後的商是最高位）；中間出現的 0 一定要寫，它佔住一個位置。

再一個：753 換五進位 753 → 150 餘 3 → 30 餘 0 → 6 餘 0 → 1 餘 1，最後商 1，得 (11003)₅。換八進位：753 = 94·8 + 1，94 = 11·8 + 6，11 = 1·8 + 3，得 (1361)₈。五進位換三進位沒有捷徑，先換十進位再換。

這跟多項式一樣：把多項式寫成 (x + 1) 的次方展開，也是一直除以 x + 1，餘數依序是各項係數。

**名詞**：每一位乘的 b⁰、b¹、b² 叫該位的**權重**（weight）。二進位的一位叫 bit；權重最高那位叫 **MSB**（most significant bit），最低那位叫 **LSB**（least significant bit）。2569 最接近 2000：最高位最有意義。

**連除法的程式**：

```python
def to_base(n, b):          # n 為正整數
    digits = []
    q = n
    while q != 0:
        digits.append(q % b)    # 第 k 位
        q = q // b              # floor(q / b)
    return digits[::-1]         # 由高位到低位
# to_base(139, 4) -> [2, 0, 2, 3]
```

**2、8、16 進位快速互換**：8 = 2³、16 = 2⁴，先換成二進位最快。十六進位一位對 4 bit，八進位一位對 3 bit。

```
(ABC)₁₆ = 1010 1011 1100
重新從右邊 3 個一組：101 010 111 100 = 5 2 7 4
所以 (ABC)₁₆ = (5274)₈

(1361)₈ = 001 011 110 001
從右邊 4 個一組（左邊補 0）：0010 1111 0001 = 2 F 1
所以 753 = (1361)₈ = (2F1)₁₆
```

> **陷阱** 分組一定從最右邊開始，左邊不夠補 0。八進位換十六進位要先拆成 bit 再重組，一位對一位直接換是錯的。

**二進位加法、乘法**：

```
   1110   (14)          1011   (11)
 + 1011   (11)        ×  101   (5)
 ------               ------
  11001   (25)          1011
                       0000
                      1011
                      ------
                      110111  (55)
```

加法 1 + 1 = 10 寫 0 進 1，1 + 1 + 1 = 11 寫 1 進 1。一位加法電路：不管進位的叫半加器，管進位的叫全加器。乘法就是照抄、左移（shifter）、相加。

## Euclid 演算法與模運算

### 輾轉相除法
**定理**：若 a = bq + r，則 **gcd(a, b) = gcd(b, r)**。

證明：設 c 是 a、b 的公因數，r = a − bq 是 a、b 的線性組合，所以 c | r，c 是 b、r 的公因數。反過來 a = bq + r，b、r 的公因數也整除 a。兩組公因數完全一樣，最大的也一樣。

r < b，數字越變越小，最後餘數變 0，答案就是另一個數（0 是任何數的倍數）。

> **例題** gcd(528, 30)
> ```
> 528 = 17·30 + 18
>  30 =  1·18 + 12
>  18 =  1·12 +  6
>  12 =  2·6  +  0     → gcd = 6
> ```

```python
def gcd(a, b):
    x, y = a, b         # 不必管誰大，迴圈會自己交換
    while y != 0:
        r = x % y
        x, y = y, r
    return x
```

遞迴寫法：

```python
def gcd(a, b):          # 假設 a < b
    if a == 0:
        return b        # 終止條件
    return gcd(b % a, a)
# gcd(4, 10) -> gcd(2, 4) -> gcd(0, 2) -> 2
```

**Lamé 定理**：輾轉相除的除法次數不超過較小那個數**十進位位數的 5 倍**。五位數最多 25 次，所以即使 RSA 那種幾百位的大數也很快。（證明提示：除數下一步會變成被除數，要兩步一起看。）

### Bézout 定理
**gcd(a, b) 一定能寫成 sa + tb**，s、t 為整數。求法：把輾轉相除倒推回去，每一步只換掉一個餘數。

> **例題** 528s + 30t = 6
> ```
> 6 = 18 − 12                 (由 18 = 1·12 + 6)
>   = 18 − (30 − 18)          (12 = 30 − 18)
>   = 2·18 − 30
>   = 2·(528 − 17·30) − 30    (18 = 528 − 17·30)
>   = 2·528 − 35·30
> ```
> s = 2，t = −35。驗算：1056 − 1050 = 6。

> **例題** gcd(528, 35)：528 = 15·35 + 3，35 = 11·3 + 2，3 = 1·2 + 1，gcd = 1（互質）。
> 倒推：1 = 3 − 2 = 3 − (35 − 11·3) = 12·3 − 35 = 12·(528 − 15·35) − 35 = 12·528 − 181·35。驗算：6336 − 6335 = 1。

### 互質引理與消去律
**引理**：gcd(a, b) = 1 且 a | bc ⇒ a | c。
證：sa + tb = 1，兩邊乘 c：sac + tbc = c。sac 是 a 的倍數，a | bc 所以 tbc 也是，相加還是 a 的倍數。∎
推廣：p 是質數，p | a₁a₂…aₙ ⇒ p 至少整除其中一個。

**mod 的消去律**：ac ≡ bc (mod m) 且 **gcd(c, m) = 1** ⇒ a ≡ b (mod m)。
證：m | (a − b)c，c 與 m 互質，由引理 m | (a − b)。

> **陷阱** 反例：2·2 ≡ 2·5 (mod 6)（4 和 10 差 6），但 2 ≢ 5 (mod 6)，因為 gcd(2, 6) ≠ 1。

### 模反元素
消去就是除法，除法就是乘反元素。實數裡除以 3 就是乘 1/3。mod 裡不能除，但 c 有「倒數」就能消。

**定理**：gcd(a, m) = 1 ⇒ 存在 b 使 ab ≡ 1 (mod m)。b 叫 a 的 **multiplicative inverse**（模反元素），記作 a⁻¹（mod m）。
求法：Bézout 給 sa + tm = 1，兩邊 mod m，tm 消失，得 sa ≡ 1 (mod m)，s 就是 a⁻¹。

> **例題** 5 在 mod 3 的倒數。
> 5 = 1·3 + 2，3 = 1·2 + 1。倒推：1 = 3 − 2 = 3 − (5 − 3) = 2·3 − 5。5 的係數 −1，所以 5⁻¹ ≡ −1 ≡ 2 (mod 3)。驗算：5 × 2 = 10 ≡ 1 (mod 3)。

> **例題** 倒數的用法與存在與否：
> - mod 3 下 7·5⁻¹：5⁻¹ 不是五分之一，而是 2。7 × 2 = 14 ≡ 2 (mod 3)。
> - mod 6 下 5 的倒數：5 ≡ −1，(−1)(−1) = 1，所以 5⁻¹ = 5（25 ≡ 1）。0 到 5 中只有 1、5 和 6 互質，所以 2⁻¹ (mod 6) 不存在。
> - mod 9 下 2 的倒數：2 × 5 = 10 ≡ 1，所以 2⁻¹ = 5。gcd(6, 9) = 3，6 在 mod 9 沒有倒數。

> **陷阱** 「10 mod 3 = 1」是運算，用等號；「10 ≡ 1 (mod 3)」是關係，用同餘符號。只有 a、m 互質才有倒數。

## 中國餘數定理

### 韓信點兵
「3 個一數剩 1、5 個一數剩 1、7 個一數剩 1」：答案是 105 的倍數加 1。一般的情形就要用**中國餘數定理**（Chinese Remainder Theorem, CRT）。

前提：m₁, m₂, …, mₙ **兩兩互質**。則 x ≡ aᵢ (mod mᵢ)（i = 1…n）在 mod m = m₁m₂⋯mₙ 下有唯一解。

用湊的：x ≡ 1 (mod 3)、x ≡ 2 (mod 5)。除 3 餘 1 的有 1、4、7…；1 除 5 餘 1，4 餘 4，7 餘 2，所以 x ≡ 7 (mod 15)。

### 系統解法
1. m = m₁m₂⋯mₙ，**Mᵢ = m / mᵢ**。
2. **yᵢ = Mᵢ⁻¹ (mod mᵢ)**（Mᵢ 剛好拿掉 mᵢ，兩兩互質所以 Mᵢ 與 mᵢ 互質，倒數存在）。
3. **x ≡ ∑ aᵢMᵢyᵢ (mod m)**。

> **例題** x ≡ 1 (mod 3)，x ≡ 2 (mod 5)，x ≡ 3 (mod 7)。m = 105。
> | i | mᵢ | aᵢ | Mᵢ | yᵢ | aᵢMᵢyᵢ |
> |---|---|---|---|---|---|
> | 1 | 3 | 1 | 35 | 2（35 ≡ 2，2·2 = 4 ≡ 1） | 70 |
> | 2 | 5 | 2 | 21 | 1（21 ≡ 1） | 42 |
> | 3 | 7 | 3 | 15 | 1（15 ≡ 1） | 45 |
> x = 70 + 42 + 45 = 157 ≡ 52 (mod 105)。驗算：52 = 17·3 + 1 = 10·5 + 2 = 7·7 + 3。

> **陷阱** 公式裡用原本的 Mᵢ（35、21、15），不能換成化簡後的 2、1、1；最後才 mod 105。

為什麼對：x 除以 m₁ 時，第 2、3 項的 M 都含 m₁，被整除；剩 a₁M₁y₁，而 M₁y₁ ≡ 1，所以餘 a₁。其他同理。

唯一性：兩個解相減，同時被 3、5、7 整除，兩兩互質所以被 105 整除，兩解在 mod 105 下相同。

> **陷阱** 證明 CRT 時只證「有解」不夠，還要證在 mod m 下**唯一**，漏掉會被扣分。

### 除數不互質
不能直接套公式。做法：把除數拆成互質的因數，一個式子換成幾個，再檢查：重複的刪掉，矛盾的就判無解，寬嚴不同的保留嚴格的。

> **例題** x ≡ 2 (mod 3)，x ≡ 3 (mod 5)，x ≡ 2 (mod 15)。
> 15 = 3 × 5，x ≡ 2 (mod 15) ⇔ x ≡ 2 (mod 3) 且 x ≡ 2 (mod 5)。
> mod 3 的條件重複，刪掉；mod 5 一個要餘 3、一個要餘 2，**矛盾，無解**。
> 若要相容，第三式要改成和前兩式一致：除 3 餘 2、除 5 餘 3 的數是 8，所以改成 x ≡ 8 (mod 15)，整題答案就是 x ≡ 8 (mod 15)。

> **例題** x ≡ 5 (mod 6)，x ≡ 10 (mod 30)，x ≡ 3 (mod 4)。
> 拆開：mod 6 → x ≡ 1 (mod 2)、x ≡ 2 (mod 3)；mod 30 → x ≡ 0 (mod 2)、x ≡ 1 (mod 3)、x ≡ 0 (mod 5)。mod 2 一個餘 1 一個餘 0，矛盾，無解。
> 修正：以 30 那條為準，第一式改成 x ≡ 4 (mod 6)（4 除 2 餘 0、除 3 餘 1），它和 mod 30 那條一致，變成多餘。更聰明的拆法：30 = 5 × 6，x ≡ 10 (mod 30) ⇔ x ≡ 0 (mod 5) 且 x ≡ 4 (mod 6)，mod 6 那條多餘一目了然。
> 4 = 2 × 2 無法拆成互質。x ≡ 3 (mod 4) 推得 x ≡ 1 (mod 2)，又和 x ≡ 0 (mod 2) 矛盾。改成 x ≡ 2 (mod 4) 才相容。
> x ≡ 2 (mod 4) 比 x ≡ 0 (mod 2) 嚴格（4 除 2 餘 0，除 4 卻餘 0），所以 mod 2 只拿來檢查矛盾，算答案用 mod 4。
> 剩 x ≡ 2 (mod 4)、x ≡ 1 (mod 3)、x ≡ 0 (mod 5)，兩兩互質，解得 **x ≡ 10 (mod 60)**。

> **重點** 不互質就拆；拆出矛盾寫無解；像 mod 4 與 mod 2，留嚴格的算答案。

## 費馬小定理

**定理**：p 是質數，p ∤ a，則 **a^(p−1) ≡ 1 (mod p)**。

例：p = 7、a = 10，10⁶ = 1000000 = 7 × 142857 + 1，真的餘 1。

證明想法（以 p = 7、a = 10 為例）：
1. 非 0 的餘數只有 1, 2, …, 6（共 p − 1 個）。
2. 每個乘 10：10, 20, 30, 40, 50, 60，mod 7 分別是 3, 6, 2, 5, 1, 4。
3. 10 與 7 互質，有倒數，所以若 10b ≡ 10c 則 b ≡ c；不同的數乘 10 後仍不同，而且都不是 0。所以 {3, 6, 2, 5, 1, 4} 只是 {1, …, 6} 的重新排列（permutation）。
4. 全部乘起來同餘：10⁶ · 6! ≡ 6! (mod 7)。6! 的每個因數都與 7 互質，可以消掉，得 10⁶ ≡ 1 (mod 7)。

一般化：a·1, a·2, …, a·(p−1) 是 1, …, p−1 的重排，所以 a^(p−1)(p−1)! ≡ (p−1)!，消去得證。關鍵是「乘 a 造成重排」，**p 是質數、p ∤ a 缺一不可**。

**放寬版**：p 是質數，對任何整數 a，**a^p ≡ a (mod p)**。
- p ∤ a：原定理兩邊乘 a。
- p | a：兩邊除以 p 都餘 0，當然同餘。

## RSA

### 加密與解密
要送資料又怕被偷看，就把看得懂的**明文**（plaintext）經過函式變成看不懂的**密文**（ciphertext），叫**加密**；收件者把密文還原成明文，叫**解密**。RSA 以三位發明者 Rivest、Shamir、Adleman 的姓氏首字母命名。

### 產生金鑰
1. 選兩個很大的質數 p、q（實務上 n 至少 2048 位元；考試用 13、17 這種小數算）。
2. n = pq（之後拿來取餘數的除數）。
3. 算 (p − 1)(q − 1)，選一個與它互質的 e。
4. 求 d：**de ≡ 1 (mod (p − 1)(q − 1))**，d 就是 e 的模反元素。
5. 公開 n 和 e（公鑰），d 自己留著（私鑰）。p、q 用完要銷毀，別人知道 p 或 q 就能算出 d。

> **陷阱** d 是 e 在 mod (p − 1)(q − 1) 下的倒數，不是 mod n。

### 加密、解密
明文（如 ASCII）是一串 bit，切成段，每段當成一個數 M。

- 加密：**C = M^e mod n**
- 解密：**M = C^d mod n**

加密、解密做的是同一種運算（次方再取餘數），只是鑰匙不同。標準用法是用收件者的公鑰 e 加密、收件者用私鑰 d 解密；反過來用私鑰加密、別人用公鑰解，可以確認是你送的，這是數位簽章的用法。

為什麼會還原：C^d ≡ M^(ed) (mod n)。ed ≡ 1 (mod (p−1)(q−1))，用費馬小定理分別看 mod p、mod q，得 M^(ed) ≡ M，再用 CRT 合起來得 mod n 下也成立。

> **例題** p = 43，q = 59。
> - n = 43 × 59 = 2537，(p − 1)(q − 1) = 42 × 58 = 2436。
> - 取 e = 13，gcd(13, 2436) = 1。
> - d = 937：13 × 937 = 12181 = 5 × 2436 + 1。
> - 明文 M = 1819：C = 1819¹³ mod 2537 = 2081。
> - 解密：2081⁹³⁷ mod 2537 = 1819，還原了。

### 大次方取餘數：快速冪
要算 2081⁹³⁷ mod 2537 有兩個問題：乘 937 次太慢；數字一乘就 overflow。

**避免 overflow**：ab mod m = ((a mod m)(b mod m)) mod m。每乘一次就取一次餘數，兩個餘數相乘仍可能 ≥ m，最後一定要再 mod 一次。

**加速：一直平方**。2¹⁶ 不必乘 15 次：16 = 2 × 8，2¹⁶ = (2⁸)² = 256² = 65536，平方一次就到。

指數不是 2 的次方時，例如 13：13 = 2·6 + 1，6 = 2·3 + 0，3 = 2·1 + 1，一直除以 2 記餘數，這就是二進位 13 = (1101)₂ = 8 + 4 + 1。所以 2¹³ = 2⁸ · 2⁴ · 2¹，而 2、2²、2⁴、2⁸ 每項都是前一項的平方。二進位是 1 的位才乘進答案：2 × 16 × 256 = 8192。

**Modular exponentiation**（計算 bⁿ mod m）：

```python
def mod_pow(b, n, m):
    x = 1
    power = b % m
    while n > 0:
        if n % 2 == 1:              # 這一位是 1
            x = (x * power) % m     # 乘進答案
        power = (power * power) % m # 每一輪都要平方
        n //= 2
    return x
```

追蹤 2¹³（先不看 mod），13 = (1101)₂，由低位往高位：

| 輪 | 位元 | power | x |
|---|---|---|---|
| 0 | 1 | 2 | 2 |
| 1 | 0 | 4 | 2 |
| 2 | 1 | 16 | 32 |
| 3 | 1 | 256 | 8192 |

> **陷阱** 不論這一位是 0 或 1，power 每輪都要平方；只有位元為 1 才把 power 乘進 x。

## 數學歸納法

### 原理：骨牌
要證帶 n 的敘述 S(n)（例如 1 + 2 + … + n = n(n+1)/2）對所有正整數成立：
1. **Induction basis**（起始條件）：S(1) 成立。
2. **Induction step**（歸納步驟）：對**所有** k ≥ 1，若 S(k) 成立（**induction hypothesis**，歸納假設），則 S(k + 1) 成立。

S(1) 成立，推出 S(2)，再推出 S(3)……全部成立。

> **比喻** 一排骨牌：第一張被推倒（basis），而且「這一張倒，下一張一定倒」（step），全部就依序倒下。中間只要有一個 k 推不動，鏈子就斷了。

**標準格式三步**：① 起始條件 ② 推演 ③ 結論（「所以對所有正整數 n，P(n) 為真」）。② 最重要，但 ① 不能省，③ 形式上也要寫。

> **例題** 證明 1 + 2 + … + n = n(n+1)/2。
> ① n = 1：左邊 1，右邊 1·2/2 = 1，成立。
> ② 假設 1 + … + k = k(k+1)/2。則
> 1 + … + k + (k+1) = k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2，正是 n = k + 1 的公式。
> ③ 由數學歸納法，對所有正整數 n 成立。
> 把前段換成假設的那一步，就是「用上歸納假設」。

> **例題** 證明 ∑ᵢ₌₁ⁿ (4i + 3) = 2n² + 5n。
> basis：n = 1，左邊 7，右邊 2 + 5 = 7。
> step：假設 ∑ᵢ₌₁ᵏ (4i + 3) = 2k² + 5k。則加到 k + 1 為 2k² + 5k + (4(k+1) + 3) = 2k² + 9k + 7。目標 2(k+1)² + 5(k+1) = 2k² + 9k + 7，相同。∎

> **例題** 證明 1³ + 2³ + … + n³ = [n(n+1)/2]²。
> basis：n = 1，1 = 1²。
> step：1³ + … + k³ + (k+1)³ = k²(k+1)²/4 + (k+1)³ = (k+1)²·(k²/4 + k + 1) = (k+1)²·(k² + 4k + 4)/4 = [(k+1)(k+2)/2]²。∎

> **例題** 證明 n < 2ⁿ（n 為正整數）。
> basis：1 < 2。
> step：假設 k < 2ᵏ。k + 1 < 2ᵏ + 1 ≤ 2ᵏ + 2ᵏ = 2ᵏ⁺¹（k ≥ 1，所以 1 ≤ 2ᵏ）。∎
> 不等式的訣竅：放大、串接。

> **例題** 證明 2ⁿ < n!，n ≥ 4。
> 第一張骨牌在 4：2⁴ = 16 < 24 = 4!。不能從 1 開始，因為 n = 3 時 2³ = 8 > 6 = 3!。
> step：假設 2ᵏ < k!，k ≥ 4。2ᵏ⁺¹ = 2·2ᵏ < 2·k! < (k+1)·k! = (k+1)!（k + 1 ≥ 5 > 2）。∎
> 證明裡一定要用到歸納假設，前提沒用上通常就是證錯了。

> **例題** 證明 |P(S)| = 2^|S|（P(S) 是 S 的 power set，所有子集合組成的集合）。
> 骨牌的順序選「集合的大小」。
> basis：|S| = 0，S = ∅，P(∅) = {∅} 有 1 個元素，2⁰ = 1。
> 舉例：{1, 2, 3} 的子集合有 ∅、{1}、{2}、{3}、{1,2}、{1,3}、{2,3}、{1,2,3}，共 8 = 2³ 個。加入新元素 a 後，子集合分兩類：不含 a 的（原來 8 個）、含 a 的（每個舊子集合再加 a，也是 8 個），共 16 = 2⁴。
> step：|S| = k + 1，拿掉一個元素 x 得 T，|T| = k，T 有 2ᵏ 個子集合；S 的子集合是 T 的子集合「加或不加 x」，共 2ᵏ⁺¹ 個。∎

> **陷阱** P(∅) = {∅} 有 1 個元素，不是空集合。

> **例題** 調和數 H_j = 1 + 1/2 + … + 1/j。證明 H_{2ⁿ} ≥ 1 + n/2（n ≥ 0）。
> 骨牌跳著走：H₁、H₂、H₄、H₈…。
> basis：n = 0，H₁ = 1 ≥ 1。
> step：H_{2ᵏ⁺¹} = H_{2ᵏ} + [1/(2ᵏ+1) + … + 1/2ᵏ⁺¹]。前段 ≥ 1 + k/2；後段共 2ᵏ 項，每項 ≥ 最小的 1/2ᵏ⁺¹，所以 ≥ 2ᵏ/2ᵏ⁺¹ = 1/2。相加 ≥ 1 + (k+1)/2。∎
> 意思是調和數會一直變大、不收斂，增長速度像 log。「把每項換成最小的」是常用技巧。

> **例題** 推廣的 De Morgan：(A₁ ∩ A₂ ∩ … ∩ Aₙ)ᶜ = A₁ᶜ ∪ A₂ᶜ ∪ … ∪ Aₙᶜ。
> 工具：兩個集合的 De Morgan（起點），以及 k 個時成立的假設。
> k + 1 個：令 B = A₁ ∩ … ∩ Aₖ，則 (B ∩ Aₖ₊₁)ᶜ = Bᶜ ∪ Aₖ₊₁ᶜ（兩集合版），Bᶜ 再用假設拆成 A₁ᶜ ∪ … ∪ Aₖᶜ，用結合律合起來即得。∎

> **例題** 排容原理（inclusion–exclusion）的歸納證明：先把各集合個數加起來，加過頭減兩兩交集，減過頭再加三個的交集……。n + 1 個時，把最後兩個集合的聯集綁成一個，就只剩 n 個，可以套假設；再用兩集合的公式和分配律把藏在裡面的聯集拆開，整理後所有組合剛好都出現。重點：歸納證明不一定是數字，也可以很抽象。

### 廣義的歸納法
三個放寬：
1. 起始條件不一定從 1 開始，可從任何 n₀ 開始（如上面的 4）。
2. 起始條件不一定只有一個，可能要檢查好幾個。
3. step 不一定只假設 S(k)：假設 S(n₀), …, S(k) **全部**成立，證 S(k + 1)。結論是對所有 n ≥ n₀ 成立。

要幾個起始條件，看 step 往前用幾格。

### 強歸納法
第 3 個放寬叫 **strong induction**（強數學歸納法）：第 k + 1 張倒，是因為前面 1 到 k 全倒了。

> **比喻** 中間有一張超大骨牌，要前面好幾張一起倒才推得動。

> **例題** 每個大於 1 的整數都能寫成質數的乘積。
> basis：2 是質數。
> step：假設 2 到 k 都能分解。看 k + 1：
> - k + 1 是質數：自己就是分解。
> - 不是質數：k + 1 = ab，2 ≤ a, b ≤ k，由強假設 a、b 都能分解，乘起來就是 k + 1 的分解。例：12 = 3 × 4 = 3 × 2 × 2。∎
> a、b 不是 k，而是 2 到 k 之間的某個數，所以只假設 P(k) 不夠。

> **例題** 撿火柴：兩堆一樣多，輪流從其中一堆拿走至少一根，拿到最後一根的人贏。證明後手必勝。
> 對每堆根數歸納。basis：每堆 1 根，先手拿走一根，後手拿最後一根。
> step：假設每堆 1 到 k 根都是後手贏。每堆 k + 1 根時，先手在某堆拿幾根，後手就在另一堆拿一樣多，又回到兩堆一樣多、對方先手，而且根數 ≤ k，由假設後手贏。∎

> **例題** 只用 4 元和 5 元郵票，12 元以上都湊得出來。
> basis（四個）：12 = 4+4+4，13 = 4+4+5，14 = 4+5+5，15 = 5+5+5。
> step：k ≥ 15，假設 12 到 k 都湊得出。k + 1：先貼一張 4 元，剩 k − 3 元，12 ≤ k − 3 < k，由假設湊得出。∎
> 為什麼要四個起始條件？一步退 4 元，16 退到 12，12 到 15 都必須先驗過。

> **例題** 三角剖分：任何 n 邊形都能切成 n − 2 個三角形。
> 對角線連兩個不相鄰頂點。**凸多邊形**（convex）對角線全在裡面；**凹多邊形**（concave）有內凹的角，有些對角線會跑到外面。凸的很好切（從一個頂點畫對角線，五邊形 3 個、六邊形 4 個），難的是凹的。
> 關鍵 lemma：不管凸凹，至少有一條對角線完全在內部。沿它切開，兩塊都是較小的多邊形，用強假設。例：八邊形切成 4 邊形和 6 邊形，4 + 6 = 10 是因為切線被兩塊共用。三角形數 2 + 4 = 6 = 8 − 2。一般：兩塊邊數 s + t = n + 2，三角形 (s − 2) + (t − 2) = n − 2。

> **陷阱** 切開後兩塊的邊數加起來是 n + 2，不是 n。

### 錯誤的歸納：每個人都有錢？
「定理」：S(n)：任找 n 個人，只要其中一人有錢，這 n 個人全有錢。
- basis：n = 1，成立。
- step：k + 1 個人 α₁, …, αₖ₊₁，設 α₁ 有錢。前 k 個人含 α₁，由假設全有錢；再拿掉 αₖ、放進 αₖ₊₁，這組 k 人也含 α₁，所以 αₖ₊₁ 也有錢。

世界上至少有一個有錢人，所以每個人都有錢？荒謬（換成「沒錢」也能證）。結論錯，證明一定錯；推翻結論只要找一個沒錢的人，但重點是**證明錯在哪**。

把 k = 1 帶進 step：兩個人，α₁ 有錢。第一組挑 1 人，要含 α₁，只能是 {α₁}；第二組也要含 α₁，還是 {α₁}。α₂ 從沒被放進任何一組！k = 2 時第一組 {α₁, α₂}、第二組 {α₁, α₃} 沒問題。所以**錯在 S(1) ⇏ S(2)**：第一張倒了卻碰不到第二張。

> **陷阱** 檢查歸納證明要把論證真的帶進去，確認 1 推 2、2 推 3 都成立。錯誤常常只藏在最小的那一步。

### 良序原理
**Well-ordering principle**：任何**非空**的**非負整數**集合，一定有最小元素。例 {3, 5, 8, 9}：從 0 開始問在不在，0 不在、1 不在、2 不在、3 在，就是最小的。集合非空，總會碰到第一個。

三個條件缺一不可：
- 換成有理數：{1, 1/2, 1/3, 1/4, …} 非空且非負，但 1/n 永遠不是最小（1/(n+1) 更小），0 又不在裡面，沒有最小元素。
- 拿掉非負：所有整數 −1、−2、… 一直往下，沒有最小。

應用：我們不知道「最年輕的大學畢業生幾歲」，但相信答案存在；湊出 1.17 美元最少要幾枚硬幣？能湊出的枚數是非空的非負整數集合（117 枚 1 分就行），所以最小值一定存在。

> **例題** 用良序原理說明分數都能化成最簡。
> 證 √2 無理時，「假設 √2 = m/n 已是最簡分數」憑什麼？所有能寫成 √2 = m/n 的分子 m 構成非空的正整數集合，取最小的 m。若 m、n 有公因數 c > 1，則 (m/c)/(n/c) 也等於 √2，分子更小，矛盾。所以 m、n 互質。

數學歸納法、強歸納法、良序原理三者其實等價。

> **陷阱** 自然數 ℕ 是否含 0 各書不同；用良序原理時說的「數」是非負整數 0, 1, 2, …。

## 遞迴

### 不知道答案時：遞迴關係
用歸納法證立方和，必須先知道答案。不知道時，令 aₙ = 1³ + 2³ + … + n³，則

aₙ − aₙ₋₁ = n³（n ≥ 2），a₁ = 1

a₂ = 1 + 8 = 9，a₃ = 9 + 27 = 36……每項都由前面算出，所以 aₙ 是 **well-defined**。這種式子叫**遞迴關係**（recurrence relation），解它就是把 aₙ 寫成只跟 n 有關的式子。右邊不是 0 叫 non-homogeneous，是 0 叫 homogeneous。它是離散版的微分方程，也叫差分方程。4 次方、5 次方的和也能這樣解（遞迴關係那章教）。

### 遞迴定義數列
數列其實就是變數為整數的函式。遞迴定義 = **首項 + 遞迴式**。

- aₙ = 2ⁿ 也可寫成：a₀ = 1，aₙ = 2aₙ₋₁，得 1、2、4、8、16。
- f(0) = 3，f(n+1) = 2f(n) + 3：f(1) = 9，f(2) = 21，f(3) = 45。
- 階乘：0! = 1，n! = n·(n−1)!。

> **陷阱** 一定要有首項。首項改成 5、遞迴式不變，就變成 5、13、29…，完全不同。首項加遞迴式，數列才唯一。

**階數**：只跟前一項有關叫 first order（一階），跟前兩項有關叫 second order（二階），要兩個起始值。

> **例題** a₁ = 1，a₂ = 5，aₙ₊₁ = 5aₙ − 6aₙ₋₁（n ≥ 2）。a₃ = 25 − 6 = 19。證明 aₙ = 3ⁿ − 2ⁿ。
> basis（兩個）：n = 1：3 − 2 = 1；n = 2：9 − 4 = 5。
> step：假設第 k、k − 1 項符合公式。
> aₖ₊₁ = 5(3ᵏ − 2ᵏ) − 6(3ᵏ⁻¹ − 2ᵏ⁻¹) = 3ᵏ⁻¹(15 − 6) − 2ᵏ⁻¹(10 − 6) = 3ᵏ⁻¹·9 − 2ᵏ⁻¹·4 = 3ᵏ⁺¹ − 2ᵏ⁺¹。∎（證明結束可畫實心方塊 ∎ 或寫 QED。）

> **陷阱** 遞迴用到前兩項時，basis 必須驗兩個值，只驗 n = 1 不夠。

### Fibonacci 數列
f₀ = 0，f₁ = 1，fₙ = fₙ₋₁ + fₙ₋₂：0、1、1、2、3、5、8……

> **例題** 證明 fₙ < 2ⁿ。
> basis：f₀ = 0 < 1，f₁ = 1 < 2。
> step（強歸納）：n ≥ 2，假設比 n 小的都成立。fₙ = fₙ₋₁ + fₙ₋₂ < 2ⁿ⁻¹ + 2ⁿ⁻² < 2ⁿ⁻¹ + 2ⁿ⁻¹ = 2ⁿ。∎
> 練習：n ≥ 3 時 fₙ > αⁿ⁻²，α = (1 + √5)/2 ≈ 1.618（黃金比例），basis 要驗 n = 3、4。

### 遞迴定義集合
- 起始：3 ∈ S。
- 規則：x ∈ S 且 y ∈ S ⇒ x + y ∈ S。

只有一個 3 怎麼用規則？x、y 沒說要不同，3 + 3 = 6 ∈ S，3 + 6 = 9 ∈ S……S 就是 3 的正倍數。

> **陷阱** 規則裡的 x、y 沒要求不同，不要自己綁死。

### 字串
- 字母集（alphabet）Σ，例如 {a, …, z}。
- Σ⁰：長度 0 的字串，只有空字串 λ。Σ¹：a 到 z，26 個。Σ²：aa、ab、…、zz，26² 個（ab 和 ba 不同）。
- **Σ*** = Σ⁰ ∪ Σ¹ ∪ Σ² ∪ …，所有字串（含空字串）。字母集是 {0, 1} 時就是所有二進位字串。

遞迴定義 Σ*：起始 λ ∈ Σ*；規則：w ∈ Σ*、x ∈ Σ ⇒ wx ∈ Σ*。
證明 "apple" 是字串：λ → "a" → "ap" → "app" → "appl" → "apple"。

### 遞迴定義樹
- **有根樹**（rooted tree）：起始，一個點就是一棵樹（樹根）。規則：有幾棵有根樹，放一個新節點連到每棵的根，就是一棵新樹。節點 node、邊 edge、子樹、父親、小孩、兄弟。
- **二元樹**（binary tree，extended binary tree）：起始，**空樹**也是二元樹。規則：拿兩棵（左、右）二元樹，加一個新根連起來。左右兩棵都是空樹時，得到一個點。

| | 有根樹 | 二元樹 |
|---|---|---|
| 最小的 | 一個點 | 空樹 |
| 小孩數 | 任意多 | 最多兩個 |
| 順序 | 沒有 | 分左、右 |

> **陷阱** 最小的二元樹是空樹；「只有左兒子」和「只有右兒子」是兩棵不同的二元樹。

有兒子的叫內部節點（internal node），沒兒子的叫葉子（leaf，也叫 external node）。

### 遞迴演算法
aⁿ = a·aⁿ⁻¹，函式自己呼叫自己，相信它算得出來：

```python
def power(a, n):
    if n == 0:
        return 1             # 終止條件
    return a * power(a, n - 1)
```

追蹤 power(5, 3)，用堆疊（stack）記錄還沒算完、先「冷凍」的乘法：

```
power(5,3) = 5 * power(5,2)      冷凍
power(5,2) = 5 * power(5,1)      冷凍
power(5,1) = 5 * power(5,0)      冷凍
power(5,0) = 1
回傳：5*1 = 5 → 5*5 = 25 → 5*25 = 125
```

呼叫次數和時間成正比，power(5, 10) 要呼叫 11 次（10 到 0）。

> **陷阱** 遞迴一定要有終止條件（base case），否則會無限呼叫。

**更快的遞迴**：n 偶數時 aⁿ = (a^(n/2))²。

```python
def power(a, n):
    if n == 0:
        return 1
    if n % 2 == 0:
        h = power(a, n // 2)
        return h * h          # 存起來再平方
    return a * power(a, n - 1)
```

追蹤 5¹⁰：10 偶 → 算 5⁵ 再平方；5 奇 → 5·5⁴；4 偶 → (5²)²；2 偶 → (5¹)²；1 奇 → 5·5⁰；5⁰ = 1。回傳：5¹ = 5，5² = 25，5⁴ = 625，5⁵ = 3125，5¹⁰ = 9765625。只呼叫 6 次（10、5、4、2、1、0）。加上 mod 時每一步取餘數即可。

> **陷阱** 寫成 power(5, 5) * power(5, 5) 看起來一樣，但會算兩次，一路分岔，反而更慢。要把結果存起來再平方。

### Merge sort
最原始的排序是一個一個比，先抓最大的、再抓剩下最大的（selection sort），好寫但慢。**Merge sort**：切成兩半，相信遞迴把兩半各自排好，再合併。合併像整理兩疊排好的撲克牌：比兩疊頂端，拿出較大（或較小）的，一疊空了，另一疊照抄。

> **例題** 10、6、5、7、8、3、2 由大排到小。
> ```
> 切：[10, 6, 5] [7, 8, 3, 2]
> 切：[10] [6, 5]   [7, 8] [3, 2]
> 切：[10] [6] [5]  [7] [8] [3] [2]   一個的自己就排好
> 併：[6, 5]        [8, 7] [3, 2]
> 併：[10, 6, 5]    [8, 7, 3, 2]       8 vs 3 取 8，7 vs 3 取 7，剩 3、2 照抄
> 併：[10, 8, 7, 6, 5, 3, 2]
> ```

```python
def mergesort(L):
    if len(L) <= 1:
        return L
    m = len(L) // 2
    return merge(mergesort(L[:m]), mergesort(L[m:]))

def merge(A, B):              # A、B 已由小到大排好
    i = j = 0
    out = []
    while i < len(A) and j < len(B):
        if A[i] <= B[j]:
            out.append(A[i]); i += 1
        else:
            out.append(B[j]); j += 1
    return out + A[i:] + B[j:]  # 剩下的照抄
```

Merge sort 比 selection sort 效能好很多。

### Ackermann 函數
```
A(m, n) = 2n                     若 m = 0
        = 0                      若 m ≥ 1 且 n = 0
        = 2                      若 m ≥ 1 且 n = 1
        = A(m−1, A(m, n−1))      若 m ≥ 1 且 n ≥ 2
```
A(2, 2) = A(1, A(2, 1)) = A(1, 2) = A(0, A(1, 1)) = A(0, 2) = 4。看起來簡單，但 A(3, 3) 會長得非常非常快。

## 函數

### 定義
A、B 是非空集合。**函數** f : A → B 是一個對應規則：**A 的每一個元素都對應到 B 中唯一的一個元素**。

- A 叫 **domain**（定義域），每個元素都要有定義。
- B 叫 **codomain**（對應域）。
- f(a) = b：a 對應到 b。兩個元素對到同一個 b 沒有違反定義；一個 a 對到兩個 b 就不是 well-defined。
- **range**（值域）= {f(a) : a ∈ A}，真的被對到的部分。

> **陷阱** range 一定是 codomain 的子集合，但不一定等於 codomain。

### 一對一、映成、對射
- **one-to-one / injective**（一對一、嵌射，名詞 injection）：f(a₁) = f(a₂) ⇒ a₁ = a₂。逆否：a₁ ≠ a₂ ⇒ f(a₁) ≠ f(a₂)，不同的對過去就不同。
- **onto / surjective**（映成、蓋射，名詞 surjection）：f(A) = B，即對每個 b ∈ B 都至少有一個 a 使 f(a) = b。
- **bijective / one-to-one correspondence**（對射、一一對應）：兩個都成立。

證 one-to-one：證 f(a₁) = f(a₂) ⇒ a₁ = a₂。證 onto：證任何 b 都找得到 a。

> **陷阱** one-to-one 不代表 onto，onto 也不代表 one-to-one，兩者獨立。

### 計數熱身
> **例題** A = {1, 2, 3}，B = {x, y}。
> - 函數總數：1、2、3 各有 2 種選擇，2³ = 8 個（f₁ 到 f₈）。
> - injective：三個要對到不同元素，B 只有兩個，**0 個**。
> - surjective：x、y 都要出現，扣掉全 x、全 y，**6 個**。
> - bijective：**0 個**。

一般 |A| = m、|B| = n：
- 函數共 **nᵐ** 個。
- injective 需 n ≥ m，個數是排列 n(n−1)⋯(n−m+1)。例：|A| = 3、|B| = 4，4 × 3 × 2 = 24 個。
- surjective 需 m ≥ n，公式較麻煩，用排容原理算（計數那章）。
- bijective 需 m = n。

> **陷阱** |B| < |A| 時不可能有 injective；|B| > |A| 時不可能有 surjective。

## 重點整理
- P(x) 不是命題；∀ 是一長串 ∧，∃ 是一長串 ∨；答案取決於 domain。
- ¬∀x P(x) ≡ ∃x ¬P(x)，¬∃x P(x) ≡ ∀x ¬P(x)；¬ 穿過一個量詞就互換一次。
- ∀∀、∃∃ 可交換，∀∃ 混用不可交換；∀x P(x) ∨ Q(x) 中 ∀ 只管 P(x)。
- 「所有」配 →：∀x (S(x) → C(x))；「有些」配 ∧：∃x (P(x) ∧ ¬R(x))。
- 有效推論 ⇔ (p₁ ∧ … ∧ pₙ) → q 是 tautology。
- modus ponens：p, p → q ∴ q；modus tollens：¬q, p → q ∴ ¬p；resolution：p ∨ q, ¬p ∨ r ∴ q ∨ r。
- 謬誤：肯定後件（q, p → q ∴ p）、否定前件（¬p, p → q ∴ ¬q）。
- 直接、逆否、矛盾、空證明、平凡證明、列舉（case 要列完整）。
- a = dq + r，0 ≤ r < |d|；−11 = 3·(−4) + 1。
- a ≡ b (mod m) ⇔ m | (a − b)；可加、可乘，相除需 gcd(c, m) = 1。
- gcd(a, b) = gcd(b, a mod b)；Bézout：gcd = sa + tb；Lamé：除法次數 ≤ 5 × 較小數的位數。
- a⁻¹ (mod m) 存在 ⇔ gcd(a, m) = 1，用 Euclid 倒推求。
- CRT：x ≡ ∑ aᵢMᵢyᵢ (mod m)，Mᵢ = m/mᵢ，yᵢ = Mᵢ⁻¹ (mod mᵢ)；不互質先拆、查矛盾、留嚴格的。
- 費馬小定理：p 質數、p ∤ a ⇒ a^(p−1) ≡ 1 (mod p)；a^p ≡ a (mod p) 對所有 a。
- RSA：n = pq，ed ≡ 1 (mod (p−1)(q−1))，C = M^e mod n，M = C^d mod n。
- 快速冪：指數寫成二進位，power 每輪平方，位元為 1 才乘進 x，每步 mod。
- 歸納法：basis + step（對所有 k）+ 結論；step 往前用幾格，basis 就驗幾個。
- 強歸納：假設 n₀ 到 k 全成立；用於質因數分解、郵票、Fibonacci、三角剖分。
- 良序原理：非空、非負、整數，缺一不可。
- 遞迴定義 = 首項 + 遞迴式；遞迴程式一定要有終止條件。
- |A| = m、|B| = n：函數 nᵐ 個；injective 需 n ≥ m，surjective 需 m ≥ n，bijective 需 m = n。
