# 計數原理

計數（counting，enumeration）回答「一件事有幾種可能」，關鍵是不漏也不重複。這一章從加法原理、乘法原理出發，用「有沒有順序 × 能不能重複」把選法分成四種：排列、可重複排列、組合、可重複組合（星棒法）；再學有相同物的排列、格子路徑、二項式定理與組合恆等式；最後是鴿籠原理（pigeonhole principle）與它的推廣 ⌈N/k⌉，重點在怎麼設計鴿籠。考試最常考：判斷該加還是該乘、排列與組合的區別、相鄰條件、星棒法加上下限、鴿籠的設計。

## 加法原理與乘法原理

兩件事，第一件有 m 種做法，第二件有 n 種做法：
- **加法原理**（sum rule）：兩件**只挑一件**做，共 m + n 種。
- **乘法原理**（product rule）：兩件**都要做**，共 m × n 種。例：兩題作業都要交，第一題 2 種做法、第二題 3 種，共 2 × 3 = 6 種。

> **比喻** 臺北到臺中有 m 種交通方式，臺中到高雄有 n 種，臺北到高雄兩段都得走：m × n 種。臺北到宜蘭可以開車（好幾條路）、坐飛機、搭船，只要選一種方式：相加。分步驟、每步都要做就乘；分情況、選一種就加。

**集合的寫法**：
- 加法原理：A、B 是有限集合且 **A ∩ B = ∅**（disjoint），則 |A ∪ B| = |A| + |B|。例：|A| = 3、|B| = 2，|A ∪ B| = 5。想數一個集合，就切成不相交的幾塊各自數完再加。
- 乘法原理：|A × B| = |A| × |B|。A × B 是所有有序對 (a, b)，每個 a 配每個 b 都是不同的一對，3 × 2 = 6。

> **陷阱** 加法原理一定要不相交；有交集還直接相加，同一個東西會被數兩次，要改用排容原理（inclusion–exclusion）。

高中的排列組合公式，基本上都能用這兩個原理推出來。

### 例題
> **例題**（加法）三張題目單分別有 23、15、19 題，每人只挑一題做：23 + 15 + 19 = **57** 種。加法原理就是「分類」，再從其中一類挑一個。

> **例題**（乘法）座號由一個英文字母加一個數字組成（像 A1、B2）。字母 26 種、數字 1 到 99 有 99 種，兩格都要填：26 × 99 = **2574**。若數字是 1 到 100，答案 2600。

> **例題** 長度 7 的 bit string（每位 0 或 1）：7 個位置都要填，2⁷ = **128**。

> **例題** 巢狀迴圈跑幾次？
> ```
> k = 0
> for i₁ = 1 to n₁
>   for i₂ = 1 to n₂
>     …
>       for iₘ = 1 to nₘ
>         k = k + 1
> ```
> 每一組不同的 (i₁, …, iₘ) 讓 k 加 1，所以 k = n₁ × n₂ × ⋯ × nₘ。兩層、n₁ = 2、n₂ = 3 時 k = 6。

> **例題** 密碼長 6 到 8 個字元，每個字元是大寫英文字母或數字，**至少要有一個數字**，共有幾個？
> 先分組（加法原理）：P = P₆ + P₇ + P₈。
> 長度 6：每格 26 + 10 = 36 種，不管限制共 36⁶ 個；扣掉完全沒數字（全是字母）的 26⁶ 個：P₆ = 36⁶ − 26⁶。
> 同理 P₇ = 36⁷ − 26⁷，P₈ = 36⁸ − 26⁸。
> 總和 = 2,684,483,063,360 ≈ 2.68 × 10¹²。

> **陷阱** 「至少一個」不要硬算，用「全部 − 一個都沒有」最快；長度不同的要分組再相加。

> **例題** IPv4 位址有幾個？
> 位址是 4 個 8-bit 數字（每段 0～255，即 2⁸ 種），不管規則共 2³² ≈ 4 × 10⁹（約四十億）。
> 實際上位址分成 Net ID（哪個網路）和 Host ID（網路裡哪台電腦），並分類：
> | 類別 | 開頭位元 | Net ID | Host ID |
> |---|---|---|---|
> | Class A | 0 | 7 bits | 24 bits |
> | Class B | 10 | 14 bits | 16 bits |
> | Class C | 110 | 21 bits | 8 bits |
> 例：開頭 140 = 128 + 8 + 4 = (10001100)₂，開頭是 1、0，屬 Class B。
> 限制：Class A 的 Net ID 不能全 1；Host ID 不能全 0 也不能全 1（各扣 2 個）。
> ```
> Class A：(2⁷ − 1)(2²⁴ − 2)
> Class B：2¹⁴ (2¹⁶ − 2)
> Class C：2²¹ (2⁸ − 2)
> 合計 3,737,091,842 ≈ 3.7 × 10⁹
> ```
> 比粗估少，因為開頭 3 bit 的 8 種組合中，A、B、C 用掉 0xx、10x、110，111 另作他用，約 7/8 合法：4 × 7/8 = 3.5，再多一點。估算技巧：2¹⁰ = 1024 ≈ 1000。

## 樹狀圖
題目複雜時，把情況一一畫出來：先決定第一件事，在這個前提下再看下一步能怎麼走。列完通常再配合加法原理。（把所有情況列出來刪掉不要的，本身也是一種演算法。）

> **例題** 長度 4 的 0/1 字串，**不能有兩個連續的 1**，有幾個？
> 不限制有 2⁴ = 16 個。畫樹：前一位是 0，下一位可放 0 或 1；前一位是 1，下一位只能放 0（不行的分支不畫）。
> ```
> 0 ─┬─ 0 ─┬─ 0 ─┬─ 0    0000
>    │     │     └─ 1    0001
>    │     └─ 1 ─── 0    0010
>    └─ 1 ─── 0 ─┬─ 0    0100
>                └─ 1    0101
> 1 ─── 0 ─┬─ 0 ─┬─ 0    1000
>          │     └─ 1    1001
>          └─ 1 ─── 0    1010
> ```
> 從葉子走回樹根就是一個字串，共 **8** 個。

IP 類別也能畫成樹：第一位 0 → Class A；10 → Class B；110 → Class C；111 → 另作他用。

## 四種選法
從 n 個元素的集合拿 m 個：

| | 可重複 with repetition | 不重複 without repetition |
|---|---|---|
| 有順序 ordered | nᵐ | P(n, m) = n(n − 1)⋯(n − m + 1) |
| 無順序 unordered | C(n + m − 1, m) | C(n, m) = P(n, m)/m! |

「可重複」：第一次拿了 1 號，第二次還可以再拿 1 號。

### 有順序、可重複：nᵐ
每個位置都有 n 種，彼此不影響，n 連乘 m 次。

> **例題** 柳丁、蘋果、香蕉、芭樂 4 種水果，每種多到拿不完，擺到 6 個位置：每個位置 4 種，4⁶ = **4096**。

**函數個數**：|A| = m、|B| = n，A → B 的函數有 **nᵐ** 個（|B| 的 |A| 次方）。a₁ 可對到 n 個中任何一個，a₂ 也是 n 種且不受 a₁ 影響……上例就是 6 個位置（定義域）各對到 4 種水果之一。函數和「從 B 有順序、可重複地拿 m 個」一一對應。

**冪集合**：|S| = n，每個元素只有「在子集合裡」或「不在」兩種命運，所以 |P(S)| = **2ⁿ**（n = 3 有 8 個子集合）。

### 有順序、不重複：排列
第一個 n 種，第二個不能重複只剩 n − 1 種……第 m 個剩 n − m + 1 種：

**P(n, m) = n(n − 1)(n − 2)⋯(n − m + 1) = n!/(n − m)!**

排列就像排隊：排第一和排第二是不同結果，**位置有區別**。

> **例題** 6 個座位，請 100 位同學中挑人來坐：100 × 99 × 98 × 97 × 96 × 95 = P(100, 6)。

> **例題** 拆彈：炸彈上 10 條不同的電線，要**依序**剪 3 條（順序有關，就是排列）：10 × 9 × 8 = **720** 種，只有一種正確。

**一對一函數個數**：|A| = m、|B| = n，a₁ 有 n 種，a₂ 不能和 a₁ 撞，剩 n − 1 種……共 n(n − 1)⋯(n − m + 1) 個。例：m = 3、n = 4 有 4 × 3 × 2 = 24 個。需先 n ≥ m（B 比 A 小就不可能一對一，見鴿籠原理）。

### Permutation 與 n!
有限非空集合 A 的一個 **permutation** 定義為 A → A 的**對射**（bijection）。定義域與對應域一樣大，一對一就會 onto，反之亦然。通常取 A = {1, 2, …, n}。

例：n = 5，α(1) = 2、α(2) = 4、α(3) = 5、α(4) = 1、α(5) = 3，寫成兩列：

```
1 2 3 4 5
2 4 5 1 3
```

就是把 1 2 3 4 5 重新排一次。上面那列固定，常只寫下面那列。

所有 permutation 的集合記作 **Sₙ**。兩個 permutation 可以合成，滿足封閉、結合、有單位元素、有反元素，構成**對稱群**（symmetric group）；n ≥ 3 時沒有交換律（non-Abelian group）。

|Sₙ| = n(n − 1)⋯1 = **n!**（n factorial）。正式定義是遞迴的：**0! = 1**，n! = n·(n − 1)!（n ≥ 1）。1! = 1·0! = 1，2! = 2……沒有負數的階乘。

> **例題** TALES 的 5 個字母（全不同）排一列：5 × 4 × 3 × 2 × 1 = 5! = **120**。走一次：第 1 格挑 L，第 2 格從 A、T、E、S 挑 S，再挑 E，再挑 A，最後只能放 T。

### 相鄰問題：綁成一個單位
> **例題** 10 個人 P1～P10 排一列：10! = 3,628,800（n! 長得極快）。
> 若 P2、P6、P9 一定要站在一起：先把三人綁成一個單位 G = {P2, P6, P9}，加上其他 7 人共 8 個單位，排列 8! 種；G 裡面還能排 3! 種。
> 8! × 3! = **241,920**。

> **例題** A～H 八個字母排列。
> (1) **包含字串 ABC**（A、B、C 相鄰且照 A、B、C 的順序）：把 ABC 看成一個單位，共 6 個單位，6! = **720**。例如 A D E C B G F H（沒相鄰）不算；B C A D E F G H（相鄰但順序不對）也不算。
> (2) **A、B、C 相鄰即可**（順序不限）：外面 6!，裡面 ABC、ACB、BAC、BCA、CAB、CBA 共 3! 種，6! × 3! = **4320**。

> **陷阱** 「包含字串 ABC」是相鄰而且照順序；「ABC 相鄰」沒規定順序，要再乘 3!。兩題很像，答案差 6 倍。

### 有相同物的排列
> **例題** SUCCESS 有 7 個字母（S 3 個、C 2 個、U、E 各 1 個）。
> 先標號假裝都不同：S₁、S₂、S₃、C₁、C₂，共 7! 種。但 3 個 S 互換有 3! 種看起來一樣，2 個 C 互換有 2! 種看起來一樣：
> 7!/(3! × 2!) = 5040/12 = **420**。U、E 只有一個，除以 1! = 1，省略不寫。

> **例題** BARBARIC：8 個字母，B、A、R 各 2 個，I、C 各 1 個。
> 8!/(2! × 2! × 2!) = 40320/8 = **5040**。

一般式（**多項係數**，multinomial coefficient）：n 個東西，第 i 種有 nᵢ 個，

**n!/(n₁! n₂! ⋯ nₖ!)**

TALES 也可看成 5!/(1!·1!·1!·1!·1!)。

> **陷阱** 有相同的東西，就要除以它個數的階乘；漏除會把同一個字算好幾次。

> **例題** 長度 n、**恰有 r 個 1** 的 0/1 字串：n!/(r!(n − r)!)。n = 7、r = 3：35 個。

### 格子路徑
> **例題** 從 (0, 0) 走到 (4, 4)，每步只能往東（E）或往北（N）：要 4 個 E、4 個 N。每條路對應一個字串，例如 EEEENNNN、NENNENEE（北、東、北、北、東、北、東、東，確實到得了）。
> 路徑數 = 這 8 個字母的排法數 = 8!/(4! × 4!) = **70**。

一般：從 (a, b) 走到 (c, d)，令 m = c − a（往東步數）、n = d − b（往北步數）：

**(m + n)!/(m! n!) = C(m + n, m)**（m + n 步中挑 m 步往東）

> **陷阱** 公式只在 c ≥ a、d ≥ b 時成立；終點在左下方又只准往東、往北走，答案是 0。

### 無順序、不重複：組合
只看最後拿到什麼，不管順序。

> **比喻** 百貨公司比賽：一分鐘內搬到的東西都是你的。先搬冰箱再搬冷氣，或反過來，結果一樣。

**r-combination**：先當排列算 P(n, r)，同樣 r 個東西的 r! 種順序在組合裡算同一種，除掉：

**C(n, r) = P(n, r)/r! = n(n − 1)⋯(n − r + 1)/r! = n!/(r!(n − r)!)**

例：10 樣東西挑 5 樣，C(10, 5) = 30240/120 = **252**。符號有 C(n, r)、Cⁿᵣ，或括號上 n 下 r（念「n 取 r」），叫**二項式係數**（binomial coefficient）。

用乘積 n(n − 1)⋯(n − r + 1)/r! 定義的好處：n < r 時分子一定乘到 0，答案自動是 0；若用 n!/(r!(n − r)!)，會出現負數的階乘而沒有定義。這個定義之後還能推廣到上面是負數甚至實數（廣義二項式係數）。

> **例題** A 有 8 個元素。
> - 3 個元素的子集合：C(8, 3) = 8·7·6/3! = **56**。
> - 5 個元素的子集合：C(8, 5) = **56**。挑 3 個要的，等於挑 5 個不要的。
> - 9 個元素的子集合：C(8, 9) = 8·7·⋯·1·0/9! = **0**。

**對稱性**：0 ≤ r ≤ n 時 **C(n, r) = C(n, n − r)**（選要的 = 選不要的）。考試很好用，要熟到一看就知道。

### 組合題的限制條件
> **例題** 考卷 10 題，學生答其中 7 題（只在乎選哪 7 題）。
> (1) 無限制：C(10, 7) = C(10, 3) = **120**。
> (2) 第 1、2 題必答：C(2, 2) × C(8, 5) = **56**（就是後 8 題選 5 題）。
> (3) 前 6 題至少答 4 題：分情況（不重疊，相加），前區、後區的選法相乘：
> ```
> 前 6 題答 4、後 4 題答 3：C(6,4)·C(4,3) = 15·4 = 60
> 前 6 題答 5、後 4 題答 2：C(6,5)·C(4,2) = 6·6  = 36
> 前 6 題答 6、後 4 題答 1：C(6,6)·C(4,1) = 1·4  = 4
> 合計 100
> ```
> 也可寫成 ∑ᵢ₌₀² C(6, 4 + i)·C(4, 3 − i) = 100。

> **陷阱** 不能寫成 C(6, 4) × C(6, 3)（先從前 6 題選 4 題，再從剩下 6 題任選 3 題），那會把同一種選法重複計算。

## 可重複的組合：星棒法

### 從窮舉到星棒
> **例題** 蘋果、柳丁、梨子三種，挑 4 個，可以重複挑。
> **決策樹**（decision tree）窮舉：蘋果挑 0～4 個；在此前提下柳丁挑 0 到（剩下的數量）；梨子沒得選，只能補到 4。數葉子共 15 個。
> **星棒法**（stars and bars）：結帳時 4 個水果是 4 顆星，按種類排（蘋果、柳丁、梨子），三種要 2 根分隔棒隔開。
> ```
> ★ | ★★ | ★     蘋果 1、柳丁 2、梨子 1
>   | ★★ | ★★    蘋果 0、柳丁 2、梨子 2
>   |    | ★★★★  蘋果 0、柳丁 0、梨子 4
> ```
> 每種買法剛好對應一種星棒排列（一對一，不多也不漏）。4 顆星 + 2 根棒共 6 個東西，星都一樣、棒都一樣：6!/(4! × 2!) = **15**，和窮舉一樣。

### 非負整數解
**x₁ + x₂ + ⋯ + xₙ = k 的非負整數解個數 = C(n + k − 1, k) = C(n + k − 1, n − 1)**

想成把 k 個一樣的東西分進 n 個不同的箱子（每箱可空），n 個箱子要 n − 1 根隔板，k 顆星加 n − 1 根隔板共 n + k − 1 個位置，挑 n − 1 個放隔板。也有書用 H 表示這個數（重複組合）。

> **例題** x₁ + x₂ + x₃ = 12，非負整數解。例：6、2、4 是一組；隔板擠到兩端也行，如 0、12、0。
> 14 個位置挑 2 個放隔板：C(14, 2) = C(14, 12) = **91**。

> **例題** x₁ + x₂ + x₃ = 11 的自然數（含 0）解：11 顆星、2 根棒，13!/(11! × 2!) = C(13, 2) = **78**。

### 正整數解與下限
**正整數解**：每個 xᵢ ≥ 1，先每人發一個，剩下的再自由分。

> **例題** x₁ + x₂ + x₃ = 11，xᵢ ≥ 1：先各給 1 個，剩 8 個，x₁′ + x₂′ + x₃′ = 8，C(10, 2) = **45**。

> **例題** x₁ + x₂ + x₃ = 12，每個 xᵢ ≥ 2：令 xᵢ = yᵢ + 2（yᵢ ≥ 0），即每箱先放 2 個。
> y₁ + y₂ + y₃ = 12 − 6 = 6，C(3 + 6 − 1, 6) = C(8, 2) = **28**。

> **陷阱** 變數代換的方向是 xᵢ = yᵢ + 2（先放下限，再分剩下的），不要寫反成 y = x + 2。

> **例題** x₁ + x₂ + x₃ = 11，x₁ ≥ 3、x₂ ≥ 1、x₃ ≥ −1，整數解。
> 令 x₁ = x₁′ + 3、x₂ = x₂′ + 1、x₃ = x₃′ − 1（新變數都 ≥ 0）。x₃ ≥ −1 可以想成它可以「吐一個出來」。
> 代回：x₁′ + x₂′ + x₃′ = 11 − 3 − 1 + 1 = 8，C(10, 2) = **45**。

> **陷阱** 下限是負數也照樣換：x₃ = x₃′ − 1，右邊要加回 1。

### 上限：交給排容
> **例題** 同上題，再加上 x₁ ≤ 5（即 3 ≤ x₁ ≤ 5）。
> 用排容：所有 x₁ ≥ 3 的解，扣掉 x₁ ≥ 6 的解。x₁ ≥ 6 時令 x₁ = x₁″ + 6，總和變 11 − 6 − 1 + 1 = 5，C(7, 2) = 21。
> 45 − 21 = **24**（列舉檢查也是 24）。條件更多時就要真正用排容原理。

### 文字題
> **例題** 8 顆一樣的白球放進 4 個不同的箱子：x₁ + x₂ + x₃ + x₄ = 8。
> - 可以空箱：C(4 + 8 − 1, 8) = C(11, 8) = **165**。
> - 箱子不能空：先每箱放 1 顆，剩 4 顆，C(4 + 4 − 1, 4) = C(7, 3) = **35**。

> **陷阱** 題目若說「箱子不能空」，就不能用 xᵢ ≥ 0 的公式；要先每箱放一顆。

> **例題** x₁ + x₂ + x₃ + x₄ = 8，xᵢ ≥ 0，且 **x₄ 是奇數**。x₄ 只能是 1、3、5、7，四種情況互斥，分開算再相加：
> ```
> x₄ = 1：x₁ + x₂ + x₃ = 7，C(9, 7) = 36
> x₄ = 3：x₁ + x₂ + x₃ = 5，C(7, 5) = 21
> x₄ = 5：x₁ + x₂ + x₃ = 3，C(5, 3) = 10
> x₄ = 7：x₁ + x₂ + x₃ = 1，C(3, 1) = 3
> 合計 70
> ```

## 二項式定理

### 巴斯卡三角形與二項式定理
(x + y)² = x² + 2xy + y²，(x + y)³ = x³ + 3x²y + 3xy² + y³。係數排成**巴斯卡三角形**（Pascal triangle）：兩邊是 1，中間是上面兩個相加。

```
            1                 C(0,0)
          1   1               C(1,0) C(1,1)
        1   2   1
      1   3   3   1
    1   4   6   4   1
  1   5  10  10   5   1
```

**二項式定理**（binomial theorem）：

**(x + y)ⁿ = ∑ᵣ₌₀ⁿ C(n, r) xⁿ⁻ʳ yʳ**

xⁿ 的係數 C(n, 0)，xⁿ⁻¹y 的係數 C(n, 1)，xⁿ⁻²y² 的係數 C(n, 2)……

**為什麼係數是 C(n, r)**：(x + y)ⁿ 是 n 個括號相乘，「乘開」就是每個括號挑一項乘起來，再把所有挑法加起來。例如 n = 5，第 1 個挑 x、第 2 個挑 y、第 3、4 個挑 x、第 5 個挑 y，得 x³y²，貢獻係數 1。n 個括號中有 r 個挑 y、n − r 個挑 x，就得 xⁿ⁻ʳyʳ，所以**每項次數加起來一定是 n**；xⁿ⁻ʳyʳ 的係數 = 從 n 個括號挑 r 個出 y 的方法數 = C(n, r)。例：x³y² 的係數是 C(5, 2) = 10。

> **例題** (x + y)ⁿ 展開中 xⁿ⁻³y² 的係數？答案 0：次數 (n − 3) + 2 ≠ n，這種項不會出現。

> **陷阱** 不要死背公式；懂了「每個括號挑一項」，想一想就出來了。

### Pascal 恆等式
**C(n + 1, k) = C(n, k − 1) + C(n, k)**（等價寫法：C(n, r) = C(n − 1, r − 1) + C(n − 1, r)），這就是巴斯卡三角形「每格等於上面兩格相加」。例：C(3, 1) = C(2, 0) + C(2, 1) = 1 + 2 = 3。

可以把三個組合數寫成階乘硬算驗證，但**組合式證明**（combinatorial proof）只要說一個數數的故事：

> **例題** 左邊：n + 1 個東西挑 k 個。盯住其中一個（假設是一顆鑽石）：
> - 拿了鑽石：剩 n 個東西還要挑 k − 1 個，C(n, k − 1)。
> - 不拿鑽石：從剩下 n 個挑滿 k 個，C(n, k)。
> 兩種情況不重疊，相加就是左邊。
> 另一種說法：{1, …, n} 的 r 元素子集合，含 n 的有 C(n − 1, r − 1) 個，不含 n 的有 C(n − 1, r) 個。

組合式證明：左右兩邊數的是同一個東西，只是數法不同，所以一定相等。三角形最左、最右都是 1，因為 C(n, 0) = C(n, n) = 1。（三角形以 17 世紀法國數學家 Pascal 命名，他也做過機械計算機。）

### 用二項式定理證恆等式
二項式展開對任何 x、y 都成立，所以可以代特別的值。

> **例題** **∑ᵣ₌₀ⁿ C(n, r) = 2ⁿ**。
> 代 x = y = 1：(1 + 1)ⁿ = 2ⁿ，右邊只剩係數總和。
> 組合解釋：2ⁿ 是 n 元素集合的子集合總數，左邊是按子集合大小 0、1、…、n 分類各自數再加。n = 4：1 + 4 + 6 + 4 + 1 = 16。

> **例題** **∑ᵣ₌₀ⁿ (−1)ʳ C(n, r) = 0**（加減交錯）。
> 代 x = 1、y = −1：(1 − 1)ⁿ = 0。例：1 − 4 + 6 − 4 + 1 = 0，1 − 5 + 10 − 10 + 5 − 1 = 0。

> **例題** **∑ᵣ₌₀ⁿ 2ʳ C(n, r) = 3ⁿ**：代 x = 1、y = 2，(1 + 2)ⁿ = 3ⁿ。

> **例題** **∑ᵣ₌₀ⁿ C(n, r)² = C(2n, n)**。光代值不夠，改**比較係數**：
> (1 + x)ⁿ(1 + x)ⁿ = (1 + x)²ⁿ。右邊 xⁿ 的係數是 C(2n, n)。
> 左邊要乘出 xⁿ：第一個取 xʳ 項、第二個取 xⁿ⁻ʳ 項，係數 C(n, r)·C(n, n − r)，r 從 0 加到 n；又 C(n, n − r) = C(n, r)，所以是 ∑ C(n, r)²。
> n = 3：1 + 9 + 9 + 1 = 20 = C(6, 3)。
> 套路：同一個量用兩種方法看，結果就是等式的兩邊。

## 鴿籠原理

### 直覺與敘述
4 隻鴿子放進 3 個籠子：隨便放可能是 3、0、1；想讓每籠只放一隻，三籠各一隻後還剩第 4 隻，只能塞進有鴿子的籠子，變成 2、1、1。不管怎麼放，總有一籠超過一隻。

**鴿籠原理**（pigeonhole principle，也叫抽屜原理、Dirichlet drawer principle）：把 m 隻鴿子（物品 items）放進 n 個鴿籠（容器 containers），若 **m > n**，則某個鴿籠裡**超過一隻**鴿子。

> **比喻** 一個蘿蔔一個坑，蘿蔔比坑多，就有一個坑有兩個以上的蘿蔔。

**證明（逆否）**：假設結論不對，即每個鴿籠最多一隻，n 個鴿籠最多 n 隻鴿子，與 m > n 矛盾。

### 推廣：⌈N/k⌉
> **比喻** 三人吃火鍋，店家送 4 顆蛋，蛋不能切。平均每人 4/3 ≈ 1.33 顆，多出的 0.33 一定落在某人身上，所以至少有人拿 2 顆。也可能有人全拿 4 顆，結論照樣成立。

**推廣的鴿籠原理**：N 個物品放進 k 個容器，**至少有一個容器有 ⌈N/k⌉ 個以上**（⌈ ⌉ 是上高斯 ceiling，有小數就無條件進位）。

證明（反證）：若每個容器都少於 ⌈N/k⌉，即每個 ≤ ⌈N/k⌉ − 1 < N/k，加起來少於 N，矛盾。

- 4 隻鴿子、3 籠：⌈4/3⌉ = 2。
- 10 個物品、4 個容器：10/4 = 2.5，再平均也只能 3、3、2、2，⌈2.5⌉ = 3。它保證的是「不可能每箱都少於 3 個」：每箱最多 2 個，4 箱只裝得下 8 個。

> **陷阱** ⌈N/k⌉ 保證的是「至少」，不是每個人都這麼多，也不是最多只有這麼多；10 個全擠在同一箱也符合。

> **陷阱** 中文「以上」含等號（≥），「之上」不含（>）。

### 小例子
- 成績 0～100 分共 101 種（101 個籠子），班上超過 101 人，至少兩人同分。
- 280 位同學、一年 52 週每週辦一次慶生會：280/52 ≈ 5.38，⌈5.38⌉ = 6，至少有一週要準備 6 個以上的蛋糕。
- 366 人、一年 365 天：⌈366/365⌉ = 2，至少兩人同天生日（也可能大家擠在同一天）。若把 2 月 29 日也算進去有 366 個籠子，要 367 人才保證。

### 函數版本
f : A → B，A、B 為有限集合：
- f 一對一（injective）的必要條件：**|A| ≤ |B|**。逆否：**|A| > |B| ⇒ f 不是一對一**（鴿子比籠子多，某個 b 被對到兩次）。
- f 映成（onto）的必要條件：**|A| ≥ |B|**（A 只有 5 個、B 有 10 個，最多對到 5 個）。|A| < |B| ⇒ 不是 onto。
- f 是對射（bijection）⇒ **|A| = |B|**。常用來證明兩個有限集合一樣大：做出一個 bijection 就好。

應用時只要分清楚誰是鴿子、誰是鴿籠，把兩邊數目算出來比一比。

## 設計鴿籠：經典應用
大部分題目鴿子很明顯，難在決定哪些東西放同一籠、籠子有幾個。沒有萬用方法，多看多想。

> **例題** 50 萬個英文字，每個由 4 個以內的小寫字母組成，可能全都不同嗎？
> 4 個字母以內的字共 26 + 26² + 26³ + 26⁴ = 26 + 676 + 17,576 + 456,976 = **475,254** 種。
> 50 萬（鴿子）> 475,254（鴿籠），至少兩個字一樣，不可能全不同。若只有 40 萬個字，就推不出來（可能全不同）。

> **例題** 任何有限人群（至少 2 人，朋友關係是互相的），一定有兩人在群內的朋友數相同。
> 小例子：4 人，1–2、1–4、3–4 是朋友，朋友數 2、1、1、2，果然有人一樣。
> 證明：定義 f(x) = x 在群內的朋友數，要證 f 不是一對一。設群有 m 人，朋友數可能是 0、1、…、m − 1，也是 m 個值，光數目推不出來。
> 關鍵：若有人有 m − 1 個朋友（和其他所有人都是朋友），朋友是互相的，其他每人至少有他這個朋友，就沒有人是 0。所以 **0 和 m − 1 不會同時出現**，f 的值域最多 m − 1 個值。m 個人放進 m − 1 個籠子，必有兩人朋友數相同。
> （若假設每人至少 1 個朋友，籠子直接是 1～m − 1，更簡單；但上面的證法連有人 0 個朋友的情況也處理了。）

> **陷阱** 直接拿 0～m − 1 當鴿籠有 m 個，和人數一樣多，推不出結論；關鍵是 0 和 m − 1 不能並存。卡住時，找個小例子試試就會看到。

> **例題** 從 1～20 任挑 11 個數，一定有兩數和為 21。
> 把和為 21 的兩數配成一組當籠子：{1, 20}、{2, 19}、{3, 18}、{4, 17}、{5, 16}、{6, 15}、{7, 14}、{8, 13}、{9, 12}、{10, 11}，共 **10 個籠子**，每個數剛好在一組。
> 11 個數放進 10 組，⌈11/10⌉ = 2，有一組兩個數都被挑到，和為 21。（反例試探：每組只挑一個如 1～10，就湊不出 21，但只有 10 個；第 11 個例如 19，和 2 同組，2 + 19 = 21。）

> **陷阱** 籠子是 10 對，不是 20 個數；寫成 ⌈11/20⌉ 是錯的。

> **例題** 從 1～200 任取 101 個不同整數，一定有一個整除另一個。
> 把每個 x 寫成 **x = 2ᵏ·y**，k ≥ 0，y 是奇數（2 的因數全提出來，gcd(2, y) = 1）。寫法唯一。例：28 = 2²·7。
> y 是 1～200 的奇數，只有 100 種（1, 3, …, 199），就是 100 個籠子。101 個數，必有兩個 y 相同：a = 2ᵐ·y、b = 2ⁿ·y，a ≠ b 所以 m ≠ n。
> 若 m < n，a | b（例：28 = 2²·7 整除 56 = 2³·7）；若 m > n，b | a。
> （a | b 讀作 a divides b：存在整數 c 使 b = ac。）

> **例題** 8 cm × 8 cm 的正方形畫成 16 個 2 cm × 2 cm 的小方格，放 17 個點，一定有兩點距離 ≤ √8 cm。
> 16 個小方格是 16 個籠子，17 個點必有兩點在同一格；同一個 2 × 2 小格內兩點最遠是對角線 √(2² + 2²) = √8。
> 反過來問「最少幾個點才能保證」：要讓 ⌈N/16⌉ = 2，N = 16 時 ⌈16/16⌉ = 1 不保證，**N = 17**。若題目沒畫格子，就要自己想出切法（讓小塊的對角線剛好是 √8，即邊長 2 的正方形）。

> **例題** 邊長 1 的等邊三角形**內部**（不含邊上）放 5 個點，一定有兩點距離 < ½。
> 連接三邊中點，切成 4 個邊長 ½ 的小等邊三角形（4 個籠子）。5 點放進 4 塊，必有兩點同塊；同塊內兩點最遠是邊長 ½，只有兩個頂點才等於 ½，點都在內部，所以距離 < ½。

> **例題** 對任何正整數 n，都存在 n 的倍數 m，m 的十進位數字只有 0 和 1。
> 例：n = 5，m = 10；n = 3，m = 111。
> 想法：兩數除以 n 的餘數相同，相減就是 n 的倍數。除以 n 的餘數有 0～n − 1 共 n 種（n 個籠子）。取 n + 1 個數 1, 11, 111, …, 11⋯1（n + 1 個 1），必有兩個同餘，長的減短的，得到「一串 1 後接一串 0」，是 n 的倍數。
> 例：n = 4，11 和 111 除以 4 都餘 3，111 − 11 = 100 是 4 的倍數。

> **例題** 10 顆外觀相同的球，只有一顆比較重。天平（不是秤）只告訴你左重、右重、一樣重三種結果，只准用兩次。有沒有方法保證找出重球？
> 兩次最多看到 3 × 3 = **9** 種結果，但要分辨 **10** 種情況（重球是第 1～10 顆）。10 種情況是鴿子、9 種結果是鴿籠，至少兩種情況（例如第 4 顆重、第 8 顆重）會看到一模一樣的結果，分不出來。所以不可能，不必檢查任何人的方法。
> 衍生題：12 顆球有一顆重量不同（可能重或輕），天平用 3 次。情況 12 × 2 = 24 種，結果 3³ = 27 種，24 < 27 只代表「有可能」，方法要另外想出來（這題確實做得到）。

> **陷阱** 鴿籠原理只能證明「不可能」；結果數 ≥ 情況數不代表方法一定存在，要另外構造。

## 重點整理
- 加法原理：互斥情況選一種，相加（需 disjoint）；乘法原理：每步都做，相乘；|A × B| = |A||B|。
- 「至少一個」= 全部 − 一個都沒有。
- 有順序可重複 nᵐ；有順序不重複 P(n, m) = n!/(n − m)!；無順序不重複 C(n, m)；無順序可重複 C(n + m − 1, m)。
- A → B 函數 |B|^|A| 個；一對一函數 n(n − 1)⋯(n − m + 1) 個；|P(S)| = 2ⁿ。
- Permutation = A → A 的對射，|Sₙ| = n!，0! = 1。
- 相鄰：綁成一個單位，裡面再乘內部排法；「包含字串 ABC」不再乘 3!。
- 相同物排列 n!/(n₁!⋯nₖ!)：SUCCESS 420、BARBARIC 5040。
- 格子路徑 (m + n)!/(m!n!)：(0,0)→(4,4) 共 70 條。
- C(n, r) = C(n, n − r)；n < r 時 C(n, r) = 0；「至少」的限制要分情況相加，不能 C(6,4)·C(6,3)。
- x₁ + ⋯ + xₙ = k 非負整數解 C(n + k − 1, k)；下限先放（xᵢ = yᵢ + 下限），上限用排容。
- (x + y)ⁿ = ∑ C(n, r)xⁿ⁻ʳyʳ，次數和必為 n；Pascal：C(n + 1, k) = C(n, k − 1) + C(n, k)。
- ∑ C(n, r) = 2ⁿ；∑ (−1)ʳC(n, r) = 0；∑ 2ʳC(n, r) = 3ⁿ；∑ C(n, r)² = C(2n, n)。
- 鴿籠：m > n 必有一籠 ≥ 2；推廣至少 ⌈N/k⌉；|A| > |B| ⇒ 不是一對一。
- 設計鴿籠：和為 21 配 10 對；x = 2ᵏ·y 看奇數部分；切方格／切三角形；餘數；結果數 vs 情況數。
