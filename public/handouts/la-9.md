# SVD與應用

奇異值分解（singular value decomposition，SVD）是矩陣「最後、也最好」的分解：任何矩陣（長方形、不可逆都可以）都能寫成 A = UΣVᵀ，正交 × 對角 × 正交。它替四個基本子空間各選出「對的」標準正交基底，讓 A 變成對角的 Avᵢ = σᵢuᵢ。這一章學 SVD 的由來與手算步驟、怎麼從 Σ 讀出矩陣的性質、把 A 展開成 rank 1 矩陣的和與最佳低秩近似（Eckart–Young），以及左反矩陣、右反矩陣與 Moore-Penrose 虛反矩陣 A⁺ = VΣ⁺Uᵀ；最後用一組綜合題把整門課（特徵值、對稱、正定、Markov、最小平方）串起來。考試重點：SVD 手算（AᵀA 的特徵值 → σᵢ → V → uᵢ = Avᵢ/σᵢ）、低秩近似的意義、pseudo-inverse。

## 學完這章要會
- 說出 A = UΣVᵀ 中 U、Σ、V 的大小、意義（旋轉／反射、伸縮、旋轉／反射）與它們跟四個子空間的關係。
- 由 AᵀA = V(ΣᵀΣ)Vᵀ 推出：V 是 AᵀA 的特徵向量、σᵢ = √λᵢ；U 是 AAᵀ 的特徵向量。
- 照五個步驟手算 SVD，並用 uᵢ = Avᵢ/σᵢ 避開正負號錯誤。
- 從 Σ 讀出可逆性、rank、null space、|det A|。
- 寫出 A = σ₁u₁v₁ᵀ + … + σᵣuᵣvᵣᵀ，分辨 full / economy / truncated SVD，說明 Eckart–Young。
- 求 left inverse (AᵀA)⁻¹Aᵀ、right inverse Aᵀ(AAᵀ)⁻¹，知道反過來乘得到投影矩陣。
- 說明 A⁺ 是 row space ↔ column space 的反對應，用 A⁺ = VΣ⁺Uᵀ 計算，知道 A⁺b 是最短的最小平方解。

## SVD：正交 × 對角 × 正交

### 為什麼要兩個正交矩陣
- 對稱正定矩陣 S = QΛQᵀ（例如 [2 1; 1 2]）本身就是一個 SVD：左右用同一個正交矩陣，U = V = Q。
- 一般的對角化 A = SΛS⁻¹ 裡，特徵向量矩陣 S 通常不是正交的。例如 [1 2; 0 3] 的特徵向量 (1, 0)、(1, 1) 內積是 1，不垂直；有些矩陣（如 [4 4; −3 3]）連實數特徵向量都沒有。
- 所以 SVD 的新地方是：需要**兩個**正交矩陣 U、V，通常不一樣；而且**任何**矩陣都有 SVD。

```
 A = U Σ Vᵀ
 A：m×n，rank r
 U：m×m 正交矩陣（左奇異向量 left singular vectors）
 Σ：m×n 對角矩陣，對角線 σ₁ ≥ σ₂ ≥ … ≥ σᵣ > 0，其餘為 0
 V：n×n 正交矩陣（右奇異向量 right singular vectors）
```

### 幾何意義：轉 → 伸縮 → 轉
- Vᵀ：旋轉或反射，把 v₁、v₂ 轉到座標軸上。
- Σ：沿座標軸伸縮，單位圓變成橢圓。σᵢ 叫**奇異值**（singular values），一定是正數。
- U：再旋轉或反射到最後位置。

合起來和直接乘 A 完全一樣：A 把單位圓送成一個橢圓，**橢圓的半軸方向是 uᵢ、長度是 σᵢ**。

### 目標：正交基被送成正交基
看大圖：A 把 row space 的向量送到 column space。
- 在 row space 找正交基不難（Gram-Schmidt），例如 e₁、e₂。但隨便一組正交基乘上 A 之後通常不垂直：A = [4 4; −3 3] 把 e₁、e₂ 送到 (4, −3)、(4, 3)，內積 16 − 9 = 7 ≠ 0。
- SVD 要找的是特別的一組：row space 的標準正交基 v₁, …, vᵣ，被 A 送過去之後**仍然**互相垂直。Avᵢ 一般不是單位向量，而是某個單位向量 uᵢ 的倍數：

```
 A vᵢ = σᵢ uᵢ      （i = 1, …, r）
```

σ 是伸縮倍數（刻意不再叫 λ）。

### 寫成矩陣：AV = UΣ
把 v₁…vᵣ 排成矩陣的行、u₁…uᵣ 也排成行，右邊乘對角矩陣（把每一行乘上對應的 σ）：

```
 A [v₁ … vᵣ] = [u₁ … uᵣ] diag(σ₁, …, σᵣ)
```

null space 不是難處：在 V 後面補上 N(A) 的標準正交基 v_{r+1} … vₙ（乘 A 都是 0），在 U 後面補上 N(Aᵀ) 的標準正交基 u_{r+1} … uₘ，它們在 Σ 裡對應的都是 0。於是 V 是 Rⁿ 的標準正交基、U 是 Rᵐ 的標準正交基：

```
 AV = UΣ  ⇒  A = UΣV⁻¹ = UΣVᵀ     （方的正交矩陣 V⁻¹ = Vᵀ）
```

兩組標準正交基底把 A「對角化」成 Σ。只有對稱正定時才是 AQ = QΣ（同一組）。

### 讓 U 消失：AᵀA = V(ΣᵀΣ)Vᵀ
一次找兩個未知的正交矩陣太難，用 AᵀA 把 U 消掉：

```
 Aᵀ = (UΣVᵀ)ᵀ = VΣᵀUᵀ
 AᵀA = VΣᵀ(UᵀU)ΣVᵀ = V(ΣᵀΣ)Vᵀ       （UᵀU = I）
 AAᵀ = UΣ(VᵀV)ΣᵀUᵀ = U(ΣΣᵀ)Uᵀ       （VᵀV = I）
```

ΣᵀΣ 是對角矩陣，對角線 σ₁², σ₂², …。這正是對稱矩陣的 QΛQᵀ 形式，所以：

> **重點** V 的行 = AᵀA 的單位特徵向量；σᵢ² = AᵀA 的特徵值；U 的行 = AAᵀ 的單位特徵向量。AᵀA（the great matrix）一定對稱、至少半正定，所以特徵值 ≥ 0，開正平方根得 σ。AᵀA 和 AAᵀ 的非零特徵值一模一樣（AB 和 BA 的非零特徵值相同）。

> **陷阱** AAᵀ 只能決定 u 的方向，決定不了正負號（特徵向量整個變號還是特徵向量）。分別解 AᵀA、AAᵀ 再隨意配對，有一半的機會符號錯。正確做法：先定好 v（符號任選但只選一次），再用 **uᵢ = Avᵢ / σᵢ** 算 u，符號自動配好。

## 例題：A = [4 4; −3 3]（可逆）

> **例題** 求 A = [4 4; −3 3] 的 SVD。det = 12 + 12 = 24 ≠ 0，rank 2。
> 1. Aᵀ = [4 −3; 4 3]。AᵀA：左上 16 + 9 = 25，非對角 16 − 9 = 7，右下 25。AᵀA = [25 7; 7 25]（對稱）。
> 2. [a b; b a] 型矩陣的特徵向量是 (1, 1)、(1, −1)：AᵀA(1, 1) = (32, 32)，λ₁ = 32；AᵀA(1, −1) = (18, −18)，λ₂ = 18。
> 3. 單位化（不改變特徵值）：v₁ = (1, 1)/√2，v₂ = (1, −1)/√2。
> 4. σ₁ = √32，σ₂ = √18，Σ = [√32 0; 0 √18]。
> 5. u₁ = Av₁/σ₁ = (8, 0)/√2 ÷ √32 = (8/8, 0) = (1, 0)。u₂ = Av₂/σ₂ = (0, −6)/√2 ÷ √18 = (0, −6/6) = (0, −1)。
> 6. U = [1 0; 0 −1]，A = UΣVᵀ。負號放在 U 裡，Σ 的對角線仍是正數。

為什麼會錯：若改用 AAᵀ 找 U，AAᵀ = [16+16 −12+12; −12+12 9+9] = [32 0; 0 18]，剛好是對角矩陣，特徵向量一眼是 (1, 0)、(0, 1)，特徵值又是 32、18。取 U = I 檢查 UΣVᵀ：第一列 √32·(1, 1)/√2 = 4(1, 1) = (4, 4) 對；第二列 √18·(1, −1)/√2 = 3(1, −1) = (3, −3)，但 A 的第二列是 (−3, 3)，**符號反了**。用 uᵢ = Avᵢ/σᵢ 就得到正確的 u₂ = (0, −1)。

幾何上：單位圓被 A 變成橢圓，兩個半軸是 √32·u₁ 和 √18·u₂。

## 例題：A = [4 3; 8 6]（rank 1）

> **例題** 求 A = [4 3; 8 6] 的 SVD。第二列是第一列的 2 倍，rank 1。
> 1. 四個子空間（都在 R² 裡、都是 1 維）：row space 是 (4, 3) 的倍數；null space 是垂直它的線，例如 A(3, −4) = (12 − 12, 24 − 24) = 0；column space：兩個 column (4, 8)、(3, 6) 都是 (1, 2) 的倍數；N(Aᵀ) 是垂直 (1, 2) 的線。
> 2. v₁ = (4, 3) 單位化 = (0.8, 0.6)；u₁ = (1, 2)/√5。
> 3. AᵀA = [16+64 12+48; 12+48 9+36] = [80 60; 60 45]，也是 rank 1（每列是 (4, 3) 的倍數），一個特徵值是 0，另一個 = trace = 125。σ₁ = √125，σ₂ = 0。
> 4. 補成標準正交基：v₂ = (0.6, −0.8)（null space），u₂ = (2, −1)/√5（N(Aᵀ)）。
> 5. 檢查：σ₁u₁v₁ᵀ = √125 · (1, 2)/√5 · (0.8, 0.6)ᵀ = 5 · [0.8 0.6; 1.6 1.2] = [4 3; 8 6] = A（√125/√5 = √25 = 5）。

null space 的 v₂、N(Aᵀ) 的 u₂ 都只乘到 0，好處理；關鍵是 row space 與 column space 那一對 v₁、u₁。

## SVD = 四個子空間的標準正交基

| 向量 | 是哪個子空間的標準正交基 | 維度 |
|---|---|---|
| v₁ … vᵣ | row space C(Aᵀ) | r |
| u₁ … uᵣ | column space C(A) | r |
| v_{r+1} … vₙ | null space N(A) | n − r |
| u_{r+1} … uₘ | left null space N(Aᵀ) | m − r |

Gram-Schmidt 也能做出正交基；SVD 多用了特徵值，因為這組基底讓矩陣變對角：每個 vᵢ 只對到同一號的 uᵢ（Avᵢ = σᵢuᵢ），null space 的對到 0，彼此互不牽扯。例二的四個維度是 1、1、1、1。

## Σ 的形狀
Σ 和 A 一樣是 m×n，對角線依大到小放 σ₁ ≥ … ≥ σᵣ > 0，σᵢ = √λᵢ（λᵢ 是 AᵀA、也是 AAᵀ 的非零特徵值）。例：[2 2; −1 1] 的 AᵀA = [5 3; 3 5]、AAᵀ = [8 0; 0 2]，非零特徵值都是 8、2。

- m > n（高）：上面一塊 n×n 對角，下面補 m − n 列 0。
- m < n（寬）：右邊補 n − m 行 0。
- 方陣但 rank 不足（r < n）：對角線後面的 σ 是 0。

## 手算 SVD 五步驟

> **例題** 求 A = [1 1; 1 0; 0 1] 的 SVD。
>
> **步驟一：大小與 rank。** A 是 3×2，所以 U 是 3×3（邊長 = A 的列數）、Σ 是 3×2（和 A 一樣）、V 是 2×2（邊長 = A 的行數）。化成 echelon form：R₂ − R₁ 得 (0, −1)，R₃ + 新 R₂ 得 (0, 0)，[1 1; 0 −1; 0 0]，兩個 pivot，r = 2。
>
> **步驟二：求 Σ。** AᵀA = [1 1 0; 1 0 1][1 1; 1 0; 0 1] = [2 1; 1 2]。det(AᵀA − λI) = (2 − λ)² − 1 = 0，λ = 3、1。慣例最大的放第一個：σ₁ = √3、σ₂ = 1。m = 3 > n = 2，下面補一列 0：Σ = [√3 0; 0 1; 0 0]。
>
> **步驟三：求 V。** 本題 n = r = 2，V 的兩行就是 AᵀA 的單位特徵向量。λ = 3：AᵀA − 3I = [−1 1; 1 −1]，rref [1 −1; 0 0]，x₁ = x₂，取 (1, 1)，v₁ = (1/√2, 1/√2)。λ = 1：[1 1; 1 1]，rref [1 1; 0 0]，x₁ = −x₂，取 (−1, 1)，v₂ = (−1/√2, 1/√2)。VᵀV = I。
>
> **步驟四：求 U。** 前 r 個用 uᵢ = Avᵢ/σᵢ。u₁ = (1/√3)·A(1, 1)/√2 = (2, 1, 1)/√6。u₂ = A(−1, 1)/√2 = (0, −1, 1)/√2。v 是單位向量，這樣算出的 u 自動是單位向量且 u₁ ⟂ u₂。剩下 m − r = 1 個從 Aᵀx = 0 來：Aᵀ = [1 1 0; 1 0 1]，rref [1 0 1; 0 1 −1]，x₁ = −x₃、x₂ = x₃，取 x = (−1, 1, 1)，u₃ = (−1, 1, 1)/√3（垂直整個 column space）。
>
> **步驟五：組合並檢查。** 記得 V 要轉置：

```
     [2/√6    0     −1/√3]   [√3  0]
 A = [1/√6  −1/√2    1/√3] · [ 0  1] · [ 1/√2  1/√2]
     [1/√6   1/√2    1/√3]   [ 0  0]   [−1/√2  1/√2]
```

乘回去等於 A。幾何上，A 把平面上的單位圓送到 R³ 裡的一個橢圓，兩個半軸是 √3·u₁ 和 1·u₂。

> **陷阱** 若 n > r，V 的後 n − r 行要從 Ax = 0 的解補上；若 m > r + 1，Aᵀx = 0 會給好幾個向量。補上的向量超過一個時，要用 Gram-Schmidt 變成互相垂直再單位化。

## 從 Σ 讀出矩陣的性質
考試可能只給 SVD 的零件，問矩陣的性質。
- Σ = [3 0; 0 2]（U、V 各有兩個正交的行）：σ 都不是 0 ⇒ A 可逆；單位圓被拉成半軸 3、2 的橢圓；**|det A| = σ₁σ₂ = 6**。
- 把 2 換成 −5：那就不是 SVD，**奇異值不可能是負的**。
- Σ = [3 0; 0 0]：A singular，橢圓被壓成一條線段；只有一個非零 σ，**rank = 1**；null space 維度 2 − 1 = 1，由 v₂ 張成（Av₂ = 0·u₂ = 0）；N(Aᵀ) 是 u₂ 的方向；column space 是 u₁ 的方向。

> **重點** rank = 非零奇異值的個數；|det A| = σ₁σ₂⋯σₙ（方陣）；N(A) 由「對到 0」的 v 張成，C(A) 由前 r 個 u 張成。

## SVD 展開與低秩近似

### 展開成 rank 1 矩陣的和
資料矩陣 X（例如 n×m，n 列、m 行）= UΣVᵀ，把 Vᵀ 看成一列一列的 v₁ᵀ, v₂ᵀ, …：
1. UΣ：Σ 對角，第 i 行只有 uᵢ 乘 σᵢ，所以 UΣ = [σ₁u₁ σ₂u₂ …]。
2. 再乘 Vᵀ：第 i 行 σᵢuᵢ 只和第 i 列 vᵢᵀ 配對（行 × 列）。

```
 X = σ₁u₁v₁ᵀ + σ₂u₂v₂ᵀ + … + σₘuₘvₘᵀ
```

奇異值由大到小排：σ 越大，對應的 u、v 越重要（u₁ 比 u₂ 重要……）。σ 小的項影響很小。

### 外積：每一項都是 rank 1
u（直的）乘 vᵀ（躺的）叫**外積**（outer product），結果是一個矩陣；對比內積（躺的乘直的）結果是一個數。

> **例題** u = (1, 2, −1)、vᵀ = (3 1 0 2)。u 的第 1 個數乘整個 vᵀ 得第 1 列，依此類推：

```
 uvᵀ = [ 3   1  0   2
         6   2  0   4
        −3  −1  0  −2 ]
```

每一列都是 vᵀ 的倍數、每一行都是 u 的倍數，只有一個獨立的列和行，所以 rank 1。

### Full、economy、truncated SVD
- **Full SVD**：U 是 n×n，但 X 只有 m 個 columns，rank ≤ m，σ_{m+1} 之後全是 0，對應的 u 乘到 0，對 X 沒有貢獻。
- **Economy SVD**（精簡 SVD）：只留 U 的前 m 行（Û，n×m）和 Σ 左上 m×m 的 Σ̂，V 不動。**X = ÛΣ̂Vᵀ 精確相等**，不是近似。高瘦（tall skinny）矩陣幾乎都該用它：例如每個 column 是一張一百萬像素的臉、只有一千人，完整的 U 會是一百萬 × 一百萬，太大又沒用。（數值軟體通常有 economy 選項，只回傳前 m 行。）
- **Truncated SVD**（截斷 SVD）：若後面的奇異值很小，只留前 r 個最大的：

```
 X ≈ X̃ = Ũ Σ̃ Ṽᵀ = σ₁u₁v₁ᵀ + … + σᵣuᵣvᵣᵀ      （rank r 近似）
```

### Eckart–Young 定理：最佳低秩近似
最好的 rank 1 近似是 σ₁u₁v₁ᵀ；加上 σ₂u₂v₂ᵀ 是最好的 rank 2 近似；依此類推。

> **重點** **Eckart–Young 定理**（1936）：在所有 rank r 的矩陣中，讓 ‖X − X̃‖_F（Frobenius norm，所有元素平方和開根號）最小的，就是截斷 SVD ŨΣ̃Ṽᵀ，誤差是 √(σ_{r+1}² + … + σₘ²)。任何其他 rank r 的矩陣都不會更接近 X；例如改留 σ₁、σ₃ 兩項，誤差就比留 σ₁、σ₂ 大很多。（用 2-norm 量時誤差是 σ_{r+1}，結論一樣。）

> **觀念** 低秩近似的意義：資料的資訊幾乎都集中在前幾個大奇異值裡。只存 r 個 σ、r 個 u、r 個 v，就能近似重建整個矩陣，用於壓縮、去雜訊、找主要模式。

### 截斷後的陷阱
> **陷阱** 完整的 U、V 是正交（複數時 unitary）矩陣：UᵀU = UUᵀ = I。截斷後 Ũ 只剩 r 行、不是方陣：**ŨᵀŨ 仍是 r×r 的 I**（留下的行還是標準正交），但 **ŨŨᵀ 不是 I**，它是 n×n、rank r 的投影矩陣（投影到 Ũ 的 column space，P² = P）。很多證明在這裡寫錯。

## 左反矩陣、右反矩陣與虛反矩陣

### 四種情形
m×n、rank r，四個子空間維度 r、n − r（Rⁿ）與 r、m − r（Rᵐ），row space ⟂ null space、column space ⟂ N(Aᵀ) 互為正交補。

| 情形 | 條件 | Ax = b 的解 | 反矩陣 |
|---|---|---|---|
| 1 | r = m = n | 恰一解 | 雙邊 A⁻¹（AA⁻¹ = I = A⁻¹A） |
| 2 | r = n < m（full column rank） | 0 或 1 個 | 左反矩陣 |
| 3 | r = m < n（full row rank） | 永遠有解、無限多 | 右反矩陣 |
| 4 | r < m、r < n | 0 或無限多 | 只有虛反矩陣 A⁺ |

長方形矩陣不可能有雙邊反矩陣：m ≠ n 時 A 或 Aᵀ 一定有 null space。

### Full column rank：左反矩陣
r = n：n 個 columns 獨立，N(A) = {0}，row space 是整個 Rⁿ。Ax = b 有解就只有一個（沒有 null space 向量可加）；但 rows 通常不獨立，有些 b（不在 column space）無解。這時 AᵀA 是 n×n、對稱、**可逆**：

```
 A⁻¹_left = (AᵀA)⁻¹Aᵀ ，   A⁻¹_left · A = (AᵀA)⁻¹(AᵀA) = I（n×n）
```

這就是最小平方的關鍵：A⁻¹_left b = x̂。

> **例題** A = [1 0; 0 1; 1 1]。AᵀA = [2 1; 1 2]（det 3），(AᵀA)⁻¹ = (1/3)[2 −1; −1 2]。A⁻¹_left = (1/3)[2 −1; −1 2][1 0 1; 0 1 1] = (1/3)[2 −1 1; −1 2 1]。b = A(1, 2) = (1, 2, 3) 在平面上，有唯一解；(1, 2, 4) 不在平面上，無解，A⁻¹_left 給出最小平方解。

這時 AAᵀ 是 3×3、det 0，不可逆。

### Full row rank：右反矩陣
r = m：rows 獨立，N(Aᵀ) = {0}。消去永遠不會出現零列，**Ax = b 永遠有解**，但有 n − m 個自由變數，解太多。這次好的是 AAᵀ（m×m 可逆）：

```
 A⁻¹_right = Aᵀ(AAᵀ)⁻¹ ，   A · A⁻¹_right = I（m×m）
```

> **例題** B = [1 0 1; 0 1 1]（上例的轉置），BBᵀ = [2 1; 1 2]。B⁻¹_right = (1/3)[2 −1; −1 2; 1 1]。b = (1, 2)：x = (1/3)(2 − 2, −1 + 4, 1 + 2) = (0, 1, 1)，它正好在 row space 裡；所有解是 (0, 1, 1) 加上 null space 方向 (1, 1, −1) 的倍數，排成一條直線。

### 反過來乘：得到投影矩陣
- A · A⁻¹_left = A(AᵀA)⁻¹Aᵀ = P：**投影到 column space**。它「想要當 I」：在 column space 上的向量不動，但垂直方向被送到 0。上例：(1/3)[2 −1 1; −1 2 1; 1 1 2]，對稱且 P² = P。
- A⁻¹_right · A = Aᵀ(AAᵀ)⁻¹A：**投影到 row space**。

### 一般情形：row space ↔ column space 一對一
r < m、r < n 時兩個 null space 都在，A 把某些向量打成 0，任何反矩陣都救不回來。但：
- x 在 row space ⇒ Ax 在 column space（Ax 是 columns 的組合），兩邊都是 r 維。
- 任何向量 = row space 成分 + null space 成分，A 殺掉 null space 成分。
- **限制在 row space 上，A 是一對一的**：x ≠ y 都在 row space ⇒ Ax ≠ Ay。

證明：設 Ax = Ay，則 A(x − y) = 0，x − y ∈ N(A)；又 x、y 都在 row space，相減 x − y 也在 row space（向量空間對減法封閉）。row space ⟂ null space，交集只有 0，所以 x − y = 0。

所以 A 是 row space → column space 的可逆對應，它的反方向就是**虛反矩陣**（pseudo-inverse）**A⁺**：A⁺(Ax) = x（x 在 row space）。A 殺掉 N(A)，A⁺ 殺掉 N(Aᵀ)；真正重要的事都發生在 row space 和 column space 之間。

### 為什麼需要 A⁺：rank 不足的最小平方
統計的線性迴歸就是最小平方，但 normal equation 只在 full column rank 時可解。若重複做了同一個實驗，A 的 columns 相依，AᵀA singular，最小平方解不唯一。

> **例題** A = [1 1; 2 2; 1 1]、b = (2, 1, 3)。AᵀA = [6 6; 6 6]（singular），Aᵀb = (2 + 2 + 3, 2 + 2 + 3) = (7, 7)。normal equation 6x₁ + 6x₂ = 7，整條線 x₁ + x₂ = 7/6 都是最小平方解。A⁺b = (7/12, 7/12)：落在 row space（(1, 1) 方向）上，是所有最小平方解裡**長度最短**的那個。

### Σ⁺ 與 A⁺ = VΣ⁺Uᵀ
Σ 是 m×n、rank r 的對角矩陣，是一般情形最簡單的例子。可逆對角矩陣的反矩陣是對角線取倒數；Σ⁺ 也這樣做，但只取到 σᵣ：

```
 Σ⁺：n×m，對角線放 1/σ₁, …, 1/σᵣ，其餘 0
 例：Σ = [3 0 0 0; 0 2 0 0; 0 0 0 0]（3×4）
     Σ⁺ = [1/3 0 0; 0 1/2 0; 0 0 0; 0 0 0]（4×3）
```

- ΣΣ⁺（m×m）和 Σ⁺Σ（n×n）都是對角線上 r 個 1、其他 0：分別是投影到 column space、row space 的投影矩陣。左乘右乘都得不到 I，只能把東西帶回兩個好空間、清掉 null space。
- Σ⁺ 的零區其實還能塞別的數（只會乘到 0，不影響 ΣΣ⁺、Σ⁺Σ），但「沒有多餘東西、最小」的那個才是 pseudo-inverse。

A = UΣVᵀ：Vᵀ 的反矩陣是 V，U 的反矩陣是 Uᵀ，Σ 承擔了所有麻煩，只能用 Σ⁺。順序倒過來：

```
 A⁺ = V Σ⁺ Uᵀ = (1/σ₁)v₁u₁ᵀ + … + (1/σᵣ)vᵣuᵣᵀ
```

> **例題** A = [4 3; 8 6]，σ₁ = √125、v₁ = (0.8, 0.6)、u₁ = (1, 2)/√5。A⁺ = (1/σ₁)v₁u₁ᵀ = (1/√125)(1/√5)(0.8, 0.6)ᵀ(1, 2) = (1/25)[0.8 1.6; 0.6 1.2] = (1/125)[4 8; 3 6]。檢查 AA⁺ = (1/125)[25 50; 50 100] = (1/5)[1 2; 2 4]（投影到 (1, 2) 方向），AA⁺A = (1/5)[1 2; 2 4][4 3; 8 6] = (1/5)[20 15; 40 30] = A。

> **例題** A = [1 1; 1 0; 0 1]（前面五步驟的例子）。A⁺ = (1/√3)v₁u₁ᵀ + 1·v₂u₂ᵀ = (1/6)[2 1 1; 2 1 1] + (1/2)[0 1 −1; 0 −1 1] = (1/3)[1 2 −1; 1 −1 2]。A 是 full column rank，所以 A⁺ 也等於左反矩陣 (AᵀA)⁻¹Aᵀ = (1/3)[2 −1; −1 2][1 1 0; 1 0 1] = (1/3)[1 2 −1; 1 −1 2]，一致。

> **重點** A⁺ 的整理：full column rank 時 A⁺ = (AᵀA)⁻¹Aᵀ（左反矩陣）；full row rank 時 A⁺ = Aᵀ(AAᵀ)⁻¹（右反矩陣）；可逆時 A⁺ = A⁻¹；一般時用 VΣ⁺Uᵀ。A⁺b 是長度最短的最小平方解。A⁺ 是唯一滿足 Moore-Penrose 四條件的矩陣：AA⁺A = A、A⁺AA⁺ = A⁺、(AA⁺)ᵀ = AA⁺、(A⁺A)ᵀ = A⁺A。

## 綜合複習：特徵值與特殊矩陣

### 第六章重點
- 求特徵值解 det(A − λI) = 0，但常有捷徑（trace、det、奇異、特殊結構）。
- 對稱：λ 實數，特徵向量夠多（重根也夠）且可選正交，A = QΛQᵀ。
- 正定：對稱且所有 λ > 0。
- 相似：B = M⁻¹AM，代表同一個轉換換了基底；特徵值相同（trace、det 也相同），Bᵏ = M⁻¹AᵏM（A 的次方成長，B 也成長；A 衰減，B 也衰減）。M 改變特徵向量，不改變特徵值。
- SVD：A = UΣVᵀ，對每個矩陣都成立。

### 例題：反對稱矩陣的微分方程
> **例題** du/dt = Au，A = [0 −1 0; 1 0 −1; 0 1 0]，求一般解的形式與週期。
> 1. 一般解 u(t) = c₁e^{λ₁t}x₁ + c₂e^{λ₂t}x₂ + c₃e^{λ₃t}x₃，c 由 u(0) 決定；第一件事是特徵值。
> 2. 第一列 (0, −1, 0) 和第三列 (0, 1, 0) 只差負號，相依 ⇒ singular ⇒ λ₁ = 0。
> 3. Aᵀ = −A，**反對稱**（skew-symmetric）⇒ 特徵值是純虛數（0 也在虛軸上）。
> 4. det(A − λI) = −λ(λ² + 1) − λ = −λ³ − 2λ = −λ(λ² + 2) = 0 ⇒ λ = 0、±√2 i。（也可檢查 A³ = −2A。）
> 5. e^{0t} = 1；|e^{±i√2 t}| = 1，在單位圓上繞圈：解**不爆炸也不衰減**，是週期的。
> 6. 回到起點要 √2 i·T = 2πi ⇒ **T = 2π/√2 = π√2**；此時 e^{AT} = I。

> **陷阱** 可對角化時 e^{At} = Se^{Λt}S⁻¹，e^{Λt} = diag(e^{λ₁t}, …)；只有特徵向量夠多時才能用。本題三個特徵值相異，沒問題。

### 正交特徵向量 ⇔ AAᵀ = AᵀA
對稱與反對稱矩陣的特徵向量都正交。確切條件是 **AAᵀ = AᵀA**（A 和自己的轉置可交換，正規矩陣）：
- 對稱：兩邊都是 A²。
- 反對稱：兩邊都是 −A²。
- 正交矩陣 Q：QᵀQ = QQᵀ = I。

大部分矩陣（例如 [1 2; 0 3]）有足夠的特徵向量但不正交。反對稱、正交矩陣的特徵向量可能是複數，例如 (1, i)、(1, −i)，要用複數內積（第一個取共軛）：(1, i)ᴴ(1, −i) = 1·1 + (−i)(−i) = 1 + (−1) = 0，正交。

### 例題：特徵值 0、c、2
> **例題** 3×3 矩陣的特徵值是 0、c、2，三個特徵向量兩兩正交。
> 1. 哪些 c 可對角化？能否對角化看特徵向量：三個正交 ⇒ 獨立 ⇒ **所有 c** 都可以（c 和別的重複也沒關係）。
> 2. 哪些 c 對稱？特徵向量已正交，還需要特徵值實數：**c 為任意實數**（c = i 就不對稱）。
> 3. 會是正定嗎？**不會**，有特徵值 0；c ≥ 0 時是半正定。
> 4. 可能是 Markov 矩陣嗎？Markov 一定有 λ = 1 且其他 |λ| ≤ 1，這裡有 λ = 2，**永遠不可能**。
> 5. A/2 可能是投影矩陣嗎？投影 P² = P ⇒ λ² = λ ⇒ λ 只能是 0 或 1。A/2 的特徵值 0、c/2、1，所以 **c = 0 或 c = 2**（c = 1 就不行）。

整題的關鍵是特徵向量正交；否則對稱、正定、投影全都不可能。

### 例題：又對稱又正交的矩陣
> **例題** A 對稱又正交（例如鏡射 A = I − 2nnᵀ，n 為單位向量）。
> 1. 特徵值：對稱 ⇒ 實數；正交不改變長度，‖Ax‖ = ‖x‖ ⇒ |λ| = 1。所以 **λ = ±1**。
> 2. 一定正定？不一定（可能有 −1）。
> 3. 沒有重複特徵值？錯：只有 ±1 兩種，3×3 以上一定重複。
> 4. 可對角化？可以，而且能用正交的 Q。可逆？可以，沒有 0 特徵值。
> 5. 證明 P = ½(A + I) 是投影矩陣：A 對稱 ⇒ P 對稱。A = Aᵀ = A⁻¹ ⇒ A² = I。P² = ¼(A² + 2A + I) = ¼(2I + 2A) = ½(A + I) = P。也可看特徵值：A 是 ±1，A + I 是 0、2，除以 2 得 0、1，正是投影矩陣的特徵值。

## 綜合複習：整門課的考古題

### Ax = b 的解與 rank
> **例題** A 是 3×n，Ax = (1, 0, 0) 無解，Ax = (0, 1, 0) 恰一解。關於 m、n、r 能說什麼？
> 1. m = 3（3 列）。
> 2. 有 b 無解 ⇒ r < m（若每列都有 pivot，任何 b 都解得出來）。
> 3. 有解時恰一解 ⇒ null space 只有 0 ⇒ r = n（columns 獨立）。
> 4. 結論 **r = n < m = 3**，n 只能是 1 或 2。
> 5. 舉例：(0, 1, 0) 要在 column space。A = [0; 1; 0]（n = r = 1，column space 是 y 軸，(1, 0, 0) 不在上面）；或 A = [0 0; 1 0; 0 1]（r = n = 2，column space 是 yz 平面）。

> **例題** 承上，判斷真假。
> - AᵀA 可逆：**真**。AᵀA 可逆 ⇔ r = n。例 A = [0 0; 1 0; 0 1]，AᵀA = I。
> - AAᵀ 正定：**假**。AAᵀ 是 3×3 但 rank 只有 2；例子中第一列全是 0。改成「半正定」就永遠成立。
> - det(AᵀA) = det(AAᵀ)：**假**。前者 1、後者 0。det(AB) = det(BA) 只對方陣成立。
> - Aᵀy = c 對每個 c 都有解，而且無限多：**真**。A 的 columns 獨立 ⇒ Aᵀ 的 rows 獨立（full row rank）⇒ 一定有解；dim N(Aᵀ) = m − r = 3 − n > 0 ⇒ 可以加 null space 向量，無限多解。例 c = (1, 2)：y = (t, 1, 2) 整條線都是解。

### A 的 columns v₁、v₂、v₃
> **例題** A 的三個 columns 是 v₁、v₂、v₃。
> - (a) 解 Ax = v₁ − v₂ + v₃：Ax 是 columns 的組合，**x = (1, −1, 1)**。
> - (b) 若 v₁ − v₂ + v₃ = 0，解唯一嗎？(1, −1, 1) 在 null space，任何解加上它 Ax 不變，**永遠不唯一**。
> - (c) 若 v₁、v₂、v₃ 標準正交，v₁、v₂ 的哪個組合最接近 v₃？想成 x、y、z 軸：v₃ 投影到 xy 平面落在原點，答案 **0·v₁ + 0·v₂**。

### Markov 矩陣
> **例題** A 的三個 columns 是 (.2, .4, .4)、(.4, .2, .4)、(.3, .3, .4)（每行和 1）。u₀ = (0, 10, 0)，求穩態。
> 1. col₁ + col₂ = (.6, .6, .8) = 2·col₃ ⇒ columns 相依 ⇒ singular ⇒ λ₁ = 0。
> 2. Markov ⇒ λ₂ = 1（(1, 1, 1) 是 Aᵀ 的特徵向量，A 和 Aᵀ 特徵值相同）。
> 3. trace = .2 + .2 + .4 = 0.8 ⇒ λ₃ = 0.8 − 0 − 1 = −0.2。
> 4. uₖ = c₁·0ᵏx₁ + c₂·1ᵏx₂ + c₃(−0.2)ᵏx₃ → c₂x₂。
> 5. 猜 x₂ = (3, 3, 4)：A(3, 3, 4) = 3(.2, .4, .4) + 3(.4, .2, .4) + 4(.3, .3, .4) = (3, 3, 4)，成立。
> 6. Markov 過程總人數不變：一開始 10 人，(3, 3, 4) 和也是 10，所以 c₂ = 1，**u∞ = (3, 3, 4)**。

### 2×2 快問快答
> **例題** 舉出 2×2 的例子，或說明不存在。
> 1. 投影到 a = (4, −3) 的直線：aaᵀ = [16 −12; −12 9]，aᵀa = 25，**P = [16 −12; −12 9]/25**。
> 2. 特徵值 0 對應 (1, 2)、特徵值 3 對應 (2, 1)：A = SΛS⁻¹，S = [1 2; 2 1]、Λ = diag(0, 3)、S⁻¹ = (−1/3)[1 −2; −2 1]。SΛ = [0 6; 0 3]，A = [0 6; 0 3]·(−1/3)[1 −2; −2 1] = **[4 −2; 2 −1]**。檢查 A(1, 2) = (0, 0)、A(2, 1) = (6, 3) = 3(2, 1)。
> 3. 不能寫成 BᵀB 的實矩陣：BᵀB 一定對稱，所以**任何不對稱矩陣**都行，例如 [1 2; 0 1]。
> 4. 特徵向量正交但不對稱：**反對稱**（例 [0 1; −1 0]）或**正交矩陣**（例旋轉 [cos θ −sin θ; sin θ cos θ]）。

### 最小平方
> **例題** A = [1 0; 1 1; 1 2]、b = (3, 4, 1)，已知最小平方解 Ĉ = 11/3、D̂ = −1。
> 1. 驗證：AᵀA = [3 3; 3 5]，Aᵀb = (8, 6)。3C + 3D = 8、3C + 5D = 6，相減 2D = −2，D = −1，C = 11/3。
> 2. 投影 p = Ax̂ = (11/3)(1, 1, 1) − 1·(0, 1, 2) = **(11/3, 8/3, 5/3)**。
> 3. 對應的直線擬合：A 的第二行 0、1、2 是時間 t，b 是高度，三點 (0, 3)、(1, 4)、(2, 1)，最佳直線 **y = 11/3 − t**（截距 11/3、斜率 −1）。
> 4. 找非零 b 讓最小平方解是 (0, 0)：最佳組合是零組合 ⇔ b 垂直整個 column space（Aᵀb = 0），例如 **b = (1, −2, 1)**：和 (1, 1, 1)、(0, 1, 2) 內積都是 0。

## 重點整理
- A = UΣVᵀ：任何 m×n 矩陣都有；U（m×m）、V（n×n）正交，Σ（m×n）對角、σ₁ ≥ … ≥ σᵣ > 0。
- 幾何：Vᵀ 轉 → Σ 伸縮 → U 轉；單位圓 → 橢圓，半軸 σᵢuᵢ。
- Avᵢ = σᵢuᵢ；AV = UΣ。
- AᵀA = V(ΣᵀΣ)Vᵀ：V = AᵀA 的特徵向量，σᵢ = √λᵢ；AAᵀ = U(ΣΣᵀ)Uᵀ。
- 手算：大小與 rank → Σ → V（必要時從 N(A) 補、Gram-Schmidt）→ uᵢ = Avᵢ/σᵢ（其餘從 N(Aᵀ) 補）→ 組合 UΣVᵀ。
- 不要分別解 AAᵀ 再配對，符號會錯。
- 四個子空間：v₁..vᵣ ∈ C(Aᵀ)、u₁..uᵣ ∈ C(A)、v_{r+1}..vₙ ∈ N(A)、u_{r+1}..uₘ ∈ N(Aᵀ)。
- rank = 非零 σ 個數；|det A| = ∏σᵢ；σ 不可為負。
- A = Σ σᵢuᵢvᵢᵀ（每項 rank 1）；economy SVD 精確；truncated SVD 是最佳 rank r 近似（Eckart–Young），F-norm 誤差 √(σ_{r+1}² + …)。
- ŨᵀŨ = I，但 ŨŨᵀ ≠ I（是投影）。
- 左反 (AᵀA)⁻¹Aᵀ（r = n），右反 Aᵀ(AAᵀ)⁻¹（r = m）；反過來乘得到投影到 C(A)、C(Aᵀ)。
- A⁺ = VΣ⁺Uᵀ，Σ⁺ 放 1/σᵢ；A⁺：column space → row space，殺掉 N(Aᵀ)；A⁺b 是最短的最小平方解。
- 正交特徵向量 ⇔ AAᵀ = AᵀA；反對稱 → 純虛特徵值、週期解。
- 對稱又正交 ⇒ λ = ±1、A² = I、½(A + I) 是投影。
